## 1. 事業の目的

当社は「日本文化・武士道・体験型観光を通じて、世界と日本を精神でつなぐ」ことを事業の目的としている。

訪日外国人旅行者に対し、弓道・書道・茶道・座禅・甲冑着装等の日本文化体験を、有識者・工房・寺社等の協力を得て提供してきた。これらの体験を旅程に組み込むにあたり、海外及び国内の旅行業者から、運送・宿泊・通訳案内サービスを含む地上手配の受託を求められる機会が増加している。

本申請は、旅行業法第2条第6項に規定する旅行サービス手配業の登録を受け、旅行業者からの依頼に基づく手配業務を適法かつ確実に遂行する体制を整えることを目的とする。

なお当社は、旅行者と直接に企画旅行契約又は手配旅行契約を締結する事業は行わない。旅行者に対する旅行商品の販売は、引き続き登録旅行業者を通じて行う。

## 2. 取り扱う旅行サービス手配業務の範囲

旅行業法第2条第6項各号に掲げる行為のうち、次を取り扱う。

|区分|取扱いの有無|主な内容|
|---|---|---|
|(1) 運送等サービスの手配|取り扱う|貸切バス、ハイヤー・タクシー、鉄道乗車券、旅客船等の手配|
|(2) 宿泊サービスの手配|取り扱う|ホテル、旅館、簡易宿所等の手配|
|(3) 全国通訳案内士・地域通訳案内士の手配|取り扱う|通訳案内サービスの手配|
|(4) 免税対象物品の販売所における物品販売の手配|取り扱わない|―|

上記に付随して、日本文化体験、飲食店、拝観・入場券等の予約手配を併せて行う。

### 手配の対象地域

愛知県を中心とする中部圏を主たる区域とし、依頼内容に応じて全国を対象とする。

### 取引の相手方

|区分|想定|
|---|---|
|海外の旅行業者|欧米豪・東南アジア・東アジア圏の旅行会社、DMC、OTA（商談会等を通じて開拓）|
|国内の旅行業者|訪日旅行を取り扱う登録旅行業者|

いずれの場合も、取引の相手方は旅行業者に限り、旅行者との直接契約は行わない。

## 3. 業務の実施の方法

### 3.1 取引の流れ

```
旅行者 ──旅行代金──▶ 旅行業者（依頼元）
                       │
                       │ 手配依頼・手配料の支払
                       ▼
                  合同会社BUSHIDO（旅行サービス手配業者）
                       │
                       │ 手配・代金の支払
                       ▼
        運送機関・宿泊機関・通訳案内士・体験提供者等
```

旅行代金の決定権は依頼元である旅行業者が有し、当社は手配に係る対価（ネット料金及び手配料）を旅行業者から受領する。旅行者から直接に代金を受領することはない。

### 3.2 受注から精算までの手順

1. **引合い受付**　旅行業者から、期間・人員・行程・予算等の条件を書面（電子メールを含む）で受領する。
2. **見積・提案**　取扱管理者が法令上の適否を確認したうえで、手配可能な内容と対価を明示した見積書を提出する。
3. **受託の確定**　取引条件（手配内容、対価、取消料、責任範囲、支払期日）を記載した書面を相互に取り交わし、受託を確定する。
4. **手配の実行**　運送機関・宿泊機関・通訳案内士等に対し、書面により予約を行い、予約確認書を保存する。
5. **手配内容の通知**　確定した手配内容を依頼元の旅行業者へ書面で通知する。
6. **実施日の対応**　当日の連絡体制を定め、遅延・変更等が生じた場合は速やかに依頼元及び関係先へ連絡する。
7. **精算・記録の保存**　実施後、精算書を作成して請求を行い、取引に関する書類を営業所に備え置き保存する。

### 3.3 取引条件の明示

受託にあたっては、次の事項を書面により明示する。

- 手配する運送・宿泊・通訳案内サービスの内容及び員数
- 対価の額及び支払方法・支払期日
- 取消・変更が生じた場合の取扱い及び取消料の負担区分
- 当社の責任の範囲（手配債務の履行に限られること）
- 苦情・事故発生時の連絡先及び対応手順

## 4. 法令遵守及び業務の適正確保のための措置

### 4.1 旅行サービス手配業務取扱管理者の選任

主たる営業所に、旅行サービス手配業務取扱管理者として **上岡賢輔** を選任する（常勤・専任）。他の営業所の取扱管理者を兼務することはない。

|項目|内容|
|---|---|
|氏名|上岡賢輔|
|生年月日|昭和61年12月5日|
|職名|代表社員|
|資格|旅行サービス手配業務取扱管理者研修　修了|
|修了証明書の日付|2026年8月20日付|

取扱管理者は、旅行業法第28条の3の規定に基づき、次の事務を管理・監督する。

- 取引条件の明確な説明及び書面の交付
- 手配内容の正確な記録及び関係書類の保存
- 運送機関・宿泊機関等の選定に関する適正の確保
- 苦情の処理
- 契約書面その他の書類の管理
- 従業者に対する法令の周知及び指導

登録後は、5年ごとに実施される定期研修を受講させる。

### 4.2 遵守事項の徹底

- **名義利用の禁止**　旅行業法第14条（第32条準用）に基づき、他人に自己の名義をもって旅行サービス手配業を営ませない。
- **無登録営業の禁止**　登録完了の日までは、旅行サービス手配業務に該当する取引を行わず、対外的にも「旅行サービス手配業者」を称さない。
- **旅行者との直接契約の禁止**　旅行者から旅行代金を収受する取引は行わない。運送・宿泊の立替払いによる取次と誤認されるおそれのある取扱いも行わない。
- **通訳案内士法の遵守**　有資格者でない者に「全国通訳案内士」「地域通訳案内士」の名称を用いさせない。
- **関係法令の遵守**　道路運送法、旅館業法、食品衛生法、個人情報保護法その他の関係法令を遵守する。自社車両による旅客の運送は行わない。

### 4.3 苦情処理体制

苦情の申出は、営業所において取扱管理者が一次的に受け付ける。受付日時、申出者、内容、調査結果、回答内容及び再発防止策を苦情処理簿に記録し、営業所に備え置く。旅行者からの苦情は、依頼元の旅行業者と連携して処理する。

### 4.4 個人情報の取扱い

手配のために取得した旅行者の氏名等の個人情報は、手配の目的の範囲内でのみ利用し、施錠可能な保管庫及びアクセス制限を施した電磁的記録により管理する。保存期間経過後は速やかに廃棄する。

## 5. 事業の見通し

以下は本申請時点における見込みであり、確定した数値ではない。

### 5.1 前提

- 登録完了は2026年内を見込む。
- 初年度は、商談会等を通じて接点を持った海外旅行業者及び国内の訪日取扱旅行業者からの受託を想定し、3年目に手配業務収入1億5,000万円規模とすることを目標とする。
- 手配業務収入は、依頼元旅行業者から受領する総額（運送・宿泊・通訳案内等のネット料金及び手配料）とする。
- 支払手配代金は、運送機関・宿泊機関・通訳案内士・体験提供者等への支払額とする。手配料率（粗利率）は初年度18％とし、取引量の増加に伴う仕入条件の改善により3年目に20％となることを見込む。
- 1件当たりの平均取扱額は、初年度50万円、2年目約55万円、3年目60万円を見込む。

### 5.2 収支の見通し

|区分|初年度|2年目|3年目|
|---|---|---|---|
|取扱件数（件）|100|180|250|
|手配業務収入（千円）|50,000|100,000|150,000|
|支払手配代金（千円）|41,000|81,000|120,000|
|手配業務粗利（千円）|9,000|19,000|30,000|
|営業費用（千円）|7,500|14,000|20,000|
|営業利益（千円）|1,500|5,000|10,000|

営業費用の主な内訳は、人件費、通信費、旅費交通費、商談会等の出展・渡航費、資料制作費及び管理者の定期研修費用である。

> 旅行サービス手配業には財産的基礎の要件及び営業保証金の供託義務がないため、収支計画は審査上の可否要件ではないが、事業の実現可能性を示す資料として記載する。

### 5.3 事業の推進方針

1. 中部圏の運送機関・宿泊機関・通訳案内士・体験提供者との取引関係を整備し、手配可能な範囲を明確にする。
2. 海外旅行業者向けに、手配可能なサービスと料金体系を記載した資料を整備する。
3. 登録完了後、取引先各社に登録番号を通知し、手配業務の受託範囲を改めて明示する。
4. 案件ごとに手配内容と精算の記録を蓄積し、取扱管理者による点検を定期的に行う。
