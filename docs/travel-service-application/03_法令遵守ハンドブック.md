## 第1部　旅行業法

### 1.1 現在地

| 段階 | 状態 |
|---|---|
| 旅行サービス手配業務取扱管理者研修 修了 | 2026年8月20日　**済** |
| 旅行サービス手配業　登録申請 | **準備中**（愛知県知事登録） |
| 旅行業（第3種等）登録 | 未着手。管理者資格の取得が前提 |

**登録が完了するまでは、対外的に「旅行サービス手配業者」を名乗らない。** 「登録申請中」という表現に留める。LP・提案資料・名刺・メール署名すべてに適用する。

### 1.2 三つの層と、それぞれの境界

| 層 | 誰に | 何を | 現在 |
|---|---|---|---|
| ① 体験・ガイド | 旅行者に直接 | 弓道・書道・茶道・座禅の実施、ガイド同行、飲食店・拝観の予約 | **登録不要。実施可** |
| ② 手配（B2B） | 旅行業者へ | 運送・宿泊・通訳案内の手配 | 手配業の登録後 |
| ③ 直販（B2C） | 旅行者に直接 | 宿泊＋交通をセットで | 旅行業（第3種等）の登録後 |

### 1.3 「旅行業」に当たる行為の線引き

報酬を得て**運送または宿泊**を手配・代理・媒介・取次すること、または企画旅行を実施することが旅行業に当たる。

| 行為 | 登録なしで可否 |
|---|---|
| 弓道・書道・茶道・座禅を自ら実施する | ○ |
| 英語ガイドとして同行・案内する | ○ |
| レストラン・拝観券・体験施設を予約する | ○（運送・宿泊ではない） |
| 甲冑撮影・工房訪問の段取りをする | ○ |
| ホテル・旅館を予約してあげる | **×　旅行業** |
| タクシー・バス・新幹線を手配する | **×　旅行業** |
| 自社の車で客を運ぶ | **×　道路運送法（白タク）** |

### 1.4 現場で最も事故が起きやすい3点

**(1) 立替精算**

交通費・宿泊費を当社が立て替えて後で請求すると、「取次」と見なされる余地がある。

- **可**：「乗車券とタクシー代はご自身でお支払いください」と案内する
- **不可**：当社がまとめて支払い、後日請求する
- 宿も同じ。「このお宿がおすすめです」＝情報提供なので可。代わりに予約を取ると不可

**(2) 通訳案内士の名称**

2018年の通訳案内士法改正で業務独占は廃止され、無資格でも有償ガイドは可能。ただし**「全国通訳案内士」「地域通訳案内士」は名称独占**。有資格者でない者にこれらの名称を使わせない。

- **可**：「専属英語ガイド」「プライベートガイド」
- **不可**：「通訳ガイド（有資格者と誤認させる文脈で）」

**(3) 名義貸し**

他人に当社の名義で旅行サービス手配業を営ませることは禁止。登録後、提携先が当社の登録番号を使って独自に手配を受けることのないよう、契約書で明確に禁じる。

### 1.5 登録後に必ずやること

1. 営業所の見やすい場所に**標識を掲示**する
2. 各種資料・LP・特定商取引法に基づく表記に**登録番号を追記**する
3. 取引条件を記載した**書面の交付**を全案件で徹底する
4. **取引記録・関係書類を営業所に備え置き保存**する
5. 取扱管理者に**5年ごとの定期研修**を受講させる

### 1.6 第3種への道

**旅行者から直接集金するには旅行業の登録が必要。最大の壁は管理者資格。**

> ⚠️ **旅行サービス手配業務取扱管理者（研修修了）では、旅行業の管理者にはなれない。** 逆（国内/総合の合格者→手配業の管理者）は可。

| 区分 | 基準資産 | 営業保証金 | 業務範囲 |
|---|---|---|---|
| 第1種 | 3,000万円 | 7,000万円 | すべて（海外募集型も可） |
| 第2種 | 700万円 | 1,100万円（分担金220万円） | 国内募集型が全国可。海外募集型は不可 |
| **第3種** | **300万円** | 300万円（**分担金60万円**） | **受注型企画旅行・手配旅行は全国＋海外可**。募集型のみ拠点区域内 |
| 地域限定 | 100万円 | 15万円（分担金3万円） | すべて拠点区域内のみ |

※ 営業保証金は取引額により増加。旅行業協会（ANTA/JATA）の保証社員になれば分担金は1/5。

**「第3種は地域限定」は誤解。** 区域が制限されるのは**募集型企画旅行だけ**。受注型企画旅行と手配旅行は全国・海外すべて可。BUSHIDOの主力は「問い合わせ→提案→書面確定」＝受注型なので、第3種で全国どこでも自社完結できる。できないのは「あらかじめ行程と価格を決めて不特定多数に売る」形（即時予約ボタン、OTAへの固定価格出品）。

**旅行業者代理業の注意**：所属旅行業者は**1社のみ**。複数社との代理業兼務は不可。共同企画（提携先が企画・実施）の形なら代理業の論点を回避できる。

## 第2部　事業別の関係法令

### 2.1 レンタカー事業（テスラレンタカージャパン）

| 論点 | 内容 |
|---|---|
| 根拠 | 道路運送法に基づく**自家用自動車有償貸渡業**の許可（運輸支局） |
| 運転者のあっせん | **禁止**。レンタカー事業者が運転者を紹介・あっせんすることはできない |
| 影響 | **BUSHIDOはレンタカー事業を持つため、運転者マッチング型の例外も使えない**。交通はどのルートでも自前にできない |
| 変更時 | 事業譲渡・法人成り・車両配置の変更等は運輸支局への届出・認可が必要 |
| 窓口 | 愛知運輸支局 輸送担当 |

**ツアーとの結合に注意**：「体験＋レンタカー」をセットで案内する際、実質的に運送を手配していると評価されないよう、契約主体と支払先を分離する。

### 2.2 日本文化体験（弓道・書道・茶道・座禅・甲冑）

| 論点 | 対応 |
|---|---|
| **刀剣・甲冑** | 真剣を用いる場合は銃砲刀剣類所持等取締法の登録証が必要。運搬・保管・展示の要件を確認する。模造刀でも、公道での携帯は軽犯罪法・銃刀法上の問題となり得る |
| **弓具** | 弓・矢は銃刀法の規制対象外だが、公道での運搬時はケースに収める |
| **飲食提供** | 茶菓・食事を提供する場合、営業形態により食品衛生法の営業許可または届出が必要（保健所） |
| **寺社・文化財での実施** | 施設側の使用許可を書面で取得。文化財保護法上の制限がある場所では、撮影・使用の可否を個別確認 |
| **屋外での実施** | 道路・公園を使う場合は道路使用許可（警察）・占用許可（道路管理者）等 |
| **傷害リスク** | 弓道・武道体験は身体的リスクを伴う。**傷害保険・賠償責任保険の付保**と、参加者への書面による注意事項の交付・同意取得を必須とする |
| **未成年の参加** | 保護者の同意書を取得する |

### 2.3 宿泊を伴う事業（合宿・リトリート）

自社または関係先の施設で旅行者を宿泊させる場合、**旅館業法**の許可、または**住宅宿泊事業法（民泊）**の届出が必要になる可能性がある。「体験に付随する宿泊」でも、反復継続して宿泊料を受け取れば旅館業に該当し得る。実施前に保健所へ相談すること。

### 2.4 花火事業（BUSHIDO FIREWORKS／中国製造→海外輸出）

**この事業は規制の密度が最も高い。** 単独で専門家の確認を推奨する。

| 論点 | 内容 |
|---|---|
| 火薬類取締法 | 製造・販売・貯蔵・輸入・輸出それぞれに許可・届出。**日本国内を経由しない三国間取引でも、日本法人が主体となる場合の適用を確認すること** |
| 外国為替及び外国貿易法 | 輸出許可・役務取引許可の要否。火薬類は規制品目 |
| 危険物輸送 | 海上はIMDGコード、航空はIATA危険物規則。危険物船舶運送及び貯蔵規則 |
| 仕向国の規制 | 輸入許可・製品規格（CE、CPSC等）は国ごとに異なる |
| 関税法 | 輸出申告、原産地証明 |

### 2.5 海外との取引（インバウンド手配・輸出）

| 論点 | 対応 |
|---|---|
| 契約準拠法・裁判管轄 | 海外旅行会社との契約書に明記する |
| 外国送金 | 犯罪収益移転防止法に基づく取引時確認。金額により外為法の報告義務 |
| 消費税 | 非居住者への役務提供は輸出免税の対象となる場合がある。適用要件と証憑保存を税理士に確認 |
| インボイス | 適格請求書発行事業者　登録番号 **T8180003024921**。請求書の記載要件を満たすこと |

### 2.6 人の雇用・業務委託

| 論点 | 対応 |
|---|---|
| 外国人スタッフ | 在留資格で認められた活動範囲を超える就労をさせない。資格外活動許可の有無を確認 |
| 業務委託と雇用の区別 | 実態が指揮命令下の労働であれば、契約名称が業務委託でも労働者と扱われる |
| 労働条件通知書 | 雇用時は交付が義務 |
| ガイド・講師の外部委託 | 委託契約書で、責任範囲・再委託の可否・事故時の対応を明記 |

## 第3部　表示・広告・契約

### 3.1 景品表示法（優良誤認・有利誤認）

- **根拠のない最上級表現を使わない**：「日本最高の」「唯一の」等は、客観的な裏付けがなければ優良誤認となる
- **「登録」「認定」の表現に注意**：登録前に「登録済」と受け取れる表記をしない
- **体験内容の誇張**：実際に提供できない内容を掲載しない。「有名寺院で」等の抽象表現は、実際の提供先と齟齬がないか確認
- **価格表示**：割引の根拠となる「通常価格」に実績が必要

### 3.2 特定商取引法

LPから直接申込みを受ける場合、**特定商取引法に基づく表記**が必要。

必須記載：事業者名／代表者名／所在地／電話番号／メールアドレス／販売価格／代金の支払時期と方法／役務の提供時期／返品・キャンセルの条件／**旅行業の登録番号（登録後）**

### 3.3 消費者契約法

- 事業者の責任を全部免除する条項、消費者の解除権を放棄させる条項は**無効**
- キャンセル料は、平均的な損害を超える部分が無効となる。段階的なキャンセル料設定に合理的根拠を持たせる

### 3.4 個人情報保護法

| 項目 | 対応 |
|---|---|
| 利用目的の特定・通知 | プライバシーポリシーに明記し、取得時に通知 |
| 第三者提供 | 手配先（宿・バス会社）への提供は「利用目的の達成に必要な範囲」として整理。**海外の事業者への提供は越境移転の規律**（移転先国の制度情報の提供等）が必要 |
| 安全管理措置 | 施錠可能な保管庫、アクセス制限、退職者のアカウント停止 |
| 保存期間 | 目的達成後は速やかに廃棄 |
| 漏えい時 | 個人情報保護委員会への報告と本人通知が義務 |

**海外旅行会社から旅行者名簿を受領する場面が増えるため、越境移転の整理は登録前に済ませておくこと。**

## 第5部　日常運用チェックリスト

### 新規案件を受けるとき

- [ ] 相手は旅行業者か、旅行者本人か（旅行者本人なら、手配業では受けられない）
- [ ] 運送・宿泊を含むか。含むなら現時点では登録旅行業者を通す
- [ ] 立替精算になっていないか
- [ ] 取引条件（手配内容・対価・取消料・責任範囲・支払期日）を書面で取り交わしたか
- [ ] 体験を含む場合、保険は有効か。参加者への注意事項交付と同意取得は済んだか

### 対外文書を出すとき

- [ ] 登録前に「登録済」と読める表現がないか
- [ ] 「全国通訳案内士」等の名称独占資格を、無資格者に使っていないか
- [ ] 根拠のない最上級表現・数値がないか
- [ ] 小笠原流その他、商業利用を禁じられた名称を使っていないか

### 個人情報を受け取ったとき

- [ ] 利用目的の範囲内か
- [ ] 手配先への提供は必要最小限か。海外提供なら越境移転の整理は済んでいるか
- [ ] 保管場所は施錠・アクセス制限されているか

## 第6部　専門家に確認すべき論点

以下は解釈が分かれ得る、または事業への影響が大きい論点である。**自己判断せず、行政書士・弁護士・税理士に確認すること。**

1. **花火事業の火薬類取締法・外為法の適用範囲**（三国間取引を含む）
2. **体験に宿泊を伴わせる場合の旅館業法該当性**
3. **レンタカー事業を持つことによる、ツアー内交通の設計上の制約**
4. **海外旅行会社への個人データ越境移転のスキーム**
5. **非居住者向け役務提供の消費税の取扱い**
6. **提携先との共同企画が、旅行業者代理業に該当しないための契約設計**
7. **刀剣・甲冑を用いる体験の銃刀法上の取扱い**
