# 保護者説明会 開催計画

**会場：** 名古屋市内（要手配）　　**各回オンライン併催**（海外・外国人保護者向け／時差を考慮）

---

## 全体設計

3回に分けるのは、**目的が違うから**である。1回にまとめない。

| 回 | 時期 | 対象 | 目的 |
| --- | --- | --- | --- |
| **第1回** | 2027年5月 | 参加決定者の保護者 | プログラムの全体像を伝え、**不安を先に潰す** |
| **第2回** | 2027年6月 | 同上 | **安全管理と持ち物**。バディ発表 |
| **第3回** | 2027年7月 | 同上 | **直前確認**。書類回収 |

## 第1回（5月）— 全体像と、不安を先に潰す

| 時間 | 内容 |
| --- | --- |
| 0:00 | 開会・実行委員長挨拶 |
| 0:05 | 事業の趣旨（なぜ伊勢か、なぜ国際か） |
| 0:15 | 3日間のプログラム説明 |
| 0:35 | **多様な背景への配慮**（参拝・食事・入浴） |
| 0:50 | バディ制度の説明 |
| 1:00 | 質疑応答 |
| 1:20 | 閉会 |

**この回の要は35分からの15分。** 参拝は信仰の強制ではないこと、食事対応、大浴場の文化——**保護者が最も気にすることを、質問される前に説明する。** ここを丁寧にやると、以降の個別問い合わせが激減する。

| 時間 | 内容 |
| --- | --- |

## 運営上の注意

- **各回オンライン併催。** 海外の保護者は時差があるため、録画を一定期間視聴できるようにする
- **通訳を配置する。** 説明会で伝わらなければ、当日も伝わらない
- 資料は**日英2言語**で用意し、事前に配布する
- **欠席者へのフォロー**を必ず行う（録画URL＋資料送付＋個別連絡）
- 会場は名古屋市内。**後援が取れていれば公共施設を利用しやすい場合がある**
