# 伊勢青少年国際キャンプ パートナー向け紹介動画 台本

**尺：90秒**
**対象：** 協賛・連携のパートナー候補（企業・団体）
**素材：** 今年（2026年）の写真 ／ `mouvie.MOV`（3日間のスライドショー）から選んだもの
**構成：** 縦組みテロップ ＋ 下部の横組み補足 ＋ ナレーション
**形式：** 1920×1080（16:9）・30fps・H.264／AAC
**制作スクリプト：** `build/partner_video/make_partner_video.py`

---

## 0. 制作方針

- 3分35秒版（`12-紹介動画台本.md`）の世界観をそのまま引き継ぐ。**縦組み・明朝体・白字に影**
- パートナー向けなので、**「何をするか」より「預けたお金がどう使われるか」と「誰がすでに乗っているか」**に時間を割く
- **今年の写真は「この場所で、こういう3日間が過ごせる」ことの証拠**として使い、来年の事業を語る。今年の催しと来年の事業を混同させない言い方にしている（③のナレーション）
- **確認できていない数字は入れない。** 「リピーターが半分」は意味が未確認のため、この版では使っていない

## 4. 制作手順

1. 写真を `photos/` に置く。ファイル名は**ショット番号で始める**（例：`S2-3_飯盒.jpg`）。足りないショットは仮画面で出るので、何が埋まっていないかが動画上で分かる
2. `python make_partner_video.py --photos photos --font-dir <しっぽり明朝のフォルダ> --out out`
3. `out/partner_video_90s.mp4` ができる。`out/report.json` に、どのショットにどの写真が入ったかが出る

- ナレーションは **Open JTalk（合成音声）の仮録り**。本番は人の声で録り直し、同じ開始秒（スクリプト内 `NARRATION`）に置けばそのまま差し替わる
- 音楽は入れていない。権利処理済みの曲を、ナレーションの下に −20dB 前後で敷くことを想定
- フォントは しっぽり明朝（SIL Open Font License・商用利用可）
