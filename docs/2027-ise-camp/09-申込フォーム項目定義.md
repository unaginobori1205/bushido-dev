# 申込フォーム 項目定義

**公開：** 2027年1月1日　　**言語：** 日本語／英語
**一次締切：** 2027年3月○日　　**定員：** 40名（30〜50名）

---

## 設計方針

- **申込と本登録を分ける。** 申込時は最小限、参加決定後に詳細情報を取る
- 健康・アレルギー・宗教上の配慮など機微な情報は**本登録で取る**
- 定員超過時の選考基準を**申込前に明示する**

## 第2段階：本登録（参加決定後・4月）

| 分類 | 項目 |
| --- | --- |
| **健康** | 既往症／現在治療中の疾患／服薬／持病／かかりつけ医／健康保険証の写し |
| **アレルギー** | 食物アレルギー（品目・症状の程度・エピペンの有無）／その他のアレルギー |
| **食事** | ハラル／ベジタリアン／ヴィーガン／その他の制限 |
| **宗教上の配慮** | 礼拝の時間・場所の必要性／その他の配慮事項 |
| **入浴** | 大浴場の利用可否／個別シャワー希望の有無 |
| **泳力** | 4段階（**川遊びのエリア分けに使用**） |
| **緊急連絡先** | 第1・第2連絡先（**海外の場合は時差を考慮し必ず2件**） |
| **同意書** | 参加同意書／傷害保険の加入確認／未成年単独渡航同意書（該当者） |

## 定員超過時の選考基準（申込前に明示）

1. **国内枠と外国人枠の比率を確保する**（外国人枠を全体の1/4〜1/3）
2. 学年のバランス
3. 申込順
4. 参加動機

> **先着順と書かない。** 比率の確保が必要なため、単純な先着順では成立しない。「申込多数の場合は選考のうえ決定します」と明記する。

## キャンセル規定（記載案）

| 時期 | 取消料 |
| --- | --- |
| 参加決定〜出発30日前 | 無料 |
| 出発29日前〜15日前 | 参加費の20% |
| 出発14日前〜3日前 | 参加費の50% |
| 出発2日前〜当日 | 参加費の100% |

※台風・災害等による主催者判断での中止は全額返金（実費を除く）
※**旅行業の建て付けが確定してから最終化する。** 登録旅行業者に委託する場合は、旅行業約款に沿った取消料規定になる（計画書§3）

---

## 技術要件

- **内製する**（計画書§8）
- 決済は**銀行振込を主**とし、カードは海外・希望者のみ。手数料差は40名で約8万円
- 自動返信メールを日英で用意する
- 申込データは事務局のみがアクセスできる形で管理する
