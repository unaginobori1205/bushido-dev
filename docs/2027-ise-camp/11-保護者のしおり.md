## 3. プログラムのねらい

**静座（正座）**
一日のはじまりに、静かに座り、心と姿勢を整えます。

**宇治橋前 清掃奉仕**
伊勢神宮内宮の入口である宇治橋の前を、竹ぼうきで清掃します。場を清めることを通じて、感謝の心を育みます。

**内宮参拝**
早朝の伊勢神宮内宮を歩きます。二千年以上守られてきた場所の空気に触れていただきます。**日本文化の作法を学ぶ体験**として実施します（10章をご覧ください）。

**合気道研修（英語）**
合気道は相手を倒さない武道です。「強いとは、打ち負かすことではない」——この一点を体で学びます。株式会社鯱バス代表の宇津木滋が、自ら英語で指導します。

**野外炊事（飯盒炊さん）・BBQ交流会**
班ごとに火をおこし、米を炊き、カレーを作ります。言葉が通じなくても、手を動かせば通じ合えます。

**川遊び（五十鈴川）**
神宮のほとりを流れる清流で遊びます。泳力に応じてエリアを分け、スタッフが水際で見守ります。

**キャンプファイヤー**
班ごとに出し物を考えて発表します。ここも、言葉は要りません。

**ともしびの集い**
ろうそくの灯りだけの空間で、親があって自分たちが生きていけるということをお話しします。

**バディ制度**
日本の子どもと外国にルーツを持つ子どもが1対1で組み、3日間を共に過ごします。移動も食事も同じ相手です。

> お子さまには、一行だけお伝えください。
> **「英語ができる必要はありません。伝えようとすることが役目です」**

## 8. 安全管理体制

| 項目 | 内容 |
| --- | --- |
| **引率体制** | 引率者1名あたりのお子さまは**8名以下**。常に班行動とします |
| **看護担当** | **看護師資格保持者が夜間を含めて常駐**します |
| **医療連携** | 研修センターのホームドクター（原則24時間対応）および地域の医療機関と連携します |
| **保険** | 参加者全員に傷害保険を付保します |
| **熱中症対策** | 屋外活動は早朝に集中させます。帽子と水筒を必携とし、経口補水液を常備。暑さ指数による中止基準を事前に定めています |
| **水の事故防止** | **泳力を事前にお伺いし、エリアを分けます。** ライフジャケットを用意し、スタッフが水際に配置。入水前後に必ず人数を確認します |
| **火傷の防止** | 野外炊事では帽子・軍手の着用を徹底し、火の取り扱いは指導者の管理下で行います |
| **迷子の防止** | 全員に目印のリストバンドを着用いただきます。集合場所は事前に写真で共有します |
| **食物アレルギー** | 事前にお伺いし、研修センターおよびすべての食事提供先に書面で共有します |

## 9. 危機管理マニュアル

### 事故（ケガ）・病気が発生した場合

```
発生
 ↓
発見者 → 引率スタッフ → 看護担当が対応
 ↓
運営責任者へ連絡
 ↓
┌─ 施設にて手当て
└─ 病院へ同行 → 保護者へご連絡
```

### 迷子が発生した場合

```
発生
 ↓
発見者 → 引率スタッフ → 運営責任者へ連絡
 ↓
捜索班を結成し、直ちに捜索を開始
 ↓
30分経過して未発見の場合
 ↓
警察へ連絡／捜索班を増員／保護者へご連絡
```

### 熱中症の重症度と対応

| 重症度 | 症状 | 対応 |
| --- | --- | --- |
| Ⅰ度（熱けいれん） | めまい、立ちくらみ、筋肉痛 | 涼しい場所で休ませ、水分と塩分を補給 |
| Ⅱ度（熱疲労） | 頭痛、吐き気、倦怠感 | 涼しい場所で冷却。改善しなければ受診 |
| Ⅲ度（熱射病） | 呼びかけに反応がおかしい、けいれん、高体温 | **直ちに救急要請** |

**予防：** 「のどが渇いた」と感じる前に水分を補給します。渇きを感じた時点で、すでに脱水が始まっています。

## 10. 多様な背景への配慮

本キャンプには、さまざまな信仰・食習慣・文化的背景をお持ちのご家庭のお子さまが参加されます。

### 神宮参拝について

会場となる**公益財団法人修養団は、特定の宗教や政党に属さない社会教育団体**です（1906年創立）。

内宮参拝および清掃奉仕は、**日本文化の作法を学ぶ体験**として実施いたします。
一礼や手水の作法は礼儀として全員が学びますが、**何を祈るか、あるいは祈らないかは、お子さまご本人の自由**です。

正宮の前で手を合わせないお子さまがいてよいことを、当日、参加者全員の前で明確にお伝えします。
清掃奉仕は「奉仕」であり、宗教的な行為ではありません。

### お食事について

ハラル・ベジタリアン・ヴィーガン等の対応が可能です。アレルギーとあわせて、事前にお知らせください。
野外炊事やBBQの食材についても、成分まで確認いたします。

### 入浴について

**日本の研修施設では、大浴場で複数人が同時に入浴する習慣があります。**
裸で入浴することに抵抗のあるお子さまには、**個別のシャワー時間**をご用意いたします。事前にお知らせください。

スタッフは着衣のまま脱衣所および浴室入口で見守り、入浴はお子さまのみで行います。

### 礼拝について

礼拝の時間・場所が必要なお子さまには、静かな部屋をご用意いたします。事前にご相談ください。

## 11. 子どもたちの行動のルール

1. キャンプ中は、常に班で行動すること。
2. 班を離れるときは、必ずリーダーに伝えてから離れること。
3. 同じ班の子がけがをしたり、気分が悪くなったりしたら、必ずリーダーや大人に伝えること。
4. リーダーや大人の話をよく聞くこと。
5. 班長は移動のたびに点呼をとり、リーダーに報告すること。
6. 上級生は下級生の面倒をよく見ること。
7. 周りの人やもの、自然に対して「感謝の気持ち」を忘れずに行動すること。
8. 服や布団をたたんだり、履物をそろえたり、「礼儀正しく」行動すること。
9. **バディと、たくさん話すこと。うまく話せなくてもかまいません。**

## 12. 会場のご紹介

**公益財団法人修養団（SYD）伊勢青少年研修センター**
三重県伊勢市宇治今在家町153

修養団は、1906年（明治39年）に東京師範学校（現在の東京学芸大学）の学生たちによって創立され、2011年に内閣総理大臣より公益財団法人の認可を受けた社会教育団体です。2026年に創立120年を迎えました。

**特定の宗教や政党に属することなく**、青少年の健全な育成をはかる教育を行うとともに、「愛と汗」の精神を実践して、世界の福祉と平和に寄与することを目的としています。

伊勢神宮内宮のすぐ近くに位置し、宿泊室・食堂・大講堂・キャンプファイヤー場を備えています。
