# 募集チラシ 構成案

**判型：** A4／両面フルカラー
**部数：** 【要決定】学校配布を行う場合は名古屋市内の対象校数から逆算
**配布：** 学校（後援取得後）、学習塾、スポーツクラブ、インターナショナルスクール、外国人コミュニティ団体、国際交流センター、協賛企業
**言語：** 日本語版／英語版を別々に作る（**1枚に併記しない。情報量が入らない**）

## 裏面

| ブロック | 内容 | 面積比 |
| --- | --- | ---: |
| **① このキャンプで起きること** | 3つの柱を短文で。①礼儀と感謝 ②案内する側に立つ ③合気道 | 25% |
| **② 3日間の流れ** | 簡略化した日程表。写真3〜4点 | 30% |
| **③ 安全への取り組み** | 引率体制・看護担当・保険・毎日の写真配信 | 15% |
| **④ 募集要項** | 対象・定員・参加費・締切・説明会日程 | 15% |
| **⑤ 主催・後援・協賛** | ロゴ列。事務局連絡先。QRコード | 15% |

## 学校配布を狙う場合の注意

**名古屋市教育委員会の後援が取れているかで、扱いが変わる。**

- 後援名義は**決定してから印刷する。** 申請中の段階で刷ると刷り直しになる
- 学校配布用は**営業色を排する。** 協賛企業のロゴを大きく載せると配布を断られることがある。**配布用と一般用で裏面のロゴサイズを変える**版を用意しておくのが安全
- 配布時期は各校の年度計画に左右される。**教育委員会に早めに相談する**

## 英語版で変えること

- 直訳しない。「静座」「奉仕」「ともしびの集い」は説明を添える
- **宗教への配慮の記載を、日本語版より厚くする。** 英語版の読者が最も気にする点
- 大浴場についての説明を入れる
- 参加費に何が含まれるかを明記する（航空券は含まれない旨も）
