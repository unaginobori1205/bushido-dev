## 序章 LINEハーネスとは
ハーネス＝AIやツールを組み合わせ“実際に仕事が回る仕組み”（014）。**LINEハーネス**は、その入口（操作画面・司令塔）をLINEにしたもの。ターミナルやアプリを開かず、**いつものLINEで話しかけるだけ**で裏のAI（Claude/エージェント）が働き、結果がLINEに返る。
**なぜLINE**：一番開くアプリ／スマホ・音声でOK（ターミナル苦手でも・011）／家族・スタッフにも渡せる（014「人の熱を拡張」）。
**大原則**：頼むのは作業。決める・公開OK・責任は人間。AIの返事は下書き。

## 1. 全体像（仕組み）
```
あなた ⇅ LINE公式アカウント ⇅（Webhook）中継役(n8n/Make/サーバー) ⇅ AI(Claude/エージェント) ⇅（MCP・API）ツール(シート/Drive/SNS/カレンダー)
```
3つの流れ：①話しかける(指示) ②AIが働く（015の24時間運用とつながる） ③LINEで返る(報告・成果物・通知)。

## 2. できること
- 指示：「明日の投稿3案」「120字に」「要約して」
- 受け取る：015の完了・失敗通知、今日のSNS素材、KPI報告が自動で届く
- 相談・壁打ち：移動中に音声で
- 承認：「OK」「2番で」「ここ直して」
- みんなで使う：スタッフが返信文を頼む（公開用/社内用は分ける）
- → **015の“報告窓口”をLINEにする**のが最も効果的な第一歩。

## 3. 話しかけ方のコツ
- 文脈を仕組みに持たせる（context.md／015の上流）→ LINEから短く頼んでも“自分らしい”出力。
- 短く頼む→往復で磨く。定型コマンド（投稿/要約/予定/リサーチ）。公開前に必ずOKを取らせる。

## 4. 作り方（3レベル）
- **Lv0 受け取るだけ（今日）**：015のhooks/n8nからLINEに送るだけ。最小・最安・最も安全。`curl -X POST "$LINE_WEBHOOK" -d '{"message":"✅ 明日のSNS素材ができました→（リンク）"}'`
- **Lv1 1コマンド応答**：LINE公式アカウント＋**Messaging API**＋Webhook受け（n8n/Make/サーバー）＋Claude。メッセージ→Webhook→Claude→返信。
- **Lv2 双方向で動かす（司令塔化）**：LINE指示→AIがツール操作（シート追記・SNS下書き・調査）→結果と承認依頼をLINEへ。015と合体。「下書きまで自動・公開は人」。
- ※ チャネル作成・トークン・Webhook URL等の具体手順は LINE Developers の最新で確認。

## 5. 安全に使う
- 流していい情報の線引き（個人情報・機密はLINEに送らない、従業員ガイドライン整合）。
- 公開用アカウントと社内AI操作用を分ける。
- AIの返事は下書き、公開OKは人（001）。
- 裏のAIは015のガードレール（dontAsk＋許可のみ・--max-turns・1日上限）。
- 誤送信・なりすまし注意、鍵・トークンは直書きしない。

## 6. はじめの一歩
今日：015通知をLINEで受け取る（Lv0） → 〜30日：1コマンド応答（Lv1） → 〜60日：context.mdを裏で読ませ自分らしい出力 → 〜90日：015と合体しLINEを司令塔（双方向・承認はLINE）。
