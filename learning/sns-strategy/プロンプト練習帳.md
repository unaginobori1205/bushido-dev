# 🎙️ プロンプト練習帳 — AIに語りかけて学ぶ

このシステムの**中核トレーニング**です。
各章で学んだことを、「**AIに語りかける**」練習を通して身につけます。
読むより、**手を動かして・話しかけて**ください。

> 上達のコツは、上手な質問より「**会話を続けること**」。
> 一発で完璧を狙わず、AIと往復しながら磨いていく。

---

## 0. まずこれだけ：プロンプトの4要素

| # | 要素 | ひとことで | 合言葉 |
| --- | --- | --- | --- |
| ① | 役割 | AIに立場を与える | 「あなたは○○です」 |
| ② | 前提 | 背景・条件を渡す | 「私は○○で、相手は○○」 |
| ③ | 指示 | やってほしいこと | 「○○して」 |
| ④ | 形式 | 出力の形 | 「○字で・箇条書きで」 |

迷ったら、この4つを上から順に埋めるだけ。

---

## レベル1：語りかけてみる（ウォームアップ）

AIは「**優秀だが、たまに嘘をつく新人**」。まずは気軽に話しかけて、感触をつかみます。

**やってみる①**
```
SNS初心者の経営者に、「保存される投稿」とは何かを、
たとえ話を使って、小学生にもわかるように説明して。
```

**やってみる②（深掘りの練習）**
①の答えに、続けてこう返す：
```
なるほど。では、私の事業（［自由に記入］）の場合、
「保存される投稿」の具体例を3つ出して。
```

👉 **学び**：1回で終わらせず「**で、私の場合は？**」と返すと、急に自分ごとになる。

---

## レベル2：4要素で組み立てる

同じお願いを「雑」と「4要素」で投げて、違いを体感します。

**Before（雑）**
```
うちの宣伝文を書いて。
```

**After（4要素）**
```
①役割：あなたはプロのコピーライターです。
②前提：私は［事業］を営み、届けたい相手は［具体的な人物像］です。
③指示：その人の心が動く宣伝文を3案つくってください。
④形式：各案80字以内・絵文字なし・最後に各案の狙いを1行。
```

仕上げにAIへ：
```
Before と After、出力の差を解説して。
私のプロンプトを、さらに良くする1つの改善案を教えて。
```

## レベル3：AIを"自分の先生"にする（語りかけ学習の本番）

ここがこのシステムの肝です。AIを**家庭教師・壁打ち相手**にして、章の内容を会話で定着させます。

### 3-A 家庭教師プロンプト（どの章でも使える）
```
あなたは、私専属の「AI×SNS」家庭教師です。
今日のテーマは「［章のタイトルを記入。例：発見→信頼→蓄積］」。

進め方：
1. まず、このテーマを3行で簡単に教えてください。
2. 次に、私に理解度を試す質問を1問ずつ出してください（一度に1問）。
3. 私の答えに、◎/△/✕ と短いフィードバックを返してください。
4. 3問終わったら、私の弱点をまとめ、復習用の一言をください。

では、3行の説明からお願いします。
```

### 3-B 壁打ちプロンプト（自分の考えをぶつける）
```
あなたは率直な壁打ち相手です。私のSNSのアイデアに、
賛成ではなく「もっと良くする質問」を返してください。
私のアイデア：「［　　　］」
まず、私が見落としていそうな点を3つ質問してください。
```

### 3-C ロールプレイ（お客さん役になってもらう）
```
あなたは、私の理想のお客さん（［人物像を記入］）です。
私がこれから投稿文を読み上げます。それを聞いて、
「保存する／しない」と、その理由を本音で答えてください。
では投稿文です：「［　　　］」
```

## レベル4：AIの"嘘"を見抜く練習

AIは事実を間違える（ハルシネーション）。**鵜呑みにしない筋肉**を鍛えます。

```
SNSマーケティングについて、もっともらしいけれど
「実は間違っている説」を3つ作ってください。
そのあと、それぞれのどこが間違いかを解説してください。
```

👉 **学び**：AIの出力は**たたき台**。「本当？」「出典は？」「私の業界でも同じ？」と一度疑う。

## マイ・プロンプト集（自分の財産を貯める）

うまく書けた・よく効いたプロンプトを、ここに追記して育てていきましょう。

### テンプレ
```
【用途】　例：保存される投稿文づくり
【プロンプト】
（ここに貼る）
【メモ】　どこを直すと効いたか
```

---

### 例）投稿文3案
```
【用途】保存される投稿文を3案つくる
【プロンプト】
①役割：あなたはプロのSNS編集者です。
②前提：私は［事業］、届けたい相手は［人物像］。
③指示：その人が保存したくなる投稿文を切り口を変えて3案。
④形式：各120字・絵文字なし・各案に狙いを1行。
【メモ】「切り口を変えて」を入れると似た案にならない。
```
