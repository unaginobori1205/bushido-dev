# SNS戦略部会 学習システム

JCI NAGOYA SNS戦略部会の共有資料（講師：上岡賢輔）を、**自分のペースで・AIと会話しながら**身につけるための自習システムです。

> 事業やサービスとは、「愛（思い）」を人から人へ届けること。
> SNSとAIは、そのための強力な"道具"にすぎない。

---

## このシステムの考え方

ただ資料を読むだけでは身につきません。
**このシステムの主役は「AIとの会話」と「プロンプトの練習」**です。

各章には、

1. 📌 **要点** … 共有資料のエッセンス（読むパート）
2. 🎙️ **AIに語りかける練習** … そのままコピペして ChatGPT / Claude / Gemini に貼る対話プロンプト。AIがあなたの先生・壁打ち相手になります
3. ✍️ **自分で書く課題** … 自分の事業に当てはめてプロンプトを書く練習

の3つがセットになっています。

**読む → AIに語りかける → 自分で書く** を回すことで、知識とプロンプト力が同時に育ちます。

> 🌐 **ブラウザで使いたい方へ**：[index.html](./index.html) を開くと、全章＋練習ページにボタンで飛べます。
> プロンプトを**コピーボタンでコピーして AI に貼る**なら [practice.html](./practice.html)（プロンプト練習ページ）がおすすめ。スマホでも動きます。

---

## 学習ループ（毎回これを回す）

```
 ① 学ぶ        章の「要点」を読む
    ↓
 ② 語りかける   「AIに語りかける練習」をコピペしてAIと会話する
    ↓
 ③ 書く        「自分で書く課題」に取り組み、自分のプロンプトを作る
    ↓
 ④ もらう       AIにフィードバックを求める（後述の魔法の一言）
    ↓
 ⑤ 振り返る     学んだこと・気づきを1行メモして次へ
```

### ④で使える「魔法の一言」

AIとの会話で行き詰まったら、これを足すだけで学びが深まります。

- 「**初心者にもわかるように、たとえ話で説明して。**」
- 「**今の私のプロンプトを、もっと良くするには？ 具体的に直して。**」
- 「**私の事業（◯◯）の場合だと、どうなる？**」
- 「**質問を1つずつ私に投げかけながら、一緒に考えて。**」

## 進め方のコツ

- **1日1章** で十分。詰め込まない。SNSと同じで「継続が9割」。
- AIの答えは**たたき台**。丸ごと信じず、必ず自分の言葉に直す。
- うまく書けたプロンプトは [プロンプト練習帳.md](./プロンプト練習帳.md) の「マイ・プロンプト集」に貯めていく。
