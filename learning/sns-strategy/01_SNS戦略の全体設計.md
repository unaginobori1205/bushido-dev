# 01 SNS戦略の全体設計

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

### なぜ今、経営者が「AI×SNS」なのか
- **SNSの主戦場が変わった**：TikTok / リールの「発見タブ」は、フォロワー数に関係なく届く。無名の会社でも、良いコンテンツならいきなり数万人に届く。＝中小・地域事業者に過去最大のチャンス。
- **AIが変えたこと**：制作コストと属人性の壁を解消。AIの本質的価値は「速さ」より「**継続を可能にすること**」。SNSは**継続が9割**。

### 目的から逆算する
1アカウントに目的を詰め込みすぎない。目的ごとに媒体を選ぶ。

| 目的 | 向く媒体 |
| --- | --- |
| 認知（知ってもらう） | TikTok |
| 信頼（好きになってもらう） | Instagram |
| 集客 | Instagram・YouTube |
| 採用・組織化 | 文字SNS 等 |

### 基本戦略：発見 → 信頼 → 蓄積
```
TikTok（発見） → Instagram（信頼） → YouTube Shorts（蓄積）
```
1本のコンテンツを3媒体に展開する＝**ワンソース・マルチユース**。

### 役割分担
全13アカウントを6役割に整理（①本人の思想・信用 ②事業導線 ③商品販売 ④地域店舗集客 ⑤福祉の信頼形成 ⑥機運醸成・仲間集め）。
- **本人主導は4アカウントに集中**、残りは**スタッフ＋AI**。
- 「全部を本人がやる」をやめるのが、続く仕組みの第一歩。

### KPI（最初の3ヶ月は"中間指標"を見る）
- 入口：再生数・視聴維持率
- 中間：**保存・プロフィール来訪** ← 最初はここを見る
- 成果：DM・問い合わせ・売上

## 🎙️ AIに語りかける練習（コピペ用）

```
あなたは、SNS戦略の設計を手伝うコンサルタントです。
私の事業のSNS戦略を「発見→信頼→蓄積」の型で一緒に設計してください。

進め方：
- まず私に「事業内容」「届けたい相手」「今あるSNS」を1つずつ質問する。
- 私の答えをもとに、(1) 主戦場にすべき媒体を1つ、(2) その理由、
  (3) 最初の30日でやることを3つ、提案する。
- 専門用語には必ず短い説明をつける。

では、最初の質問からお願いします。
```

理解度チェック（会話の最後にAIへ）：
「**『発見→信頼→蓄積』を、私の事業の例で具体的に説明して。私の理解が合っているか確認したいので、わざと1か所まちがえた説明も混ぜて、クイズにして。**」

## ✍️ 自分で書く課題

1. 私の事業で、**いちばん最初に力を入れる目的**はどれ？（認知／信頼／集客／採用）
2. その目的に**いちばん向く媒体**は？　なぜ？
3. 最初の3ヶ月、私が毎週見る**中間指標**を1つ決める（例：保存数）。

AIに貼って：
「**この3つの答えをもとに、私のSNS戦略を"1枚の設計図"として箇条書きでまとめて。**」
