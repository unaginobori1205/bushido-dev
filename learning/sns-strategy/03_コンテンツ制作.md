# 03 AIでコンテンツを作る

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

### 投稿文
- テーマとターゲットを伝え「**保存される切り口で3案**」→ 気に入った案を微調整。
- AIの出力を**丸ごとコピペするのは禁物**。必ず自分の言葉に直す。

### 台本
- ショート動画は**最初の2秒（フック）が9割**。

### 画像・動画・音声
- 画像：ChatGPTの画像生成（Image 2）
- 動画：Seedance（AIアニメも可）。音声はオフにして、BGMは CapCut で後乗せ。

### トンマナ（トーン&マナー）を固定する
- **ブランド設定シート**を作り、毎回プロンプトに貼る。
- 「**やらないこと**」を明文化する（例：誇大表現しない／お涙頂戴にしない）。

### 【保存版】最高品質の15秒ショートの作り方
1. **設計**：15秒＝フック2秒／本編10秒／締め3秒。**1本＝1メッセージ**。
2. **台本**：フックを**AIに20案**出させて、いちばん刺さる1つを選ぶ。
3. **映像**：ChatGPT（Image 2）→ Seedance。縦 9:16。
4. **仕上げ**：CapCut。視聴者の8〜9割は無音で見る → **字幕は必須**。BGMは後乗せ。
5. **原則**：最初の数本は捨て筋でOK。**伸びたフックの型をAIに学習させて量産**する。

## 🎙️ AIに語りかける練習（コピペ用）

### 練習A：保存される投稿文を3案
```
①役割：あなたはプロのSNS編集者です。
②前提：私の事業は［　　　］、届けたい相手は［　　　］。
③指示：その人が思わず「保存」したくなる投稿文を、切り口を変えて3案ください。
④形式：各案120字以内・日本語・絵文字なし。各案に「狙い」を1行添える。
作ったあと、私に1つずつ「ここは響く／弱い」を聞きながら一緒に磨いてください。
```

### 練習B：15秒ショートのフックを20案
```
あなたはバズるショート動画の構成作家です。
テーマは「［　　　］」。最初の2秒で指が止まる「フック（最初の一言）」を20案ください。
・各案15文字以内
・煽りすぎ／誇大表現はNG
20案出したら、あなたのおすすめトップ3と、その理由を教えてください。
```

最後にAIへ：
「**選んだフックから、15秒台本（フック2秒・本編10秒・締め3秒）に展開して。字幕用に話し言葉で。**」

---

## ✍️ 自分で書く課題

1. 自分の事業の「**ブランド設定シート**」を3行で作る：
   - キャラ／トーン（例：丁寧・誠実・押し売りしない）
   - 使う言葉・使わない言葉
   - **やらないこと**（明文化）
2. それをプロンプトに貼って、投稿文を3案つくる。

AIに貼って：
「**このブランド設定を守って投稿文を3案。設定から外れている箇所があれば自分で指摘して直して。**」
