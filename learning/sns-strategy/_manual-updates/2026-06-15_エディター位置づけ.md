## 平文版（スライド／口頭でそのまま使える）

- **結論：多くの会員は Claude Code だけで十分。** 投稿文・台本・動画・資料・調べもの・軽い自動化は、ターミナルで日本語で頼むだけで完結する。
- **エディターが効くのは2層だけ：**
  1. Web・アプリを“見ながら”作る人（プレビュー→修正が速い）
  2. ターミナルが“怖い”初心者（GUIの方が安心、という心理的ハードルの解消）
- **部会の方針：** §003 Claude Code を主役に。§011 エディターは「Claude Code が物足りなくなったら開く任意の発展編」と明記し、全員には勧めない。
