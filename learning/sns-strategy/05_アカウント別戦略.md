# 05 アカウント別 戦略実例 ― 6役割の設計図

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

役割ごとに「ねらい」と「コンテンツの方向性」が変わります。自社に当てはめる際の見本にしてください。

### 5-1. 本人ブランド（思想・信用）
- **ねらい**：経営者個人の信頼を資産化。事業全体の“のれん”になる。
- **方向性**：考え方・価値観・舞台裏。きれいごとでなく一次情報を語る。

### 5-2. 商品販売（EC・物販）
- **ねらい**：EC・物販の売上に直結させる。
- **方向性**：商品の魅力を“使うシーン”で見せる。専門性の高い商材はニッチ深掘りで濃いファンを作る。

### 5-3. 地域店舗集客（実店舗・多店舗）
- **ねらい**：商圏内の来店。広告費の代替。
- **方向性**：店舗ごとにアカウントを分け、地域名×日常の困りごと解決で発見される。スタッフ運用＋AIで省力化。

### 5-4. 福祉の信頼形成
- **ねらい**：安心感と共感。関係者・家族の信頼。
- **方向性**：AIアニメで配慮しつつ温度を伝える（第4章の自動化実例）。誇大・お涙頂戴を避ける節度が信頼を生む。

### 5-5. 機運醸成・仲間集め（イベント・地域プロジェクト）
- **ねらい**：イベント集客とコミュニティ形成。仲間と参加者を集める。
- **方向性**：開催日に向けた短期集中で投稿し、機運を高める。熱量とストーリー（なぜやるのか）で巻き込む。
- **実例**：文字主体のThreadsで参加者を募集。短い言葉で“なぜやるのか”という思いを語り、コメント・リポストで仲間を増やす。告知・募集・コミュニティづくりはThreads／X／LINEなど「文字の場」が効く（動画SNSと役割が違う）。

> **共通する学び**：すべて同じ「発見 → 信頼 → 蓄積」の型。違うのは“誰に・何を・どんなトーンで”だけ。型を持てば横展開できる。

### 媒体の使い分けのコツ
- 映像で見せたい（商品・体験・温度感）→ TikTok / Instagram / YouTube Shorts
- **人を集めたい・告知したい** → Threads / X / LINE（文字SNS）

## 🎙️ AIに語りかける練習（コピペ用）

```
あなたは、事業の特徴からSNSの「切り口」を見つける専門家です。
私の事業を、以下の6役割のどれに当てはめるのがいちばん良いか一緒に考えてください。
①本人ブランド ②商品販売 ③地域店舗集客 ④福祉の信頼形成 ⑤機運醸成・仲間集め

進め方：
- 私に事業内容を質問する。
- 役割を1つ提案し、その役割で「効く切り口」を3つ挙げる。
- それぞれの切り口で、投稿テーマの例を1つずつ出す。

では質問からお願いします。
```

最後にAIへ：
「**私の商品の『使うシーン』を10個ブレストして。そこから投稿になりそうなニッチを3つ選んで。**」

---

## ✍️ 自分で書く課題

1. 自分の事業は**どの役割**に近い？（複数でもOK）
2. その役割で**効く切り口**を、自分の言葉で3つ書く。
3. 切り口ごとに**投稿テーマ**を1つずつ。

AIに貼って：
「**この切り口とテーマ、ターゲットに刺さりそう？　弱いものは理由つきで指摘して、代案を出して。**」
