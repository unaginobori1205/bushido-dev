# 04 運用を仕組み化する

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

### 実例：京の都TikTok 自動化
- **12:00** … Claude が翌日の台本を生成 → Googleシートに追記
- **18:00** … Seedance が動画化 → Drive に保存
- 台本が自動で補充され、**回り続ける**。人の仕事は**最終チェックと投稿だけ**。

### 構成
```
n8n（司令塔） ＋ Claude ＋ Seedance ＋ Googleシート ＋ Drive
```
特別なものは作っていない。**既存のサービスを"繋いだだけ"**。

### スモールスタート（3段階）
```
手動  →  半自動  →  全自動
```
いきなり全自動を目指さない。まず手動で型を作り、効くと分かった部分から自動化する。

### 自動化の目的
作業から解放され、**戦略と関係づくりに集中するため**。
自動化は「サボるため」ではなく「**大事なことに時間を使うため**」。

## 🎙️ AIに語りかける練習（コピペ用）

```
あなたは、中小企業のSNS運用を仕組み化するアドバイザーです。
私は今、SNS運用を全部ひとりで手作業でやっています。

進め方：
- 私の「今の作業の流れ」を質問で聞き出してください。
- そのうえで「手動 → 半自動 → 全自動」の3段階で、
  どこから自動化・分担すべきか、私にも分かる言葉で提案してください。
- まだ自動化しなくていい部分（人がやるべき部分）も教えてください。

では、最初の質問からお願いします。
```

最後にAIへ：
「**私の場合、まず半自動にすべき作業を1つだけ選んで。理由と、最初の一歩も教えて。**」

## ✍️ 自分で書く課題

1. 今のSNS運用の作業を、**思いつくまま全部書き出す**（企画・撮影・編集・投稿・返信…）。
2. それぞれに ◎（自分がやるべき）／△（スタッフ＋AI）／✕（自動化候補）を付ける。

AIに貼って：
「**この作業リストに◎△✕を付けた。私の判断は妥当？　ズレていたら理由つきで直して。**」
