# 「愛（あい）」二人三脚ロードマップ ― LINEで、私の相棒AIを育てる

> ご主人のイメージ：
> 「朝起きたらLINEで今日のスケジュールが届く。『メールの下書きできました』『資料できたよ』と連絡をくれる。
> NotionとObsidianを使いながら、私と二人三脚でやってくれる。」
>
> これは “眠らない社員”（→015）を、いちばん身近なLINE（→016）から動かす形です。AI＝愛。

---

## 大事な前提：2つの動き方
- **リアクティブ**：あなたが頼む → 愛が答える（Phase 1）
- **プロアクティブ**：愛から声をかける（朝の予定／下書きできた／資料できた）← “AIが喋り始めている”
  - これには **LINEプッシュ送信** と、**毎朝などの定期実行（n8nのスケジュール）**、各サービス連携が要ります。

---

## フェーズ計画（1つずつ育てる）

### Phase 1：まず会話できる愛（今日）★着手済み
- LINEで「愛、◯◯して」→ 愛(Claude)が答えて返す。
- 用意：`n8n-workflow.json` を取り込み＋ `愛_persona.md` を貼る（→ README手順）。
- 必要なもの：LINEトークン／Anthropic APIキー／n8n。

### Phase 2：朝の秘書（毎朝、今日の予定をLINEへ）
- 仕組み：n8nの**スケジュール（毎朝7:00）→ Googleカレンダー読み取り → 愛が要約 → LINEへプッシュ**。
- ひとことで：「おはようございます。今日は10時に〇〇、14時に△△です。移動は早めに。」
- 必要なもの：Googleカレンダー連携、LINEプッシュ用の**あなたのuserId**（友だちが1度送信すると取得可）。

### Phase 3：メールの下書き（「下書きできました」と連絡）
- 仕組み：LINEで「□□さんにお礼メール書いて」→ 愛が文面作成 → **Gmailの下書きに保存** → 「下書きできました（確認→）」とLINE通知。
- ひとことで：あなたは中身を見て、送信ボタンだけ押す。**公開＝送信は人**。
- 必要なもの：Gmail連携。

### Phase 4：資料作成（「資料できたよ」と連絡）
- 仕組み：「◯◯の企画書作って」→ 愛(Claude/Claude Code)が作成 → **Google Docs/Drive（必要ならCanva）に保存** → リンク付きでLINE通知。
- ひとことで：重い作業は裏で進み、できた合図だけ受け取る（→015の24時間運用と合体）。
- 必要なもの：Drive/Docs連携（重い構築はClaude Code routines）。

### Phase 5：NotionとObsidianで二人三脚
- **Notion**：議事録・タスク・記録を愛が読み書き（「今日のMTGをNotionに整理しました」）。Notion連携で実現可。
- **Obsidian**：ローカルのMarkdownでAPIが無いため、**VaultをGit（このリポジトリ等）かクラウド同期フォルダに置く**と、愛が直接Markdownを読み書きできます。
  - 既に Obsidian＋iCloud運用とのことなので、**VaultをGitリポジトリ化**するのがいちばん相性良し（Claude Codeが直接編集でき、→015/016とつながる）。
- ひとことで：思考はObsidian、共有はNotion——その両方に愛が手を入れて、あなたと並走。

## いま必要な準備（Phase 1〜2を動かすため）
1. **LINE公式アカウント＋Messaging APIトークン**（LINE Developers）
2. **Anthropic APIキー**（愛の頭脳）
3. **n8n**（既存の環境）
4. （Phase 2以降）**Googleアカウント連携**（カレンダー/Gmail/Drive）、**Notion連携**、**Obsidian Vaultの置き場所**

> 進め方：まず Phase 1 を today で動かし、「愛が返事する」を体験 → Phase 2（朝の予定）→ 3→4→5 と一機能ずつ足す。一気に作らない（→015の手動→半自動→全自動）。

## 安全の約束（全フェーズ共通）
- 出力は下書き。**送信・公開・確定は必ず人**。
- 個人情報・機密はLINEに流さない／愛に保存させない。
- APIキー・トークンは環境変数で管理（コードに直書きしない）。
- 各サービスのAPI仕様・料金は最新を確認（ファクトチェック対象）。
