# 06 はじめの一歩（90日アクションプラン）

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

### 今日やること
- 目的を**1つ**に決める
- 主戦場（媒体）を**1つ**に決める
- ChatGPT で**投稿文を1本**つくる

### 〜30日
- **ブランド設定シート**を作る
- **週3本**投稿する

### 〜60日
- 勝ちパターン（伸びたフックの型）を**AIで量産**する

### 〜90日
- 1本 → 3媒体の**横展開（ワンソース・マルチユース）**
- **自動化**を検討する

### やってはいけないこと
- 戦略なしの量産
- 無検証の投稿
- 誇大・お涙頂戴
- **本人が全部やる**
- フォロワー数だけを追う

> 最後に：事業とは愛を人から人へ届けること。決めるのは経営者。
> SNS・AIはその思いを遠くへ運ぶ道具。**道具に使われず、道具を使う。**

---

## 🎙️ AIに語りかける練習（コピペ用）

```
あなたは、私の90日SNSチャレンジの伴走コーチです。
これまでに私が決めた「目的」「主戦場」「届けたい相手」をもとに、
今日・30日・60日・90日でやることを、私専用のアクションプランにしてください。

条件：
- 各期間の「やること」は3つまで。多すぎないように。
- 「やってはいけないこと」も私の事業に合わせて3つ挙げる。
- 最後に「今日この瞬間にやる1アクション」を1つだけ指定する。

まず、私の目的・主戦場・届けたい相手を質問してください。
```

毎週の振り返りにも使えます：
「**今週やったことを報告します（…）。90日プランに対して順調？　来週の3つを決めて。**」

## ✍️ 自分で書く課題（修了課題）

これまでの全章をまとめ、**自分のSNS設計図を1枚**にします。

```
・思い（誰に・何を・なぜ）：
・目的（1つ）：
・主戦場（1媒体）：
・役割／切り口：
・週の投稿本数：
・見る中間指標：
・やらないこと：
・今日やる1アクション：
```

AIに貼って：
「**この設計図、抜けや矛盾はない？　経営者目線でツッコミを入れて、完成度を上げて。最後に、これを実行する私への一言メッセージを。**」
