# 00 マインドセット — 事業の出発点は、いつも愛

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

僕たちはつい、こう考え始めてしまいます。

- 「どのSNSを使えばいいか」
- 「AIで何ができるか」
- 「どうやったら売れるか」

でも、本当に大切なのはそこではありません。
**事業の出発点は、いつも愛（思い）です。**

- 誰かを喜ばせたい
- 誰かの困りごとを解決したい
- 誰かの人生を少しでも明るくしたい

その思いが、商品になり、サービスになり、ブランドになります。
SNSやAIは、その思いをより多くの人へ届けるための**道具**にすぎません。

```
思いがあるから、言葉が生まれる。
言葉があるから、発信が届く。
発信が届くから、人が動く。
```

**一言でいうと** … 事業とは、愛（思い）を人から人へ届けること。SNSとAIは、そのための"道具"にすぎない。

### 使いどころ
- 道具（SNS・AI・ツール）の話の前に、「**誰に・何を・なぜ**届けたいか」を言語化する。
- 迷ったらここに戻る：**思いが先、道具は後。**

---

## 🎙️ AIに語りかける練習（コピペ用）

以下をそのままAIに貼って、会話を始めてください。AIがあなたの「思い」を引き出すコーチになります。

```
あなたは、私の事業の「思い」を言語化してくれる対話コーチです。
私はSNSやAIを使う前に、まず「誰に・何を・なぜ届けたいか」を
はっきりさせたいです。

ルール：
- 一度にたくさん聞かず、質問を1つずつ投げかけてください。
- 私の答えを受けて、深掘りの質問を返してください。
- 最後に、私の「思い」を3行のメッセージにまとめてください。

では、最初の質問からお願いします。
```

会話が終わったら、AIにこう頼んでみましょう。
「**この思いを、SNSのプロフィール文（120字）にしてみて。**」

---

## ✍️ 自分で書く課題

ノートやメモ帳に、自分の言葉で埋めてみましょう（AIに添削してもらってOK）。

1. 私が**いちばん喜ばせたい人**は誰？（できるだけ具体的に：年齢・状況・悩み）
2. その人の**どんな困りごと**を解決したい？
3. なぜ私が？　**私だからできる理由**は？

書けたら、AIに貼ってこう聞く：
「**この3つから、私の事業の"思い"を一文にまとめて。そのうえで、SNSで最初に発信すべきテーマを3つ提案して。**」
