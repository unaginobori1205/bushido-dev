# 02 生成AIの基礎（ツール地図とプロンプト4要素）

> 学習ループ：**学ぶ → 語りかける → 書く → もらう → 振り返る**

---

## 📌 要点

### ツール地図
| 種類 | できること | 代表ツール |
| --- | --- | --- |
| 文章 | 投稿文・台本・企画・要約 | ChatGPT / Claude / Gemini |
| 画像 | サムネ・バナー・イラスト | ChatGPT（Image 2）/ Canva AI / Midjourney |
| 動画 | ショート・アニメ生成 | Seedance / Runway / Sora |
| 音声 | ナレーション・BGM | ElevenLabs / Suno |
| 自動化 | ツール連携で自動運用 | n8n / Zapier / Make |
| 資料・要約 | 要約・プレゼン資料・漫画化 | NotebookLM |

### AIの得意・不得意
- **得意**：たたき台づくり・反復・文体の模倣
- **苦手**：事実の正確さ（**ハルシネーション＝もっともらしい嘘**）・最新情報・自社固有の文脈・責任を取ること

### 黄金ルール
> AIは「**優秀だが、たまに嘘をつく新人**」。出力は必ず人間が確認する。

### プロンプトの4要素（これが全章の土台）
| # | 要素 | 中身 | 例 |
| --- | --- | --- | --- |
| ① | **役割** | AIに立場を与える | 「あなたはプロのSNS編集者です」 |
| ② | **前提** | 背景・条件を渡す | 「うなぎ専門店。客は40代男性…」 |
| ③ | **指示** | やってほしいこと | 「保存される投稿文を3案」 |
| ④ | **形式** | 出力の形 | 「各案120字／絵文字なし」 |

＋ コツ：**例を示す**／**ペルソナ（誰向けか）を毎回貼る**。

---

## 🎙️ AIに語りかける練習（コピペ用）

まずは「4要素を意識せず」雑にお願いし、次に「4要素で」お願いして、違いを体感します。

**ステップ1（わざと雑に）**
```
うちのSNSの投稿文を考えて。
```

**ステップ2（4要素入り）**
```
①役割：あなたはプロのSNS編集者です。
②前提：私は［あなたの事業を書く］を営んでいて、届けたい相手は［例：◯◯で悩む30代女性］です。
③指示：その人が「保存したくなる」投稿文を3案つくってください。
④形式：各案120字以内・日本語・絵文字は使わない。最後に各案の狙いも1行で。
```

最後にAIへ：
「**ステップ1とステップ2、出力の質はどう変わった？　4要素のうち、どれがいちばん効いたか解説して。**」

## ✍️ 自分で書く課題

下のテンプレを、自分の事業で埋めてみましょう。

```
①役割：あなたは____です。
②前提：私は____。届けたい相手は____。
③指示：____してください。
④形式：____。
```

AIに貼って：
「**このプロンプト、4要素として過不足ない？　足りない情報を質問で補ってから、改良版プロンプトを書いて。**」
