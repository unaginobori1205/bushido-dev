なぜSNSなのか — 目的から始める

やり方の前に「目的」を決める。目的なき配信は続きません（JCの議案と同じで“背景と目的”が命）。

理念なぜやる
→
目的何のために
→
ゴール成功の状態
→
誰のために届ける相手
→
なぜ自社独自の理由
  • やらないとどうなるか：知られない＝選ばれない。発信しない会社・活動は「無い」のと同じ。
  • 誰のために価値を提供するのか：フォロワー数ではなく「誰の・どんな悩みに・どんな価値を」。
  • なぜ自社（自分）なのか：他でもない自分が発信する理由＝独自の想い・経験・強み＝共感の源。
WHY自社の「発信コンセプト」を言語化する
私（自社）のSNS発信の軸を一緒に言語化してください。次の順で1つずつ質問し、私の答えをもとに整理してください。
1. 理念：なぜ発信するのか（根っこの想い）
2. 目的：何のために（事業・採用・仲間づくり 等）
3. ゴール：どうなったら成功か（数値や状態）
4. 誰のために：届けたい相手は誰で、どんな悩みを持っているか
5. 提供価値：その人にどんな価値を届けるか
6. なぜ自分か：他でもない自分・自社が発信する理由（独自の経験・強み）
最後に、以上を2〜3行の「発信コンセプト」にまとめてください。

実演1：担当例会をSNS投稿化する

例会情報を入れるだけで、投稿文・リール台本・ハッシュタグ・撮影指示までが一気にそろう。広報で一番大変な「何をどう伝えるか」をAIがたたき台に。

実演1担当例会をSNS広報セットに一括変換
あなたはJCの広報に強い編集者です。次の例会情報をもとに、SNS広報セットを一式作ってください。
【例会情報】（日時・会場・テーマ・登壇者・狙いを貼る）
出力：
1. SNS投稿文（Instagram用・共感から入る本文）
2. ストーリーズ用の短文（3枚分）
3. リール用ナレーション（30秒）
4. 告知タイトル案を3つ
5. ハッシュタグ10個
6. 「参加したくなる一言」
7. 委員会メンバーへの依頼文（撮影・拡散のお願い）
8. 当日の写真・動画の撮影指示リスト
※日付・会場・登壇者名は変えず、想いが伝わる温度感で。

実演2：画像・動画生成プロンプト

必要なのはデザイン技術より“世界観を言語化する力”。まず「何を感じてほしいか」を1行で決めてから。

実演2画像・動画生成プロンプトを作る
次の例会／事業のテーマから、SNS用ビジュアルの素材プロンプトを作ってください。
テーマ：（例）7月例会「〇〇」／対象：地域の若手経営者
出力：
1. 告知画像のイメージ案（雰囲気・色・構図を言葉で）3案
2. リール動画の構成（0-5秒／5-10秒／10-15秒）
3. 15秒ショート動画の台本（ナレーション＋テロップ）
4. 9:16縦型動画の生成プロンプト（日本語）
5. 上記の英語プロンプト版（画像生成AI用）
※最初に「何を伝えたいか（世界観）」を1行で言語化してから作ること。

実演3：AI秘書・スキル・自分専用のAIチーム

SNSだけでなく、日々の業務やJC活動全体に。よく使うものは“型”にすると、個人のスキルが組織の資産になります。Claude Codeなら役割別のAIチームも作れます。

実演3・秘書朝の“今日の動き方”を整理
あなたは私専属のAI秘書です。次の情報から「今日の動き方」を整理してください。
【入力】今日の予定／未読の連絡／抱えているタスク／JC関連の締切（箇条書きで貼る）
出力：
1. 今日やるべきこと（優先順位つき）
2. 返信すべき連絡と、その返信案
3. 今日のSNS投稿の確認事項
4. 昨日からの持ち越し
5. 今日の注意点（抜け漏れ防止）
6. 誰に何を連絡すべきか
実演3・議事録議事録からToDoと連絡事項を抽出
次の議事録から、ToDoと連絡事項を抜き出してください。
【議事録】（貼る）
出力：
1. ToDo（担当・期限つき）
2. 決定事項
3. 保留・要確認事項
4. 誰に何を連絡するか（連絡文の案つき）
実演3・AIチーム投稿作成エージェントを作る（/agents → Generate with Claude）
SNS投稿を作る専門エージェントを作って。
役割：渡されたネタメモから、Instagram・X・Facebookの3媒体ぶんの投稿文を作る。
ルール：
- 家族目線のやさしい言葉。宣伝くさくしない
- 媒体ごとの作法に合わせる（インスタ＝共感＋ハッシュタグ／X＝短く／FB＝丁寧）
- 個人情報・機密は書かない
使うツール：ファイルの読み書きのみ（最小限）
実演3・AIチームAIチームに今週のSNSを回させる（一括指示）
今週のSNSを回して。次の順で進めて、最後にまとめて。
1. ネタ収集エージェント：今週の話題・写真メモから投稿ネタを3つ出す
2. 投稿作成エージェント：3媒体×各2本の投稿文を作る
3. 校正・炎上チェックエージェント：誤字と炎上しそうな表現を点検して直す
最後に、月〜日の投稿カレンダー（曜日／媒体／本文）にまとめて。
!

AIを使うときの注意点

  • 個人情報・機密情報・未公開情報をそのまま入れない
  • AIの文章をそのまま使わず、最後は人が確認する
  • 日付・会場・金額・登壇者名は必ず自分で確認する
  • 事実と想いを分けて扱う／AIは補佐役、最終責任者ではない
ひとこと：AIを使うほど、人間の確認力と判断力が大切になります。
