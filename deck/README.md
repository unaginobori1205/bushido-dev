## 写真の差し替え

ネットワーク制限により実写を取得できなかったため、3か所を差し替え用の枠にしています。
PowerPoint で枠を右クリック →「図の変更」で入れ替えてください。

| ページ | 位置 | 推奨する写真 | 推奨アスペクト |
| --- | --- | --- | --- |
| 2. 自己紹介 | 左 | ご本人のポートレート | 縦 4:5 |
| 4. 会社概要 | 右 | 活動風景・道場など | 正方形 1:1 |
| 6. 弓道体験 | 右半面 | 弓を引くゲストの様子 | 縦 5:6 |

差し替え後は各枠下の「※〜差し替え」注記を削除してください。

## 再生成

```bash
npm install pptxgenjs sharp
node gen_assets.js   # 背景・円相・写真枠を生成
node build.js        # pptx を出力
```
