# 弓道体験 申込フォーム自動作成スクリプト

BUSHIDO JAPAN「名古屋で本格弓道体験」の申込フォームを、Google Apps Script で自動生成するためのコードです。
日本語・英語併記のフォームと、回答集計用スプレッドシートを作成し、送信後に日程条件を自動チェックします。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `Code.gs` | フォーム作成・送信後チェックの本体コード |

## 主な機能

- 日本語・英語併記の申込フォームを自動生成
- 回答集計用スプレッドシートを自動作成し、フォームと連携
- メールアドレス／参加人数（1〜20）の入力バリデーション
- 希望日程（第1希望・第2希望）の入力欄
- 送信後トリガーで以下を自動チェック
  - 希望日が本日から **2週間以上先（`minDaysAhead = 14`）** か
  - 第1希望日と第2希望日が **別日** か
- 条件を満たさない場合は、管理者と申込者の双方へ確認メールを自動送信
- 条件を満たす場合は、管理者へ新規申込通知、申込者へ受付完了メールを自動送信

## 使い方

1. [Google ドライブ](https://drive.google.com/) で Apps Script プロジェクトを新規作成
2. `Code.gs` の内容を貼り付け
3. `createKyudoApplicationForm()` を実行
4. 初回実行時に表示される権限リクエストを許可
5. 実行ログ（または `ownerEmail` 宛のメール）に出力される **申込フォームURL** を使用

実行すると、Apps Script の実行ログに次の3つのURLが出力されます。

- フォーム編集URL
- 申込フォームURL（公開用）
- 回答スプレッドシートURL

同じ内容は `CONFIG.ownerEmail` 宛にメールでも送信されます。

## 設定（CONFIG）

`Code.gs` 冒頭の `CONFIG` で各種設定を変更できます。

| キー | 既定値 | 説明 |
| --- | --- | --- |
| `ownerEmail` | `ken.pp.1205@gmail.com` | 通知メールの送信先（管理者） |
| `formTitle` | 名古屋で本格弓道体験 申込フォーム … | フォームのタイトル |
| `spreadsheetTitle` | 名古屋で本格弓道体験 申込一覧 … | 回答スプレッドシートのタイトル |
| `minDaysAhead` | `14` | 希望日として受け付ける「本日からの最短日数」 |
| `timezone` | `Asia/Tokyo` | 日付計算・表示に使うタイムゾーン |

## 補足

- 日付項目には「今日から14日以降だけ」を完全にブロックする標準バリデーションがないため、
  フォーム上の注意書き（ヘルプテキスト）＋送信後の自動チェックで運用します。
- 例えば 2026年6月6日を基準にすると、有効な最短日は **2026年6月20日** 以降になります（毎回自動計算）。
