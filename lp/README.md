# Yasmin 様向け LP（ランディングページ）

モデルプランをわかりやすく1ページで提案するための LP です。

## ファイル
- `index.html` … LP 本体（単一ファイル・外部依存なし）
- `PHOTO-LIST.md` … 各都市の写真 仕入れリスト（ファイル名指定）
- `images/` … ここに写真を置く（`PHOTO-LIST.md` のファイル名どおり）

## 使い方
1. `PHOTO-LIST.md` の優先5枚から写真を集める。
2. 指定ファイル名で `lp/images/` に保存（例：`images/hero-fuji.jpg`）。
3. `index.html` をブラウザで開いて確認。
4. 画像が無い箇所は暗色のプレースホルダーで表示され、レイアウトは崩れません。

## 公開（任意）
- GitHub Pages、Netlify、Vercel いずれにもこのフォルダごと載せれば公開できます。
- まずは `index.html` をダブルクリックでローカル確認でOK。
