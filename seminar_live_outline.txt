=====================================================
ライブ講座・構成案（NotebookLM用ソース）
タイトル：AIに働かせるSNS管理術
サブタイトル：JC会員のための実践AI講座（レベル1〜3）
軸：AI時代のSNS管理。その指示力を、JCの議案構築・商談・スライド作成・ルーティーン管理に転用する。
時間：約45分（自己紹介5分＋レベル1〜3を各10分＋質疑応答10分）
方針：初心者を置いていかない／アーカイブでテンポよく見える
主催：名古屋JC SNS戦略部会
=====================================================

■ アーカイブを最後まで見せる5つの仕掛け
1. コールドオープン：冒頭30秒に「一番すごいデモ結果」をチラ見せ→離脱防止
2. チャプター必須：YouTube概要に時間リンク（各見出しがそのままチャプター）
3. 90秒ルール：説明が90秒を超えたらデモか問いかけで画を変える
4. テロップ常時：要点を画面に出す（音声なしでも理解できる）
5. 各レベル末の「30秒まとめ」：ここだけ見れば復習できる“しおり”

■ チャプター（YouTube概要欄に貼る）
0:00 コールドオープン＋自己紹介（興味付け）
5:30 レベル1：AIにSNS管理の“雑務”をやらせる
15:30 レベル2：AIを“部下”にして成果物を作らせる
25:30 レベル3：仕組み化＝ルーティーン管理
35:30 質疑応答＋締め

-----------------------------------------------------
【0. コールドオープン＋自己紹介（0:00–5:00）】
-----------------------------------------------------
0:00 コールドオープン（30秒）
・いきなりレベル3の結果を見せる：「これ、AIが勝手に作った“今週のSNS運用表＋投稿文7本”。手作業なら半日、AIなら3分」
・テロップ：「最後まで見たら、これがあなたにもできます」

0:30 タイトル＋今日の約束（1分）
・「ゴールは1つ。AIを“便利ツール”から“部下”に変える」
・約束：初心者を置いていきません。専門用語は必ず言い換えます。

1:30 自己紹介＝興味付け（3.5分）
・草彅剛似ネタで笑い→警戒を解く
・JC歴・本業（福祉/福祉事業）・SNS15アカウント実運用
・実績：福祉事業で満床・インバウンドのイベントが動いた
・興味付けの一言：「私は発信の天才じゃない。AIに管理させてるだけ」

5:00 今日の地図（30秒）
・レベル1=触る／レベル2=任せる／レベル3=仕組み化。各10分。毎レベル冒頭で現在地を再掲。

-----------------------------------------------------
【レベル1：AIにSNS管理の“雑務”をやらせる（5:30–15:30）】
軸：SNS管理の土台。「考える・書く・まとめる」をAIに渡す。
Before：投稿文に30分 → After：30秒
-----------------------------------------------------
① 音声入力で“考えを吐き出す”（2分）
・きれいに書く前にまず喋る。20〜30秒喋ってAIが整文。「文章が苦手でも問題ない」

② NotebookLMで例会・会社資料を要約（3分）
・資料を読み込ませ「3行要約・要点5つ・想定質問」。初心者：“その資料だけ”を読むからウソが少ない。

③ SNS投稿を3媒体に一発展開（3.5分）
・1つの素材→Instagram／X／Facebook。デモしながらプロンプトをテロップ表示。

【プロンプト：1つの素材を3媒体に展開】
次の内容を、以下3媒体向けの投稿文に書き分けてください。
- Instagram：共感から入る本文＋ハッシュタグ10個
- X（旧Twitter）：140字以内のフック＋スレッド3連投
- Facebook：背景と想いが伝わる丁寧な長文
素材：（ここに出来事・写真の説明・伝えたいことを貼る）
読み手が「自分ごと」と感じる一文から始めてください。

【プロンプト：例会・会社資料を一発で要約】
この資料を読み込み、以下を出力してください。
1. 3行要約
2. 重要ポイント5つ
3. 会議で確認すべき論点3つ
4. 想定質問と回答3組
資料に書いてある内容だけを根拠にしてください。

30秒まとめ（テイクアウェイ）：今日コピペするだけで、SNS投稿は今日から楽になる。

-----------------------------------------------------
【レベル2：AIを“部下”にして成果物を作らせる（15:30–25:30）】
軸：SNS管理で鍛えた指示力を、議案・商談・スライドに転用。
Before：会議資料に30分 → After：3分で叩き台
-----------------------------------------------------
① 議案構築（JC直結・3分）
・目的／背景／課題／効果／予算／スケジュールをAIで骨子化。「ゼロから書かない。叩き台を作らせて直す」

② パートナーとの商談準備（3分）
・相手企業のリサーチ→刺さる提案ストーリー→想定問答まで。「商談は“準備”で決まる」

③ スライド作成（3分）
・「目的・対象・枚数・トーン」の4点→構成済みスライド。「今見てるこの資料もこう作った」

【プロンプト：企画を“理事会を通る議案”にする】
あなたはJC（青年会議所）の議案作成に精通した事務局長です。
次の企画を、理事会を通る議案ドラフトに整えてください。
企画の一言：（例）地域の高校生向けAI体験ワークショップを開催したい
出力（この順番で）：
1. 事業名（案を3つ）
2. 目的（3行）
3. 背景・現状の課題
4. 事業内容（実施概要・対象・人数・場所）
5. 期待される効果（参加者／地域／JC会員の3視点）
6. 概算予算（費目と金額の表、ざっくりでOK）
7. スケジュール（準備〜当日〜報告まで）
8. 理事会で出そうな質問と回答を3組
専門用語は避け、初めて読む理事にも伝わる言葉で。

【プロンプト：パートナー商談の準備を丸ごと】
あなたは法人営業のトッププレイヤーです。次の商談を準備してください。
- 自社：（例）福祉事業の運営
- 相手：（例）地域の医療法人 / 不動産オーナー
- 商談のゴール：（例）入居者紹介の連携 / 物件の提供
出力：
1. 相手にとっての“うれしいこと”を3つ（相手目線の利益）
2. 提案ストーリー（課題→解決→一緒にやる絵）を5ステップ
3. 最初の30秒で言う一言（つかみトーク）
4. 想定される懸念と切り返しを3組
5. 次のアクション（着地点）の提案
分かっている相手情報：（あれば貼る）

【プロンプト：箇条書きを構成済みスライドに】
次の条件でプレゼン資料の構成（各スライドのタイトル＋箇条書き本文）を作ってください。
①目的：（例）理事会で〇〇事業の承認を得る
②対象：（例）多忙で結論を急ぐ理事
③枚数：8枚
④トーン：簡潔・論理的・数字重視
「現状→課題→提案→効果→費用→スケジュール→お願い」を含めてください。

30秒まとめ（テイクアウェイ）：JCの議案も商談も“SNS管理と同じ指示の出し方”でできる。

-----------------------------------------------------
【レベル3：仕組み化＝ルーティーン管理（25:30–35:30）】
軸：単発で終わらせず、毎週ラクに回る仕組みにする。
Before：毎週ゼロから → After：仕込み3分で回る
-----------------------------------------------------
① ルーティーン管理（3分）
・週次のSNS運用＆JC業務をテンプレ＋AIで回す。デモ：「今週の投稿7本＋運用表」一括生成（＝コールドオープンの種明かし）

② Claude Codeで“自分専用のAIチーム”を作る（3.5分）※参考動画の手法
・/agents で役割ごとに専門エージェントを作り、仕事を分業させる。初心者は「Generate with Claude」＝やりたいことを日本語で言うだけ。
・コツ：1エージェント＝1専門に絞る／ツールは最小限から。
・例（SNS運用チーム）：①ネタ収集エージェント →②投稿作成エージェント →③校正・炎上チェックエージェント。「今週のSNS回して」の一言で3役が順に動く。
・JC議案チームも同じ要領：①議案リサーチ →②ドラフト作成 →③数字・整合チェック。

③ 情報を資産化（Notion／Obsidian・2分）
・プロンプト・議事録・ナレッジを一ヶ所に＝second brain。「個人の工夫を組織の資産に」

④ 半自動ルーティーンの全体像（1.5分）
・「ソースを整える→生成ボタン」まで仕組み化。完全自動の限界も正直に説明。

【プロンプト：今週のSNS運用表＋投稿7本を一括生成】
あなたは私専属のSNS運用マネージャーです。「今週の運用表」を作ってください。
- アカウントの目的：（例）福祉事業の認知と見学申込
- 媒体：Instagram / X / Facebook
- 今週のテーマ：（例）スタッフの1日・入居者の声
- 投稿本数：7本（曜日ごと）
出力：
1. 週間カレンダー表（曜日／媒体／テーマ／投稿文／ハッシュタグ）
2. 各投稿の本文（そのまま使える完成形）
3. 画像・動画の指示メモ（何を撮るか）
4. 今週の“伸ばす一手”を1つ
家族目線のやさしい言葉で、宣伝くさくしないこと。

【プロンプト：AI活用を資産にするNotion設計】
あなたは情報整理（PKM）の専門家です。私のAI活用を“資産”にするNotion構成を提案してください。
管理したいもの：プロンプト集／議事録／SNS投稿アーカイブ／JC議案
出力：
1. データベース構成（名前・用途・主なプロパティ）
2. 各データベースの使い分けルール
3. 毎週のルーティーン（何を・いつ・どう記録するか）5ステップ
4. 最初の1週間でやることチェックリスト
初心者でも迷わないよう、具体名で。

【プロンプト：投稿作成エージェントを作る（Claude Code /agents → Generate with Claude に貼る）】
SNS投稿を作る専門エージェントを作って。
役割：渡されたネタメモから、Instagram・X・Facebookの3媒体ぶんの投稿文を作る。
ルール：
- 家族目線のやさしい言葉。宣伝くさくしない
- 媒体ごとの作法に合わせる（インスタ＝共感＋ハッシュタグ／X＝短く／FB＝丁寧）
- 個人情報・機密は書かない
使うツール：ファイルの読み書きのみ（最小限）

【プロンプト：AIチームに今週のSNSを回させる（一括指示）】
今週のSNSを回して。次の順で進めて、最後にまとめて。
1. ネタ収集エージェント：今週の話題・写真メモから投稿ネタを3つ出す
2. 投稿作成エージェント：3媒体×各2本の投稿文を作る
3. 校正・炎上チェックエージェント：誤字と炎上しそうな表現を点検して直す
最後に、月〜日の投稿カレンダー（曜日／媒体／本文）にまとめて。

30秒まとめ（テイクアウェイ）：自分専用のAIチームを組めば、AIが“毎週働く部下”になる。

-----------------------------------------------------
【質疑応答＋締め（35:30–45:00）】
-----------------------------------------------------
沈黙対策に、初心者の不安に先回りした“仕込みQ”を3つ用意。
Q1 無料でどこまでできる？ → 今日のデモの大半は無料枠で可能。まずそこから。
Q2 情報漏れは大丈夫？ → 機密・個人情報は入れないルールを決める。法人プランの選び方も一言。
Q3 結局どれから？ → レベル1の「3媒体展開」を1回やるだけ。

締めの一言：「明日、1個でいいから試してください。それが一番の近道です」
最後にアンケートQR＋Drive共有マニュアル案内。

-----------------------------------------------------
【撮影・編集メモ（アーカイブのテンポ）】
-----------------------------------------------------
・画面共有メイン＋顔ワイプ。デモ中の待ち時間はカット or 倍速テロップ「⚡生成中（実際は8秒）」
・チャプター＝各見出しをそのままYouTube概要へ
・各レベル冒頭の「Before→After数字」をサムネ＆テロップに（数字が一番効く）
・1メッセージ1スライド。読み上げず“見せて要点だけ”話す

■ NotebookLMでの使い方
このソースを元に、こう指示するとアウトプットできます。
・「このソースを元に、レベル1〜3の各スライド構成（タイトル＋箇条書き3〜5点＋話者ノート）を作って」
・「アーカイブ用に、各チャプターのテロップ案と30秒まとめを作って」
・「音声概要（Audio Overview）で、当日のリハ用ナレーションにして」
