## 0. この改訂について

第1版はゼロから設計したたたき台だった。その後、Googleドライブ「伊勢青少年国際キャンプ」フォルダの以下2点を確認した。

- `20260727-29_寺子屋伊勢合宿保護者のしおり.pdf`
- `20260727-29_寺子屋伊勢合宿リーダーマニュアル.pdf`

**結論：この企画は「新規開発」ではなく「実績あるプログラムの国際化」である。**

12回の開催実績、確立された会場、危機管理体制、リーダー運用、協賛スキームがすでに存在する。
したがって本計画書の中心は、3日間の行程を一から考えることではなく、**国際化にあたって何を変えなければならないかの差分**である。

### 運営の骨格

- **村（班）制度** — 村名を子どもが決め、村旗を作り、村長・助役を置く。移動も食事もすべて村単位
- **GL／PL の二層構造** — グループリーダー（子どもに付く）とプログラムリーダー（進行・準備を回す）。大学生・高校生が担う
- **「愛汗のしおり」** — 毎晩日記を書かせ、リーダーが一言を書き返す
- **食前食後の感謝の言葉** — 全員で唱和
- **携帯・ゲーム機の持ち込み禁止**、小遣いは3,000円まで
- **保護者連絡はLINEオープンチャット** — 当日の様子を写真で随時配信、終了後に閉鎖

### 思想的支柱：修養団（SYD）の「愛と汗」

1906年創立、2026年で120周年。**特定の宗教や政党に属さない**社会教育団体であることを明記している。
リーダーマニュアルの「流汗悟道」（頭で考えるより、まず汗をかいて体験せよ）は、そのままこのキャンプの行動原理になっている。

**この「特定の宗教に属さない」という位置づけは、国際化において決定的に重要な資産である。**（§4-1参照）

## 4. 国際化の12の論点 — この計画書の本体

### 4-1. 宗教への配慮 ★最重要

内宮参拝と宇治橋前清掃は、このキャンプの中核でありながら、国際化における最大の論点になる。
海外の参加者にはキリスト教・イスラム教その他の信仰を持つ家庭の子が必ず含まれる。

**方針：**

- 修養団が **「特定の宗教や政党に属さない社会教育団体」** であることを、募集要項の冒頭に多言語で明記する。これは既存資料にある事実であり、最も強い説明になる
- 参拝は**「日本文化の作法を学ぶ体験」**として位置づける。一礼・手水は文化的な礼儀として全員が学ぶが、**何を祈るか、あるいは祈らないかは本人の自由**とする
- 正宮の前で手を合わせない子がいてよいことを、事前の保護者説明と当日の両方で明言する
- 宇治橋前清掃は「奉仕」であって「礼拝」ではない。**掃除という行為に宗教的な意味づけをしない**説明の仕方を用意する

ここを曖昧にしたまま募集すると、海外の保護者の申し込みが止まる。逆にここを丁寧に設計すれば、**「日本の聖地を、誰も排除せずに開く」**という、このキャンプ独自の価値になる。

### 4-2. 入浴 ★要方針決定

現行マニュアルは「**グループリーダーは、子どもたちと入浴しましょう……スキンシップ**」「低学年の子どもで、頭や体を洗うようにサポート」と定めている。
日本の青少年教育の現場では長年一般的な運用だが、**海外の保護者にはそのまま説明できない。** 多くの国では、成人スタッフが児童と入浴し身体を洗うことは、制度上の禁止事項にあたる。

**提案する変更：**

| 現行 | 国際版 |
| --- | --- |
| GLが子どもと一緒に入浴 | GLは**脱衣所と浴室入口で見守る**（着衣）。入浴自体は子どもだけ |
| GLが低学年の頭・体を洗う | 洗身の介助は原則行わない。必要な場合は**同性スタッフ2名以上が立ち会う** |
| 大浴場で全員一斉 | 裸での入浴に抵抗がある子のために**個別シャワーの時間枠**を設ける |

さらに、**大浴場で裸になるという文化そのものを事前に説明する**必要がある。知らずに来て当日直面させるのは避ける。

### 4-3. 対象年齢 ★要方針決定

現行は小学1年生〜6年生（6〜12歳）。だが**小学1年生が海外から渡航してくるのは現実的でない。**

**提案：**

- **国内（名古屋）枠：小学3年生〜中学2年生**（既存の下限を少し上げる）
- **海外枠：小学5年生〜中学3年生**（単独渡航と3日間の集団生活に耐えうる下限）
- 中学生を入れるなら、**上級生に役割を与える**設計が要る。現行の「村長は5,6年生」を拡張し、中学生を**バイリンガル村長**として機能させるのが自然

### 4-4. 言語

**通訳を各村に1名置くのではなく、バディ制で解く。**

- 日本の子と海外の子を1対1で組み、村の中に混在させる
- 講話・ともしびの集い・静座行の説明は、**事前に英訳台本を用意し、当日は要点のみ逐次通訳**する（全文同時通訳は場の空気を壊す）
- 「愛汗のしおり」の英語版を作る。日記は**母語で書かせる**
- 感想文も母語で可。現行マニュアルの「漢字のわからない子にアドバイスを」は、そのまま国際版に流用できる

**キャンプファイヤーの出し物と村旗作成は、言葉が要らない。** ここが国際版で最も強く効く時間になる。

### 4-5. 保護者との連絡 ★LINEは使えない

現行はLINEオープンチャットで写真を随時配信している。
だが**LINEは日本・台湾・タイ以外ではほとんど使われていない。** 欧米圏はWhatsApp、Messenger、地域によっては別のもの。

**提案：** LINEは国内保護者向けに残しつつ、**海外保護者向けにパスワード付きの非公開Webページ**を用意し、そこに写真とテキストを1日3回更新する。プラットフォームに依存せず、どの国からでも見られる。
海外の保護者の不安は国内の比ではない。**初日の夜に「無事に着いて、笑っています」の一報が届くかどうか**で、翌年の参加が決まる。

### 4-6. 携帯電話の禁止

現行は子どもの携帯持ち込み禁止（発見時は預かり）。**この方針は維持すべき**で、キャンプの質に直結する。

ただし海外の子には緩和が要る。**到着当日の夜に一度だけ、家族への連絡時間（15分）を設ける。** 主催側の端末を貸し出す形にすれば、持ち込み禁止の原則は崩れない。

### 4-7. 食事

センター食堂の団体食。国際化では以下の事前確定が必須。

- **ハラル／ベジタリアン／ヴィーガン／アレルギー**対応の可否をセンターと詰める
- 野外炊事のカレーは、**ルーの成分（豚由来ゼラチン等）**まで確認が要る
- おかげ横丁での買い食いは、村付きリーダーが成分を確認する
- 食前食後の感謝の言葉は**宗教色のない文言**（「天地一切の恵みと、これをつくられた人々のご苦労を感謝いたします」）であり、英訳して全員で唱和できる

### 4-8. 川遊び（五十鈴川）

現行はリストバンド着用、水から上がったら即人員確認、と運用が固まっている。
国際化で足すべきは**泳力の事前申告**。水に慣れていない子は国によって珍しくない。ライフジャケットの用意と、**泳力別のエリア分け**を検討する。

### 4-9. 渡航・入国

- 査証の要否は国籍による。**未成年単独渡航の同意書**が必要な国がある
- 到着は**前日入り必須**。時差・遅延・荷物ロストを初日に持ち込まない
- 中部国際空港での出迎え体制と、名古屋市内の前泊ホテル手配
- 海外旅行保険と、日本国内の団体傷害保険（現行は東京海上日動）の**重複・空白の確認**

### 4-10. 危機管理

現行の体制は完成度が高く、**そのまま使える。**

- ホームドクター（センター指定のクリニック、原則24時間対応）
- 事故・迷子のフロー（迷子は30分未発見で警察へ通報、捜索班増員、保護者連絡）
- 熱中症の重症度別対応（熱痙攣／熱疲労／熱射病）

**国際版で足すもの：**
- 全書式の多言語化（健康チェックシート、同意書、緊急連絡先）
- 受診時の**通訳同行**（医療通訳は日常会話とは別技能。事前に手配先を決めておく）
- 海外保護者への**時差を考慮した緊急連絡フロー**（深夜に繋がらない前提で、第2連絡先を必須にする）

### 4-11. 弓道を組み込む余地

保護者のしおりの周辺地図に、研修センターの近くに**神宮道場・弓道場・相撲場**の記載がある。

BUSHIDO JAPANが弓道体験を持ち込むなら、この立地は理想的である。
現行の「リーダーと学ぶ（相互学習）」または2日目午後の枠に、**姿勢・丹田・呼吸・足さばきを軸にした「当てない稽古」**を差し込める。的中を競わせないので、言語も体力差も問題にならない。

**ただし利用条件は未確認。** §6の要確認事項に入れている。

### 4-12. 協賛

現行は地元企業17社＋匿名個人の協賛で参加費を抑えている。
国際版では**「日本文化を世界の子どもに開く」という趣旨が、より広い協賛を呼べる可能性がある。** 名古屋圏の企業、国際交流系の助成金（自治体・財団）を並行して当たる価値がある。

## 5. 運営体制（国際版）

現行のGL／PL二層構造を維持し、以下を追加する。

| 役割 | 備考 |
| --- | --- |
| GL（グループリーダー） | 村付き。**各村に日英どちらも話せるGLを最低1名** |
| PL（プログラムリーダー） | 進行・準備。現行のマニュアルがそのまま使える |
| **通訳** 2〜3名 | 講話・式典・医療対応。GLとは別に置く |
| **看護担当** 1名 | 夜間常駐。現行資料に明記がないため要確認 |
| 海外受け入れ担当 | 空港出迎え、前泊、保護者対応の窓口を一本化 |
| 記録・配信担当 | 国内LINE／海外Webページの両方を回す |

**リーダー向けの事前研修（半日）を新設する。** §4-2（入浴の運用変更）と§4-1（宗教配慮）は、口頭伝達では徹底しない。

## 7. 未決事項 — 判断が要るもの

### 7-1. 主催の建て付け ★最優先

既存の合宿は**教育再生いばらき**（大阪府茨木市）の主催である。2027年の国際版は、

- **(a)** 既存合宿の国際枠として、同じ主催の中で拡張する
- **(b)** 名古屋を拠点とする別事業として立ち上げ、ノウハウと会場を共有する
- **(c)** 共催とする

のいずれか。**これが決まらないと、募集・会計・保険・責任の所在が決められない。**
「名古屋および世界中の小中学生」という対象設定は、茨木市の事業とは明確に別の枠組みを要求している。

### 7-2. 規模と比率

国内何名、海外何名か。**初年度は海外枠を小さく（8〜12名程度）始め、既存の型を壊さずに国際化が回るかを見る**のが現実的だと考える。いきなり半々にすると、日本語の場が成立しなくなる。

### 7-3. 海外参加者の集め方

最も読めない部分。在外日本人コミュニティ、提携校、既存のBUSHIDO JAPAN顧客、現地エージェント。**ここの見通しが立つまで、規模は仮置きのままにしておく。**

### 7-4. 参加費

現行は協賛で抑えている。国際枠に同じ補助を適用するか、渡航費は自己負担として参加費のみ同額とするか。
