- **現地で日本の子ども集団と合流する** — 外国の子にとって、これは主催側が用意できるどんな企画より価値がある。**「日本の子どもたちが、いつも通りに過ごしている場に混ざる」**という体験は作れない
- BUSHIDO JAPANが設計すべきは、**この合流を偶然に任せず、必ず起こるようにする仕掛け**である

## 2. このプログラムが売っているもの

参加費50,000円。何に対する対価かを、まず言葉にしておく。

### 外国の子にとって

観光では絶対に届かない場所——**日本の子どもの生活そのもの**への参加。
早朝に正座し、神社の前を掃き、飯盒で米を炊き、川で泳ぎ、火を囲んで歌う。**ガイド付きの見学ではなく、当事者として同じことをする。**

### 名古屋の子にとって

**「説明する側」に立つ経験。**
これがこのプログラムの核心である。自分の国の当たり前を、通じない相手に説明しようとした瞬間、子どもは「知っているつもりだった」ことに気づく。
なぜ靴を揃えるのか。なぜ食事の前に手を合わせるのか。なぜ橋の前で礼をするのか。**答えられない自分に出会うことが、育成である。**

> **設計原則：日本の子を、案内される側ではなく案内する側に立たせる。**
> 通訳スタッフは、子どもが自力で伝えようとする時間を奪わない。呼ばれるまで介入しない。

### 保護者にとって

2泊3日・食事すべて込み・名古屋発着バス付き・日英バイリンガル運営・武道指導・伊勢神宮参拝。
**協賛によりバス代と合気道の指導料がかからない分、中身に振り向けられている。**

## 3. BUSHIDO JAPANが作りこむ「国際育成の層」

SYDのベースプログラムには手を入れない。**その上に、以下の6つを乗せる。**

### 3-1. バディ制度 ★中核

**日本の子と外国の子を1対1で組み、3日間ずっと同じ相手と過ごす。**

| ルール | 意図 |
| --- | --- |
| 移動・食事・村・部屋割りをバディ単位で | 一緒にいる時間の総量が、言語の壁を越える唯一の手段 |
| 通訳は呼ばれるまで介入しない | 自力で伝えようとする時間を奪わない |
| 困ったら「ジェスチャー→絵→単語→通訳」の順 | 順番を決めておくと、子どもは自分で解こうとする |

組み合わせは事前アンケートで決め、**年齢を近づけ、性格は意図的に散らす**（活発×静か）。当日変更しない。
日本の子への事前メッセージは一行でいい——**「英語ができる必要はありません。伝えようとすることが役目です」**

### 3-2. 合気道（英語）— 鯱バス様・山本様

**言語の壁が存在しない唯一の時間。** そしてプログラム全体の思想を決める時間でもある。

- **相手を倒さない。争わない。受け身から入る**——「強いとは、打ち負かすことではない」
- 体格差・年齢差を問わないので、小学生と中学生、男女が混在しても成立する
- 合気道は世界に広く普及しており、**海外の保護者に「何をやるのか」を説明する必要がない。募集の武器になる**
- **畳のあるスペースが必要**（§8 要確認）

### 3-3. 「わたしの国」の時間

各自が自分の国・地域について**3分だけ**話す。バディが手伝う。

- 上手に話す必要はない。写真1枚と、好きな食べ物と、大切にしている行事——それで足りる
- 名古屋の子も同じことをする。**「日本」ではなく「名古屋」「自分の家」について話させる**のが要点
- 抽象的な文化論にしない。具体的な生活の話にする

### 3-4. 教育再生いばらきとの交流（BBQ・川遊び・瞑想）

**言葉が要らない3つが揃っている。** ここは主催側が仕切りすぎないほうがよい。

- **BBQ** — 火と食べ物があれば子どもは勝手に混ざる。BUSHIDO JAPANの仕事は、**バディ以外とも話す口実を1つ用意しておく**こと（例：村対抗で1品ずつ担当する）
- **川遊び（五十鈴川）** — 最も自然に混ざる時間。**泳力の事前申告を必須化**（§7-4）
- **瞑想** — 国籍も宗教も言語も問わない。**外国の子にとって、これが最も「日本らしい」記憶になる可能性がある**。座り方と呼吸だけを英語で伝えれば成立する

### 3-5. 誓いの言葉

最終日、3日間で見つけたことを**一文**にする。

- **母語で書き、バディの言語にも訳す。** 相手の一番大切な一文を、自分の言葉で書き写す
- 大人が添削しない。**たどたどしくても本人の言葉であることを最優先する**
- 修了証と一緒に持ち帰らせる

### 3-6. 事前と事後

**3日間だけで終わらせない。** ここが50,000円の価値を決める。

| 時期 | やること |
| --- | --- |
| 出発6週間前 | **バディ発表**。写真と名前を伝える |
| 出発4週間前 | **オンライン顔合わせ（30分）**。バディ同士で挨拶。時差を考慮し2回開催 |
| 出発2週間前 | 持ち物・作法の事前動画（日英）。大浴場の説明もここで（§7-2） |
| 期間中 | 保護者向けに1日3回の配信（§7-3） |
| 終了後1週間 | 写真と感想文集の送付 |
| 終了後1か月 | **オンライン再会（30分）**。バディが今どうしているかを話す |

**初日に「はじめまして」から始めない。** 4週間前に一度会っていれば、初日の午後には走り回っている。

## 7. 国際化で必ず設計が要る点

SYDのベースをそのまま外国の子に適用すると詰まる箇所。**BUSHIDO JAPANが引率者として責任を持つ部分。**

### 7-1. 宗教への配慮 ★最重要

- **SYDが「特定の宗教や政党に属さない」社会教育団体**であることを、募集要項の冒頭に日英で明記する。既存資料にある事実であり、最も強い説明になる
- 内宮参拝は**「日本文化の作法を学ぶ体験」**と位置づける。一礼・手水は礼儀として全員が学ぶが、**何を祈るか／祈らないかは本人の自由**
- **正宮の前で手を合わせない子がいてよい**ことを、保護者説明と当日の両方で明言する
- 清掃奉仕は「奉仕」であって「礼拝」ではない——宗教的な意味づけをしない説明を用意する

### 7-2. 入浴 ★要協議

既存のリーダーマニュアルは「GLは子どもたちと入浴しましょう……スキンシップ」「低学年の頭や体を洗うようサポート」と定める。日本の青少年教育では長年一般的な運用だが、**多くの国では成人スタッフが児童と入浴し身体を洗うことは制度上の禁止事項にあたる。** 海外の保護者にそのまま説明できない。

**BUSHIDO JAPANの引率者については、以下を方針とする。**

| | 方針 |
| --- | --- |
| 入浴 | スタッフは**着衣で脱衣所・浴室入口を見守る**。入浴は子どもだけ |
| 洗身の介助 | 原則行わない。必要時は**同性スタッフ2名以上が立ち会う** |
| 抵抗がある子 | **個別シャワーの時間枠**を設ける |

**大浴場で裸になるという文化そのものを、事前動画で説明する。** 当日いきなり直面させない。

### 7-3. 保護者との連絡

- 国内保護者：LINEオープンチャット（SYD／既存方式に準じる）
- **海外・外国人保護者：パスワード付きの非公開Webページ**を1日3回更新。**LINEは日本・台湾・タイ以外ではほとんど使われていない**
- **初日の夜の一報**（「無事に着いて、笑っています」）が、翌年の参加を決める

### 7-4. 川遊び

**泳力の事前申告を必須化。** 水に慣れていない子は国によって珍しくない。ライフジャケットの用意と泳力別エリア分けを、SYDおよび教育再生いばらきと調整する。

### 7-5. 携帯電話

既存の持ち込み禁止方針を**維持する**。プログラムの質に直結する。
ただし外国の子には、**初日の夜に一度だけ家族への連絡時間（15分）**を設ける。主催側の端末を貸す形なら原則は崩れない。

### 7-6. 食事

**ハラル／ベジタリアン／ヴィーガン／アレルギー**の対応可否をSYDと詰める。
野外炊事のカレーは**ルーの成分（豚由来ゼラチン等）**まで確認が要る。BBQの食材も同様。

### 7-7. 対象年齢

既存合宿は小1〜小6。国際版では、

- 名古屋枠：**小学3年生〜中学2年生**
- 外国人枠：**小学4年生〜中学3年生**（在住の子を主軸にするなら下限を下げられる）

中学生を入れるなら、**上級生に役割を与える**設計が要る。バイリンガルの中学生は**村長／通訳役**として機能させるのが自然。

### 7-8. 引率体制（BUSHIDO JAPAN分）

進行はSYDが担うため、BUSHIDO JAPANは**引率と国際育成層の運営**に必要な人数を置く。

| 総括責任者 | 1（上岡） |
| バディ担当・引率 | 6〜8 |
| **通訳** | 2〜3（★削らない） |
| **看護担当** | 1（夜間常駐。SYDとの分担を要確認） |
| 海外・外国人保護者 窓口 | 1 |

**事前研修（半日）を必ず実施する。** §7-1（宗教配慮）と§7-2（入浴運用）は、口頭伝達では徹底しない。
