## 2. 運営母体 — 実行委員会方式を勧める

**結論：実行委員会を設立し、BUSHIDO JAPANが事務局を務める形にすべきである。**

毎年の恒例企画にし、協賛を増やし、自治体の後援を得たいのであれば、これは選択肢のひとつではなく前提条件に近い。

### 2-1. なぜ実行委員会でなければならないか

| 理由 | 内容 |
| --- | --- |
| **後援名義が取れる** | 自治体の後援要綱は多くの場合「営利を目的としないこと」「特定企業の宣伝にならないこと」を条件とする。**営利法人の単独主催では、名古屋市・愛知県・伊勢市の後援は通りにくい。** 実行委員会という公益的な任意団体にすることで、申請の土俵に乗る |
| **協賛が集まる** | 企業が営利法人へ支払う場合、広告宣伝費か寄付かの判断と稟議が要る。**実行委員会への協賛は「一社を助ける」形にならないため、社内で通しやすい** |
| **恒例化に耐える** | 事業が一社と一体だと、承継も規模拡大も難しい。実行委員会なら構成団体が入れ替わっても事業が続く |
| **既存の座組と整合する** | 修養団・鯱バス様・教育再生いばらきという複数主体が関わる実態に、実行委員会という形が一致している |

### 2-2. 注意点 — 実行委員会の弱点

実行委員会は**法人格を持たない任意団体**である。以下は規約で先に潰しておく。

- **契約主体になれない場面がある** — 会場契約、保険契約、決済代行。**実務はBUSHIDO JAPANが事務局として受託する**形にしておく
- **銀行口座** — 任意団体名義の口座は開設できるが手間がかかる。会計を分けるなら早めに動く
- **責任の所在が曖昧になりやすい** — 事故時に「みんなの責任＝誰の責任でもない」になる。**規約に、事業執行の責任者と事務局を明記する**
- **意思決定が遅くなる** — 委員会の合議事項と、事務局の専決事項を規約で線引きする

### 2-3. 推奨する建て付け

**伊勢青少年国際キャンプ実行委員会**

| | |
| --- | --- |
| 実行委員長 | 要検討（BUSHIDO JAPAN代表、または中立的な立場の方） |
| 構成 | **BUSHIDO JAPAN・鯱バス様（共同主催者）**／伊勢修養団（協力）／教育再生いばらき（協力）／有識者 |
| **事務局** | **BUSHIDO JAPAN**（募集・会計・契約実務・保護者対応） |
| 会計 | 事業会計を独立させ、年度末に収支報告を作成・公開 |
| 規約に明記 | 目的／構成／**共同主催者の位置づけ**／意思決定／事務局の専決範囲／会計／**事故時の責任の所在**／解散時の残余財産 |

### 2-4. 共同主催が2社になったことによる注意 ★

鯱バス様が共同主催に入られるのは、信用力・協賛集め・バス手配のいずれにも大きくプラスである。
**ただし後援申請に関しては、逆方向に働く可能性がある。**

自治体の後援要綱は多くの場合、**「営利を目的としないこと」「特定企業の宣伝を主目的としないこと」**を条件とする。
**主催者欄に営利法人が2社並ぶと、この条件の判断が厳しくなりうる。** 旅行業の「報酬性がない」という整理（§3-7）についても同様に苦しくなる。

**推奨する解き方——鯱バス様の立場は変えず、対外的な表記だけを実行委員会にする。**

```
主催：伊勢青少年国際キャンプ実行委員会
      （構成団体：BUSHIDO JAPAN／株式会社鯱バス ほか）
事務局：BUSHIDO JAPAN（愛知県豊明市西川町島原14-12）
後援：名古屋市教育委員会／名古屋市／愛知県／伊勢市／豊明市（申請予定）
協賛：株式会社鯱バス ほか
```

こうすれば、

- **主催者は非営利の任意団体**になり、後援要綱の条件を満たしやすい
- 鯱バス様は**共同主催者として実行委員会の中核**に変わりなく入っていただける
- 旅行業の「報酬性がない」という整理も維持できる
- 協賛企業を毎年増やしていく器としても、この形が最も素直

**実質を変えるのではなく、看板の掛け方の問題である。** 鯱バス様にもこの意図をご説明したうえで、規約に共同主催者としての位置づけを明記する。

### 2-5. 後援 — 取りに行く順番と、最優先の1つ

**名古屋市教育委員会の後援が、募集における最大の武器になる可能性が高い。**

自治体の後援は名義のみで金銭を伴わないが、**学校を通じたチラシ配布の可否が、教育委員会の後援の有無で変わることが多い。** 名古屋の小中学生を集めるという目的に、これが最も直接的に効く。

| 申請先 | 狙い | 優先度 |
| --- | --- | --- |
| **名古屋市教育委員会** | **市立小中学校への告知ルート** | ★★★ |
| 名古屋市 | 信用力・広報誌掲載 | ★★ |
| 愛知県／愛知県教育委員会 | 対象範囲の拡大 | ★★ |
| 伊勢市 | 開催地としての協力。地元との関係構築 | ★★ |
| **豊明市** | **事務局所在地。地元自治体は通りやすい場合が多い** | ★★ |
| 三重県 | 余力があれば | ★ |

**申請には通常、規約・役員名簿・事業計画書・収支予算書が要る。**（要綱は自治体ごとに異なるため、各窓口に確認が必要）

### 2-6. これがスケジュールを規定する

後援は**申請から決定まで1〜2か月かかることが多い。** 募集チラシに「後援：名古屋市教育委員会」と刷るなら、逆算はこうなる。

```
修養団の見積            → 事業計画書・収支予算書が書ける
        ↓
実行委員会の設立（規約・役員） → 後援申請の要件が揃う
        ↓
後援申請（9月下旬〜10月上旬）  → 決定まで1〜2か月
        ↓
協賛募集（後援名義が効く）
        ↓
募集要項に後援・協賛名を刷り込む（11〜12月）
        ↓
2027年1月1日 募集開始
```

**順番が逆にできない。** 後援名義があってはじめて協賛が集めやすくなり、学校ルートが開く。
そして後援申請には事業計画と予算が要り、予算には修養団の見積が要る。**すべての起点が修養団への問い合わせにある。**

### 2-7. 協賛を毎年増やしていくために

初年度に整えておくと、2年目以降が楽になるもの。

- **協賛メニューの階層化**（例：物品協賛／10万円／30万円／50万円で、掲載場所と特典を変える）
- **協賛社への報告書** — 参加人数、写真、子どもと保護者の声、メディア掲載。**これを毎年出せる体制が、翌年の協賛を決める**
- **実施報告書を公開する** — 収支報告を含めて出すと、後援の継続と新規協賛の両方に効く
- 鯱バス様は初年度の第一号協賛。**「協賛社の声」として次の企業に見せられる形にしておく**

## 3. 旅行業法をどうクリアするか ★募集開始前に決着が必要

### 3-1. 教育再生いばらきの確認内容

**「利益が出ない単発のイベントであれば、旅行業の許可はいらない」**と確認を取られたとのこと。

報酬性のない事業は旅行業に当たらない、という整理自体は筋が通っている。**この方向は有力な選択肢であり、真剣に検討する価値がある。**

ただし旅行業の該当性は、**その事業の具体的な事実関係**で判断される。教育再生いばらきの事業とこの企画では、以下の3点が異なる。

### 3-2. そのまま当てはまらない可能性がある3点

| # | 条件 | 教育再生いばらき | 2027年の企画 |
| --- | --- | --- | --- |
| 1 | **利益が出ない** | 協賛で参加者負担を抑える建て付け | **§8の試算では40名で+11万、条件次第で+38万の余剰が出る設計** |
| 2 | **単発** | — | **「毎年の恒例企画にしたい」= 継続事業** |
| 3 | 主催者の性格 | 非営利の団体 | **営利法人2社の共同主催**（BUSHIDO JAPAN・鯱バス様）。**実行委員会を主催に立てれば近づく（§2-4）** |

**1と2が、現在の計画とそのまま矛盾している。** 逆に言えば、**この2つを設計で満たせば、同じ整理に乗れる可能性がある。**

### 3-3. しおりが示している事実

見落とせない点がひとつある。

**教育再生いばらきの保護者のしおりには、「取扱旅行社 株式会社伊勢國際観光」と明記されている。**

つまり、**「許可はいらない」という確認を取ったうえで、実際には登録旅行業者を立てている。**
これは矛盾ではなく、おそらく順序が逆で——**旅行部分を旅行業者が担っているからこそ、主催者側に登録が不要**という整理である可能性が高い。

**確認内容の正確な文脈（何を前提に、どの窓口に、どう尋ねたか）を教育再生いばらきに聞いておく価値がある。** ここが分かれば、この企画で同じ整理が使えるかどうかの判断がつく。

### 3-4. 鯱バス様が共同主催であることは、決め手になりうる

**ただし、それを決めるのは一点だけ——鯱バス様が「旅行業登録」をお持ちかどうかである。**

ここは混同しやすい。**バス事業者であること（道路運送法上の貸切バス事業）と、旅行業登録（旅行業法）は別の制度である。** 貸切バス事業者は旅客を運送できるが、それだけでは「旅行の企画・手配を報酬を得て行う」資格にはならない。

一方で、**観光バス会社は自社でバスツアーを募集・販売するために旅行業登録も併せ持っていることが多い。** 鯱バス様も持っておられる可能性は十分にある。

**聞くべきことは一つ。**

> 「鯱バスさんは旅行業登録をお持ちですか。お持ちなら第何種でしょうか」

| 回答 | 意味 |
| --- | --- |
| **第1種または第2種** | **これで解決する。** 国内の募集型企画旅行を実施できる。鯱バス様が旅行の企画・実施主体として名を連ねる形が組める |
| **第3種／地域限定** | **解決しない可能性が高い。** 募集型企画旅行の実施区域が営業所周辺に限定されるため、名古屋発・伊勢泊は区域外になると見込まれる（要確認） |
| **登録なし（運送事業のみ）** | 旅行業の論点は解決しない。§3-5・§3-6の道を取る |

**この一問で、§3の残りの検討が大きく変わる。** 修養団への見積依頼と同じ優先度で、今月中に確認する。

### 3-5. 2つの道

| | 内容 | 条件 |
| --- | --- | --- |
| **A. 非営利・収支均衡の建て付けにする** | 実行委員会主催、余剰を出さない設計 | §3-6の設計変更が必要 |
| **B. 登録旅行業者に委託する** | 旅行部分を旅行業者が担う | 手数料が乗る。**既存合宿の実際の形** |

**AとBは排他ではない。** 実行委員会で非営利の建て付けにしたうえで、旅行部分は旅行業者に委託する——これが最も安全で、既存合宿がやっていることに最も近い。

なお**自社での第2種旅行業登録は初年度は不可能**である。旅行業務取扱管理者（国家資格）の選任が必須で、試験は年1回、2026年度の申込はすでに締切を過ぎている見込み。恒例化を見据えて2年目以降に検討する価値はある。

### 3-6. 推奨：愛知県に直接確認する

**電話1本で済み、費用はかからない。そして、これをやらない理由がない。**

他団体が取った確認は、その団体の事実関係についてのものである。**万一のとき、「他の団体がそう聞いたから」は主催者を守らない。** 自分たちの建て付けで、自分たちで確認を取る。

**愛知県の旅行業登録担当窓口**に、以下を具体的に伝えて判断を仰ぐ。

1. 実行委員会（任意団体）が主催する、小中学生対象の2泊3日の教育キャンプであること
2. 名古屋発着の貸切バス（協賛により無償）と、伊勢の研修センターでの宿泊を伴うこと
3. 参加費を50,000円収受すること
4. **毎年の開催を予定していること**
5. 事務局を営利法人（BUSHIDO JAPAN）が担うこと
6. 協賛金を受け入れること

**5と6は必ず伝える。** 事務局が営利法人であること、事務局が実行委員会から業務委託費を受け取る場合にそれが報酬性を持つかどうかは、判断に影響しうる。

### 3-7. A案を選ぶ場合、収支設計を変える必要がある

「利益が出ない」で整理するなら、**§8の収支をそのまま使えない。** 余剰が出る設計になっているためである。

**変更すべき点：**

- **実行委員会の会計を独立させ、単年度で収支を均衡させる**
- 余剰が出た場合は、**BUSHIDO JAPANの利益とせず**、以下に充てる
  - 経済的に厳しい家庭への**減免枠**
  - **次年度への繰越金**
- **事務局（BUSHIDO JAPAN）が業務委託費を受け取るかどうか**を明確にする。受け取るなら、その性格と金額の妥当性を説明できるようにしておく
- **収支報告を毎年公開する** — これは後援・協賛の継続にも効く（§2-6）

**この設計変更は、後援申請とも協賛集めとも矛盾しない。** むしろ「非営利の実行委員会が、収支を公開しながら毎年続けている事業」という形は、後援も協賛も最も通りやすい。

> **旅行業・後援・協賛の3つが、同じ答えを指している。**
> 実行委員会にして、収支を均衡させ、余剰は減免と繰越に充て、報告を公開する。これで3つ同時に解ける。

### 3-8. 海外からの参加者について

**航空券は各家庭の自己手配とする方針を維持する。**

## 8. 収支 — 修養団 33,000円/人 で再試算 ★要判断

**修養団の見積が値上げを加味して33,000円/人となったことで、収支の構造が変わった。**

### 8-1. 何が起きているか

参加費50,000円のうち、**33,000円が研修センターに行く。手元に残るのは17,000円。**

| | 40名の場合 |
| --- | ---: |
| 参加費 | 50,000 |
| − 研修センター負担金 | 33,000 |
| **= 残り** | **17,000** |
| − 引率スタッフ宿泊費の按分（12名分／40名） | 9,900 |
| − 保険・教材 | 5,000 |
| **= 残り** | **2,100** |
| **必要な固定費（通訳・看護・広報・事務・減免・予備費）／人** | **21,250** |

**1人あたり約19,000円足りない。**

### 8-2. 現行案のままでは成立しない

参加費50,000円・協賛300,000円・スタッフ12名分の宿泊費を負担する前提では、

| 定員 | 収入 | 支出 | 損益 |
| ---: | ---: | ---: | ---: |
| 30名 | 1,800,000 | 2,386,000 | **−586,000** |
| 40名 | 2,300,000 | 2,766,000 | **−466,000** |
| 50名 | 2,800,000 | 3,146,000 | **−346,000** |

**定員を増やしても解決しない。** 33,000円は人数比例の変動費であり、増員は固定費の按分にしか効かないためである。

### 8-3. 単独で解くなら、どれだけ必要か

| 解き方 | 30名 | 40名 | 50名 |
| --- | ---: | ---: | ---: |
| **参加費だけで解く** | 70,000円 | **62,000円** | 57,000円 |
| **協賛だけで解く** | 89万円 | **77万円** | 65万円 |

### 8-4. 推奨：参加費50,000円を維持し、4つを積む

募集開始まで4か月。**いま価格を上げると訴求力を落とす。** 以下を積み上げて解く。

| # | 対策 | 効果（40名） | 累計損益 |
| --- | --- | ---: | ---: |
| 0 | 対策なし | — | −466,000 |
| 1 | **実行委員4名の宿泊費を自己負担に**（手弁当） | +132,000 | −334,000 |
| 2 | **修養団に引率者分の宿泊費の減免を交渉**（半額と仮定） | +132,000 | −202,000 |
| 3 | **通訳をバイリンガル学生ボランティア中心に**（25万→10万） | +150,000 | −52,000 |
| 4 | **協賛を70万円に**（現案30万→70万） | +400,000 | **+248,000** |

**1と2が最も効き、かつ最も現実的。**

2. **減免枠を1名分に減らす**（−50,000円。ただし理念上は最後に削る）

### 8-8. 「利益を出さない」建て付けとの整合

§3-7の通り、旅行業法上「利益が出ない」ことで整理する場合、この予算はその要件を満たしている。

- **単年度で収支を均衡させている**（次年度繰越金92,000円）
- 剰余は**参加費減免枠**（100,000円）と**次年度繰越**に充てており、BUSHIDO JAPANの利益としていない
- **実行委員4名は無報酬・宿泊費自己負担**
- 収支報告を事業終了後に作成・公開する

**事務局（BUSHIDO JAPAN）が業務委託費を受け取るかどうかは未定。** 受け取る場合は、その性格と金額の妥当性を説明できるようにしておく（§3-6で愛知県に確認する際、この点も併せて伝える）。

### 8-9. 協賛の使い道

鯱バス様のバス協賛と合気道のボランティア指導により、**交通費と武道指導料はすでにゼロ**になっている。
**現金協賛70万円が新たな目標**となったため、§2-7の協賛メニューの階層化を早期に設計する。

追加の協賛が得られた場合の充当先の優先順位：

1. **引率スタッフの宿泊費**（現在8名分しか計上できていない）
2. **通訳の増員**（体験の質に直結する）
3. **減免枠の拡充**（外国人コミュニティには必要な家庭が少なくない）

## 9. 国際化で必ず設計が要る点

SYDのベースをそのまま外国の子に適用すると詰まる箇所。**BUSHIDO JAPANが引率者として責任を持つ部分。**

### 9-1. 宗教への配慮 ★最重要

- **SYDが「特定の宗教や政党に属さない」社会教育団体**であることを、募集要項の冒頭に日英で明記する。既存資料にある事実であり、最も強い説明になる
- 内宮参拝は**「日本文化の作法を学ぶ体験」**と位置づける。一礼・手水は礼儀として全員が学ぶが、**何を祈るか／祈らないかは本人の自由**
- **正宮の前で手を合わせない子がいてよい**ことを、保護者説明と当日の両方で明言する
- 清掃奉仕は「奉仕」であって「礼拝」ではない——宗教的な意味づけをしない説明を用意する

### 9-2. 入浴 ★要協議

既存のリーダーマニュアルは「GLは子どもたちと入浴しましょう……スキンシップ」「低学年の頭や体を洗うようサポート」と定める。日本の青少年教育では長年一般的な運用だが、**多くの国では成人スタッフが児童と入浴し身体を洗うことは制度上の禁止事項にあたる。** 海外の保護者にそのまま説明できない。

**BUSHIDO JAPANの引率者については、以下を方針とする。**

| | 方針 |
| --- | --- |
| 入浴 | スタッフは**着衣で脱衣所・浴室入口を見守る**。入浴は子どもだけ |
| 洗身の介助 | 原則行わない。必要時は**同性スタッフ2名以上が立ち会う** |
| 抵抗がある子 | **個別シャワーの時間枠**を設ける |

**大浴場で裸になるという文化そのものを、事前動画で説明する。** 当日いきなり直面させない。

### 9-3. 保護者との連絡

- 国内保護者：LINEオープンチャット（SYD／既存方式に準じる）
- **海外・外国人保護者：パスワード付きの非公開Webページ**を1日3回更新。**LINEは日本・台湾・タイ以外ではほとんど使われていない**
- **初日の夜の一報**（「無事に着いて、笑っています」）が、翌年の参加を決める

### 9-4. 川遊び

**泳力の事前申告を必須化。** 水に慣れていない子は国によって珍しくない。ライフジャケットの用意と泳力別エリア分けを、SYDおよび教育再生いばらきと調整する。

### 9-5. 携帯電話

既存の持ち込み禁止方針を**維持する**。プログラムの質に直結する。
ただし外国の子には、**初日の夜に一度だけ家族への連絡時間（15分）**を設ける。主催側の端末を貸す形なら原則は崩れない。

### 9-6. 食事

**ハラル／ベジタリアン／ヴィーガン／アレルギー**の対応可否をSYDと詰める。
野外炊事のカレーは**ルーの成分（豚由来ゼラチン等）**まで確認が要る。BBQの食材も同様。

### 9-7. 対象年齢

既存合宿は小1〜小6。国際版では、

- 名古屋枠：**小学3年生〜中学2年生**
- 外国人枠：**小学4年生〜中学3年生**（在住の子を主軸にするなら下限を下げられる）

中学生を入れるなら、**上級生に役割を与える**設計が要る。バイリンガルの中学生は**村長／通訳役**として機能させるのが自然。

### 9-8. 引率体制（BUSHIDO JAPAN分）

進行はSYDが担うため、BUSHIDO JAPANは**引率と国際育成層の運営**に必要な人数を置く。

| 役割 | 人数（定員40〜50名時） |
| --- | --- |
| 総括責任者 | 1（上岡） |
| バディ担当・引率 | 6〜8 |
| **通訳** | 2〜3（★削らない） |
| **看護担当** | 1（夜間常駐。SYDとの分担を要確認） |
| 海外・外国人保護者 窓口 | 1 |
| 記録・配信 | 1 |
| **合計** | **12〜15名** |

**事前研修（半日）を必ず実施する。** §9-1（宗教配慮）と§9-2（入浴運用）は、口頭伝達では徹底しない。

## 13. 次の一手

### 順番が決まっている

すべての起点は**修養団の見積**にある。見積がなければ収支予算書が書けず、予算書がなければ後援申請ができず、後援がなければ協賛も学校ルートも動かない。

```
① 修養団への問い合わせ・見積取得        ← 今月中
①' 愛知県に旅行業の該当性を確認         ← 今月中（電話1本。費用ゼロ）
①'' 教育再生いばらきに確認の文脈を聞く   ← 今月中
② 事業計画書・収支予算書の作成          ← 9月上旬
③ 実行委員会の設立（規約・役員）        ← 9月中旬
③' 旅行業の建て付けの確定               ← 9月中旬（必要なら旅行業者へ委託）
④ 後援申請（名古屋市教育委員会 ほか）    ← 9月下旬〜10月上旬（決定まで1〜2か月）
⑤ 協賛募集                            ← 10〜11月
⑥ 募集要項・申込導線の制作             ← 11〜12月（旅行業者の登録番号等の記載が必要）
⑦ 募集開始                            ← 2027年1月1日
```

**131日しかない。①が遅れると、④の後援決定が募集開始に間に合わない。**

### 修養団に一度で聞くこと

1. 2027年7月26〜28日（月〜水）に、BUSHIDO JAPAN枠として30〜50名＋引率スタッフ10〜15名を受け入れられるか
2. 宿泊・食事・施設・プログラム進行の見積（**20,000円は税込か税別か**）
3. **引率スタッフの宿泊費と、減免の可否**
4. 外国籍の子どもの受け入れ実績と、多言語対応の可否
5. 食事対応（ハラル／ベジタリアン／アレルギー）
6. 合気道ができる畳スペースの有無
7. 入浴の運用を、スタッフ着衣での見守りに変更できるか
8. 看護体制の分担

### 今月中に動かす3本

**① 修養団の見積**（上記8項目）、**② 愛知県への確認**、**③ 教育再生いばらきへの確認**。
見積がなければ予算書が書けず、旅行業の建て付けが決まらなければ募集要項が書けない。**どちらも後段のすべてを止める。**

**② 愛知県 旅行業登録担当窓口に伝えること**（§3-5）：

実行委員会主催／小中学生対象の2泊3日／名古屋発着の貸切バス（協賛で無償）と伊勢泊／参加費50,000円／**毎年の開催予定**／**事務局は営利法人**／協賛金を受け入れる。
——この6点を具体的に伝えて判断を仰ぐ。**電話1本で済み、費用はかからない。**

**③ 教育再生いばらきに聞くこと**：

「許可はいらない」という確認を、**どの窓口に、何を前提として尋ねたか。** しおりに取扱旅行社（伊勢國際観光）を立てているのは、その確認とどう関係しているか。
ここが分かれば、同じ整理をこの企画で使えるかどうかの判断がつく。

**委託が必要と判断された場合**、伊勢國際観光に聞くこと：

1. 実行委員会主催の子ども向けキャンプについて、旅行部分の委託を受けられるか
2. その場合の手数料と、参加費50,000円の建て付け（旅行代金部分の切り分け方）
3. 募集要項・パンフレットへの記載義務（登録番号、旅行業務取扱管理者名など）
4. 名古屋発着（バスは協賛）・伊勢泊という条件で、実務上の留意点
