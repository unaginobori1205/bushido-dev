レベル1

AIにSNS管理の“雑務”をやらせる

5:30–15:30

軸：SNS管理の土台。「考える・書く・まとめる」をAIに渡す。

Before：投稿文に30分→After：30秒
～2分

① 音声入力で“考えを吐き出す”

きれいに書く前にまず喋る。20〜30秒喋ってAIが整文。「文章が苦手”でも問題ない」

～3分

② NotebookLMで例会・会社資料を要約

資料を読み込ませ「3行要約・要点5つ・想定質問」。初心者：“その資料だけ”を読むからウソが少ない。

～3.5分

③ SNS投稿を3媒体に一発展開

1つの素材→Instagram／X／Facebook。デモしながらプロンプトをテロップ表示。

📋コピペ用プロンプト（レベル1）
初級・SNS1つの素材を3媒体に展開
次の内容を、以下3媒体向けの投稿文に書き分けてください。
- Instagram：共感から入る本文＋ハッシュタグ10個
- X（旧Twitter）：140字以内のフック＋スレッド3連投
- Facebook：背景と想いが伝わる丁寧な長文
素材：（ここに出来事・写真の説明・伝えたいことを貼る）
読み手が「自分ごと」と感じる一文から始めてください。
初級・整理例会・会社資料を一発で要約
この資料を読み込み、以下を出力してください。
1. 3行要約
2. 重要ポイント5つ
3. 会議で確認すべき論点3つ
4. 想定質問と回答3組
資料に書いてある内容だけを根拠にしてください。
30秒まとめ
テイクアウェイ：「今日コピペするだけで、SNS投稿は今日から楽になる」
レベル2

AIを“部下”にして成果物を作らせる

15:30–25:30

軸：SNS管理で鍛えた指示力を、議案・商談・スライドに転用。

Before：会議資料に30分→After：3分で叩き台
～3分

① 議案構築（JC直結）

目的／背景／課題／効果／予算／スケジュールをAIで骨子化。「ゼロから書かない。叩き台を作らせて直す」

～3分

② パートナーとの商談準備

相手企業のリサーチ→刺さる提案ストーリー→想定問答まで。「商談は“準備”で決まる」

～3分

③ スライド作成

「目的・対象・枚数・トーン」の4点→構成済みスライド。「今見てるこの資料もこう作った」

📋コピペ用プロンプト（レベル2）
中級・議案企画を“理事会を通る議案”にする
あなたはJC（青年会議所）の議案作成に精通した事務局長です。
次の企画を、理事会を通る議案ドラフトに整えてください。
企画の一言：（例）地域の高校生向けAI体験ワークショップを開催したい
出力（この順番で）：
1. 事業名（案を3つ）
2. 目的（3行）
3. 背景・現状の課題
4. 事業内容（実施概要・対象・人数・場所）
5. 期待される効果（参加者／地域／JC会員の3視点）
6. 概算予算（費目と金額の表、ざっくりでOK）
7. スケジュール（準備〜当日〜報告まで）
8. 理事会で出そうな質問と回答を3組
専門用語は避け、初めて読む理事にも伝わる言葉で。
中級・商談パートナー商談の準備を丸ごと
あなたは法人営業のトッププレイヤーです。次の商談を準備してください。
- 自社：（例）障害者グループホームの運営
- 相手：（例）地域の医療法人 / 不動産オーナー
- 商談のゴール：（例）入居者紹介の連携 / 物件の提供
出力：
1. 相手にとっての“うれしいこと”を3つ（相手目線の利益）
2. 提案ストーリー（課題→解決→一緒にやる絵）を5ステップ
3. 最初の30秒で言う一言（つかみトーク）
4. 想定される懸念と切り返しを3組
5. 次のアクション（着地点）の提案
分かっている相手情報：（あれば貼る）
中級・スライド箇条書きを構成済みスライドに
次の条件でプレゼン資料の構成（各スライドのタイトル＋箇条書き本文）を作ってください。
①目的：（例）理事会で〇〇事業の承認を得る
②対象：（例）多忙で結論を急ぐ理事
③枚数：8枚
④トーン：簡潔・論理的・数字重視
「現状→課題→提案→効果→費用→スケジュール→お願い」を含めてください。
30秒まとめ
テイクアウェイ：「JCの議案も商談も“SNS管理と同じ指示の出し方”でできる」
レベル3

仕組み化＝ルーティーン管理

25:30–35:30

軸：単発で終わらせず、毎週ラクに回る仕組みにする。

Before：毎週ゼロから→After：仕込み3分で回る
～4分

① ルーティーン管理

週次のSNS運用＆JC業務をテンプレ＋AIで回す。デモ：「今週の投稿7本＋運用表」一括生成（＝コールドオープンの種明かし）

～3分

② 情報を資産化（Notion／Obsidian）

プロンプト・議事録・ナレッジを一ヶ所に＝second brain。「個人の工夫を組織の資産に」

～2.5分

③ 半自動ルーティーンの全体像

「ソースを整える→生成ボタン」まで仕組み化。完全自動の限界も正直に説明。

📋コピペ用プロンプト（レベル3）
上級・運用今週のSNS運用表＋投稿7本を一括生成
あなたは私専属のSNS運用マネージャーです。「今週の運用表」を作ってください。
- アカウントの目的：（例）グループホームの認知と見学申込
- 媒体：Instagram / X / Facebook
- 今週のテーマ：（例）スタッフの1日・入居者の声
- 投稿本数：7本（曜日ごと）
出力：
1. 週間カレンダー表（曜日／媒体／テーマ／投稿文／ハッシュタグ）
2. 各投稿の本文（そのまま使える完成形）
3. 画像・動画の指示メモ（何を撮るか）
4. 今週の“伸ばす一手”を1つ
家族目線のやさしい言葉で、宣伝くさくしないこと。
上級・資産化AI活用を資産にするNotion設計
あなたは情報整理（PKM）の専門家です。私のAI活用を“資産”にするNotion構成を提案してください。
管理したいもの：プロンプト集／議事録／SNS投稿アーカイブ／JC議案
出力：
1. データベース構成（名前・用途・主なプロパティ）
2. 各データベースの使い分けルール
3. 毎週のルーティーン（何を・いつ・どう記録するか）5ステップ
4. 最初の1週間でやることチェックリスト
初心者でも迷わないよう、具体名で。
30秒まとめ
テイクアウェイ：「仕組み化すれば、AIが“毎週働く部下”になる」
Q

質疑応答＋締め

35:30–45:00

沈黙対策に、初心者の不安に先回りした“仕込みQ”を3つ用意。

  1. 無料でどこまでできる？—今日のデモの大半は無料枠で可能。まずそこから。
  2. 情報漏れは大丈夫？—機密・個人情報は入れないルールを決める。法人プランの選び方も一言。
  3. 結局どれから？—レベル1の「3媒体展開」を1回やるだけ。
締めの一言

「明日、1個でいいから試してください。それが一番の近道です」—最後にアンケートQR＋Drive共有マニュアル案内。
