# プレジャーハウス｜コインランドリー店内掲示 集客システム

コインランドリー各店舗の待ち時間を使って、**店内ポスター → QR → 簡易診断 → 相談申込 → 顧客管理**まで
一気通貫で回すための一式です。すべて静的HTML＋Googleスプレッドシート（Apps Script）で動き、月額費用はかかりません。

## 構成

| ファイル | 役割 |
|---|---|
| `poster.html` | **店内掲示ポスター（A3縦）**。店舗を選ぶとQRが自動生成され、そのまま印刷／PDF保存できます |
| `index.html` | **簡易診断LP**。6問30秒の診断 → 結果表示 → 無料点検・相談の申込フォーム |
| `admin.html` | **問合せ顧客管理システム**。一覧・絞り込み・ステータス管理・対応メモ・CSV出力・店舗別の反響集計 |
| `gas/Code.gs` | バックエンド（Google Apps Script）。スプレッドシートへの保存・更新、新規問合せのメール通知、日次リマインド |
| `assets/config.js` | 店舗マスタ・API URL・ステータス定義などの設定ファイル |
| `assets/style.css` | 共通スタイル |
| `assets/qrcode.js` | QRコード生成ライブラリ（qrcode-generator / MIT）。同梱済みのためオフラインでも印刷できます |

## 導入手順

### 1. バックエンド（10分）
1. Googleスプレッドシートを新規作成し、シート名を **`問合せ`** に変更
2. **拡張機能 → Apps Script** を開き、`gas/Code.gs` の内容を貼り付け
3. `NOTIFY_TO` に通知先メールアドレスを設定（空ならメール通知なし）
4. `setup()` を1回実行してヘッダー行を作成
5. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
6. 発行された `https://script.google.com/macros/s/.../exec` をコピー

### 2. フロント（5分）
`assets/config.js` を編集します。

```js
API_URL: "https://script.google.com/macros/s/xxxxx/exec",  // 手順1でコピーしたURL
ADMIN_TOKEN: "pleasure-house-2026",                        // Code.gs の TOKEN と必ず同じ値に
FORM_BASE_URL: "https://<公開先>/index.html",              // QRの遷移先
STORES: [ { code: "sakae", name: "コインランドリー栄店" }, ... ]  // 掲示先を追加
```

`index.html` / `poster.html` / `admin.html` / `assets/` を、GitHub Pages・Netlify・レンタルサーバー等に
そのままアップロードすれば公開できます（サーバーサイド不要）。

> `API_URL` が空のままでも **デモモード**（ブラウザのローカル保存）で全機能を試せます。
> `admin.html` の「サンプルデータを入れる」ボタンで動作確認できます。

### 3. ポスターを印刷
1. `poster.html` を開く
2. 掲示する店舗を選ぶ → QRに `?store=店舗コード` が自動で付与されます
3. 「印刷 / PDF保存」→ 用紙 **A3縦**、**背景のグラフィックをON**、余白なし
4. 店舗ごとに繰り返して、店舗数ぶん出力

## 運用の流れ

```
店内ポスター（店舗ごとに固有QR）
   ↓ 洗濯の待ち時間にスマホで読み取り
簡易診断（6問・個人情報入力なし）
   ↓ TYPE A〜D の結果と削減額の目安を表示
相談申込フォーム（氏名・電話・地域・希望時間帯）
   ↓ 送信と同時に
スプレッドシートに記録 ＋ 担当者へメール通知
   ↓
admin.html で架電・訪問・提案・成約まで進捗管理
```

### 診断タイプと営業の優先順位
| タイプ | 判定 | 対応方針 |
|---|---|---|
| **TYPE A** | 太陽光設置済み（蓄電池なし）／高スコアの戸建て | 最優先。蓄電池追加・初期費用0円プランを提案 |
| **TYPE B** | 条件次第で効果が見込める戸建て | 屋根条件の確認＋無料シミュレーションでアポ化 |
| **TYPE C** | 削減余地は小さめ | 無料点検（床下・天井裏含む）を入口に関係構築 |
| **TYPE D** | 賃貸・マンション | 実家・親族の相談、将来のマイホーム計画として保有 |

### 管理画面でできること
- KPI：問合せ合計／今月／未対応／**フォロー期日到来**／アポ以降／成約・成約率
- 絞り込み：店舗・ステータス・診断タイプ・受付日・フリーワード（氏名/電話/地域）
- 詳細パネル：ステータス、次回連絡予定日、担当者、対応メモ（日時スタンプ挿入ボタン付き）、ワンタップ発信
- **店舗別の反響グラフ**：どの店舗のポスターが効いているかが一目でわかります
- CSVダウンロード（Excel対応・BOM付き）
- `Code.gs` の `dailyReminder()` を日次トリガーに設定すると、未対応・期日到来案件が毎朝メールで届きます

## 注意事項
- 掲示前に必ず各コインランドリー運営会社／オーナーの掲示許可を取得してください。ポスター下部に
  「本掲示は店舗運営とは関係のない告知です」の一文を入れています。
- 診断結果・削減額はすべて参考シミュレーションであり、効果を保証するものではない旨を
  ポスター・診断結果の両方に明記しています。
- 申込フォームには利用目的への同意チェックを必須にしています。取得した個人情報は
  無料点検・シミュレーションのご案内以外に利用しないでください。
- `ADMIN_TOKEN` は管理画面のJSに含まれるため、`admin.html` は公開URLに置かず、
  社内共有・BASIC認証配下・ローカル利用のいずれかで運用してください。
