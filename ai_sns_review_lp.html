①START
AIを始める前に、まず目的を決める

やり方の前に「目的」を決める。目的なき発信は続きません。だからここから始めます。

やらないとどうなるか

知られない＝選ばれない。発信しない会社・活動は「無い」のと同じになっていく。

誰のために価値を提供するのか

フォロワー数ではなく「誰の・どんな悩みに・どんな価値を」。

なぜ自社（自分）なのか

他でもない自分が発信する理由＝独自の想い・経験・強み＝共感の源。

目的自社の「発信コンセプト」を言語化する
私（自社）のSNS発信の軸を一緒に言語化してください。次の順で1つずつ質問し、私の答えをもとに整理してください。
1. 理念：なぜ発信するのか（根っこの想い）
2. 目的：何のために（事業・採用・仲間づくり 等）
3. ゴール：どうなったら成功か（数値や状態）
4. 誰のために：届けたい相手は誰で、どんな悩みを持っているか
5. 提供価値：その人にどんな価値を届けるか
6. なぜ自分か：他でもない自分・自社が発信する理由（独自の経験・強み）
最後に、以上を2〜3行の「発信コンセプト」にまとめてください。

③DEMO 1
担当例会をSNS投稿化する

例会情報を入れるだけで、投稿文・リール台本・ハッシュタグ・撮影指示まで一気にそろう。広報で一番大変な「何をどう伝えるか」をAIがたたき台に。

実演1担当例会をSNS広報セットに一括変換
あなたはJCの広報に強い編集者です。次の例会情報をもとに、SNS広報セットを一式作ってください。
【例会情報】（日時・会場・テーマ・登壇者・狙いを貼る）
出力：
1. SNS投稿文（Instagram用・共感から入る本文）
2. ストーリーズ用の短文（3枚分）
3. リール用ナレーション（30秒）
4. 告知タイトル案を3つ
5. ハッシュタグ10個
6. 「参加したくなる一言」
7. 委員会メンバーへの依頼文（撮影・拡散のお願い）
8. 当日の写真・動画の撮影指示リスト
※日付・会場・登壇者名は変えず、想いが伝わる温度感で。

⑤DEMO 3
AI秘書・自分専用のAIチーム

SNSだけでなく日々の業務にも。よく使うものは“型”にすると、個人のスキルが組織の資産に。Claude Codeなら役割別のAIチームも作れます。

実演3朝の“今日の動き方”を整理（AI秘書）
あなたは私専属のAI秘書です。次の情報から「今日の動き方」を整理してください。
【入力】今日の予定／未読の連絡／抱えているタスク／JC関連の締切（箇条書きで貼る）
出力：
1. 今日やるべきこと（優先順位つき）
2. 返信すべき連絡と、その返信案
3. 今日のSNS投稿の確認事項
4. 昨日からの持ち越し
5. 今日の注意点
6. 誰に何を連絡すべきか
実演3AIチームに今週のSNSを回させる（Claude Code）
今週のSNSを回して。次の順で進めて、最後にまとめて。
1. ネタ収集エージェント：今週の話題・写真メモから投稿ネタを3つ出す
2. 投稿作成エージェント：3媒体×各2本の投稿文を作る
3. 校正・炎上チェックエージェント：誤字と炎上しそうな表現を点検して直す
最後に、月〜日の投稿カレンダー（曜日／媒体／本文）にまとめて。
🏢“自分専用のAI会社”の作り方（かんたん版）

むずかしくありません。Claude Code に、あなたの毎朝のルーティンを順番に教えていくだけ。教えたぶんだけ、AIが“社員”のように動きます。メール操作などはブラウザで制作（Claude in Chrome）、仕組み化は Claude Code で。

  1. 毎朝やっていることを書き出す（メール確認 → 振り分け → 返信下書き…）
  2. Claude Code に1つずつ教える（「まずメールを見て、緊急だけ教えて」など）
  3. うまくいったら“役割”に分ける（メール係／情報収集係／まとめ係）
  4. 毎朝ひとこと「おはよう、今日の準備して」で全部動く
✅ルーティンに含められること
  • メールのチェックと振り分け（至急／後で／不要）＋返信の下書き作成
  • 今日の天気の取得
  • Googleスプレッドシート・Notion への記録・共有・連携
  • 今日の予定・タスクを優先順に整理
AI会社毎朝のルーティンを教える（最初の一歩）
あなたは私専属のAIアシスタント（秘書）です。私の毎朝のルーティンを自動化したい。
まず次の作業を順番に手伝って。1つずつ、結果を見せながら進めて。
1. メールを確認し「至急／後で／不要」に振り分けて一覧にする
2. 「至急」への返信の下書きを作る（送信はしない）
3. 今日の天気を教える
4. 今日の予定・タスクを優先順にまとめる
5. まとめをGoogleスプレッドシート（またはNotion）に記録できる形にする
うまくいったら、この手順を毎朝の“いつもの流れ”として覚えて。
安全に：メールの操作は必ず確認しながら。「送信・削除」など後戻りできない操作は自分で最終確認を。まずは「振り分け・下書き・まとめ」まで任せるのがおすすめです。
⑥CARE
AIを使うときの注意点
  • 個人情報・機密情報・未公開情報をそのまま入れない
  • AIの文章をそのまま使わず、最後は人が確認する
  • 日付・会場・金額・登壇者名は必ず自分で確認する
  • 事実と想いを分けて扱う／AIは補佐役、最終責任者ではない
ひとこと：AIを使うほど、人間の確認力と判断力が大切になります。
⑦SETUP
まず環境を整える（課金・導入）

「まず何に課金すればいい？」——課金するなら、まずはClaude。3,000円から“自動化”をスタートできます。

💳 課金するなら、まずは Claude（3,000円〜で自動化スタート）

パソコンでやっている作業の「時短・自動化」からやってみてください。まずClaudeを1つ課金して、PC作業をAIに任せるのが一番の近道です。その他のツール（NotebookLM・画像/動画/音楽生成など）は無料でも十分使えますので、まずはClaudeから。（料金・プランは変わることがあるので公式で確認）

もう一歩進みたい方へ：ChatGPT・Gemini（ジェミニー）も、有料版（月3,000円ほど）にすると回答の質・使える機能が上がります。用途が広がってきたら、必要に応じて追加するのがおすすめです（まずはClaude → 次にChatGPT／Gemini）。
🔌入れておくと便利な Claude 連携
  • Claude in Chrome：ブラウザ上でそのままAIに相談・作業。開いている議案やページをAIに読ませたり、操作が分からない時に代わりに動いてもらえる
  • Claude in PowerPoint：スライド作成をAIに手伝わせる
  • Claude in Excel：表計算・集計・関数をAIに任せる
  • Claudeデスクトップ版：PC全体で使える。ファイルもまとめて扱える
▶️Claude in Chrome で「画面を動かす」実例プロンプト

下のプロンプトをコピーして、今見ているページでClaude in Chromeに投げてみてください。AIがブラウザを操作します。まずは害のない操作から。

Chrome①今開いているページを要約させる
今このタブで開いているページを読んで、次を出して。
1. 3行要約
2. 重要ポイント5つ
3. SNS投稿に使える切り口を3つ
（ページを操作する必要はありません。表示内容だけ読んで）
Chrome②検索して結果を表にまとめさせる（画面を動かす）
「名古屋 若手経営者 交流会」でGoogle検索して、上位5件の
「タイトル／URL／ひとこと概要」を表にまとめて。
各リンクを開いて確認する場合は、開く前に一覧を見せて。
Chrome③入力欄に下書きを入れる（送信はしない）
このページに投稿・入力欄があれば、次の内容で下書きを入力して。
【入れたい内容】（ここに投稿文やメモを貼る）
※重要：私が確認するので、入力までにして「送信」は絶対に押さないで。
Chrome④長いページから必要な情報だけ抜き出す
このページから、次の項目だけ抜き出して箇条書きにして。
・日時 ・場所 ・料金 ・申込方法 ・問い合わせ先
見つからない項目は「記載なし」と書いて。
Chrome⑤ブラウザで開いた議案を読ませて要点を出す
今このタブで開いている議案（またはPDF）を読んで、次を出して。
1. この議案の目的を3行で
2. 背景・現状の課題
3. 予算・スケジュールの要点
4. 理事会で質問されそうな点と、その回答案を3つ
専門用語は、初めて読む人にも分かる言葉に直して。
Chrome⑥操作が分からない時に、代わりに動いてもらう
このサイトで「〇〇（やりたいこと）」をしたいのですが、やり方が分かりません。
どこを押せばいいか画面を見て教えて。
そのまま代わりに操作してくれてもOKです。ただし
「送信・購入・申込の確定」だけは、実行前に必ず私に確認してください。
安全に使うコツ：Claude in Chromeは操作の前に確認を求めます。ログイン中の重要サイト（銀行・決済・会員管理）では使わない／「送信・購入・削除」など後戻りできない操作は自分で最終確認。まずは要約・検索・下書き入力など、害のない操作から試すのがおすすめです。
🐙GitHub（ギットハブ）とは？

ファイルの変更履歴を管理・共有する“クラウドの保管庫”です。Claude Code と組み合わせると、AIに作らせた資料やコードを安全に保存・バージョン管理・共有できます。「いつ・何を・どう変えたか」が全部残るので、チームやJCの委員会での共同作業にも向いています。今日の資料も、実はGitHubで管理しています。

🧾使えそうな税制優遇（節税）
  • 少額減価償却資産の特例：1個40万円未満（2026年4月〜。従来30万円）のPC・ソフト・AIツール等を、年間300万円まで全額経費に（中小企業・青色申告）。令和11年3月末まで延長。
  • 中小企業経営強化税制：認定「経営力向上計画」に基づく設備・ソフトウェアで即時償却 or 10%税額控除（資本金3,000万円超は7%）。
  • 中小企業投資促進税制：機械・一定のソフトウェアで30%特別償却 or 7%税額控除。
  • クラウド利用料・サブスク（月額）は経費（損金）に計上できる。
ポイント：補助金＝“もらう”／税制＝“納める税を減らす”。両方を組み合わせると導入コストをぐっと下げられます。適用可否は必ず税理士に確認を。
