AI時代のSNS実践セミナー（進行台本・NotebookLM用ソース）
サブタイトル：半年でここまでできる。AI秘書・SNS運用・資料作成・プロンプト活用のリアル実演

キーメッセージ：AIは、知っている人が勝つのではなく、使った人から変わっていく。
=====================================================

■ 全体の目的
AIの専門知識を学ぶ時間ではない。JC活動・SNS発信・例会準備・資料作成・タスク管理を、AIで現実的に楽にするための実践型セミナー。
参加者の持ち帰り：
・AI活用の現在地を体感する
・自分の担当例会や委員会活動に使うイメージを持つ
・今日または明日、実際に一つ使ってみる
・学んだことを誰かに伝える
・共有資料・プロンプト集で継続的に実践する

① 自己紹介はさらっと（19:15–19:20）
-----------------------------------------------------
目的：「この人がなぜAI・SNSを語るのか」を短時間で伝える。
・名古屋JCでの経験（2023年 JCブランディング）
・麻生会頭、裏千家、たけし、スイス、ジャカルタ、タイでの鰻屋出店など印象的な経験
・2024年 渉外常任として名古屋の広報物を多く確認・添削
・現在、一人で複数のSNSアカウントを運用
・AI歴は本格的にはまだ半年程度
口頭イメージ：今日はAIの専門家としてではなく、実際にJC活動・事業・SNS運用の中でAIを使い倒してきた実践者として話します。本格的に業務で使い始めたのはまだ半年ほど。でも半年で、資料作成・SNS投稿・タスク整理・情報共有・仕事の進め方が大きく変わりました。今日はそのリアルな活用例を実演しながら共有します。

② AI秘書システム実演（19:20–19:28）
-----------------------------------------------------
目的：最初に大きなインパクト。「AIは検索の延長ではなく、日常業務や意思決定の補助まで進んでいる」と体感。
見せる内容（朝、AI秘書で自動チェック）：今日の予定／やるべきこと／返信すべき連絡／SNS投稿の確認／各事業の進捗／JCタスク／優先順位／昨日からの持ち越し／今日の注意点／誰に何を連絡すべきか。
伝えるメッセージ：頭の中で全部思い出す時代から、AIに整理させ自分は判断と行動に集中する時代へ。AIは秘書・壁打ち相手・編集者・広報担当・企画補佐になってきている。

【プロンプト：朝の“今日の動き方”を整理】
あなたは私専属のAI秘書です。次の情報から「今日の動き方」を整理してください。
【入力】今日の予定／未読の連絡／抱えているタスク／JC関連の締切（箇条書きで貼る）
出力：
1. 今日やるべきこと（優先順位つき）
2. 返信すべき連絡と、その返信案
3. 今日のSNS投稿の確認事項
4. 昨日からの持ち越し
5. 今日の注意点（抜け漏れ防止）
6. 誰に何を連絡すべきか

③ AI歴半年でここまで来た背景（19:28–19:34）
-----------------------------------------------------
目的：「自分にもできそう」と思ってもらう。
・ChatGPT直後から検索補助・壁打ちには使っていた

・今年1月頃の大きな変化でNotebookLMやClaudeを知った
・毎月課金して本格的に使い始めた
・半年で時短・自動化・SNS運用・資料作成・情報整理が一気に進んだ
・嶺田会長に報告・相談 → 今回の講師の機会に
口頭イメージ：最初はChatGPTを検索の延長くらいにしか使っていなかった。業務で本格的に使うにはまだ早いかなと。でも今年1月頃から一気に見え方が変わった。実際に課金して使い始めて、これは単なる検索ではなく、仕事のやり方そのものを変えるものだと感じた。

④ ブレインアクティベーション：今日の目的設定（19:34–19:40）

口頭イメージ：使い方を知るだけなら動画で十分。実際に使って、誰かに伝えて初めて力になる。今日・明日のうちに何か一つ実行し、委員会・会社・家族の誰かに教えてみてください。教えることが一番自分の理解を深めます。

⑤ AI活用の現在地（19:40–19:48）
-----------------------------------------------------
目的：AIツールの全体像をシンプルに。役割ごとに使い分ける時代。

伝えるメッセージ：全部を覚えることではなく、自分の仕事のどの作業をAIに手伝わせるかを決めること。

⑥ 実演1：担当例会をAIでSNS投稿化する（19:48–20:00）
-----------------------------------------------------
目的：最も身近なJC活動でAI活用を体感。題材は参加者の7月例会をその場で事例化。
NotebookLMに例会情報を入れて作るもの：SNS投稿文／ストーリーズ文／リール用ナレーション／告知タイトル／ハッシュタグ／参加したくなる一言／委員会メンバーへの依頼文／写真・動画の撮影指示。
口頭メッセージ：広報で一番大変なのは投稿文より「何をどう伝えるか」を考える時間。AIでたたき台を一瞬で作り、人間は想いと温度感を加える。

【プロンプト：担当例会をSNS広報セットに一括変換】
あなたはJCの広報に強い編集者です。次の例会情報をもとに、SNS広報セットを一式作ってください。
【例会情報】（7月例会の日時・会場・テーマ・登壇者・狙いを貼る）
出力：
1. SNS投稿文（Instagram用・共感から入る本文）
2. ストーリーズ用の短文（3枚分）
3. リール用ナレーション（30秒）
4. 告知タイトル案を3つ
5. ハッシュタグ10個
6. 「参加したくなる一言」
7. 委員会メンバーへの依頼文（撮影・拡散のお願い）
8. 当日の写真・動画の撮影指示リスト
※日付・会場・登壇者名は変えず、想いが伝わる温度感で。

⑦ 実演2：画像・動画生成プロンプト（20:00–20:10）
-----------------------------------------------------
目的：SNSで使えるビジュアル作成の可能性を見せる。
内容：例会告知画像のイメージ案／リール動画の構成／15秒ショート動画の台本／9:16縦型動画のプロンプト／日本語と英語プロンプトの違い。
伝えるメッセージ：広報担当に必要なのはデザイン技術だけでなく「世界観を言語化する力」。AIに任せる前に、人間が何を伝えたいかを明確に。

【プロンプト：画像・動画生成プロンプトを作る】
次の例会／事業のテーマから、SNS用ビジュアルの素材プロンプトを作ってください。
テーマ：（例）7月例会「〇〇」／対象：地域の若手経営者
出力：
1. 告知画像のイメージ案（雰囲気・色・構図を言葉で）3案
2. リール動画の構成（0-5秒／5-10秒／10-15秒）
3. 15秒ショート動画の台本（ナレーション＋テロップ）
4. 9:16縦型動画の生成プロンプト（日本語）
5. 上記の英語プロンプト版（画像生成AI用）
※最初に「何を伝えたいか（世界観）」を1行で言語化してから作ること。

⑧ 実演3：AI秘書・ショートカット・スキル活用（20:10–20:18）
-----------------------------------------------------
目的：SNSだけでなく、日々の業務やJC活動全体にAIを使えることを見せる。
内容：毎朝のタスク整理／会議前の準備／議事録からToDo作成／LINE・メール返信案／Driveのマニュアル化／プロンプトのテンプレート化／ショートカット・スキル活用／Claude Codeで“自分専用のAIチーム”を作る。
共有：実演で使ったプロンプト・ショートカット・スキルはGoogle Driveのマニュアルにまとめて共有。
伝えるメッセージ：一回使って終わりでなく、よく使うものは型にする。型にすると個人のスキルが組織の資産になる。

【プロンプト：議事録からToDoと連絡事項を抽出】
次の議事録から、ToDoと連絡事項を抜き出してください。
【議事録】（貼る）
出力：
1. ToDo（担当・期限つき）
2. 決定事項
3. 保留・要確認事項
4. 誰に何を連絡するか（連絡文の案つき）

【プロンプト：投稿作成エージェントを作る（Claude Code /agents → Generate with Claude に貼る）】
SNS投稿を作る専門エージェントを作って。
役割：渡されたネタメモから、Instagram・X・Facebookの3媒体ぶんの投稿文を作る。
ルール：
- 家族目線のやさしい言葉。宣伝くさくしない
- 媒体ごとの作法に合わせる（インスタ＝共感＋ハッシュタグ／X＝短く／FB＝丁寧）
- 個人情報・機密は書かない
使うツール：ファイルの読み書きのみ（最小限）

【プロンプト：AIチームに今週のSNSを回させる（一括指示）】
今週のSNSを回して。次の順で進めて、最後にまとめて。
1. ネタ収集エージェント：今週の話題・写真メモから投稿ネタを3つ出す
2. 投稿作成エージェント：3媒体×各2本の投稿文を作る
3. 校正・炎上チェックエージェント：誤字と炎上しそうな表現を点検して直す
最後に、月〜日の投稿カレンダー（曜日／媒体／本文）にまとめて。

⑨ JC活動でAIを使う時の注意点（20:18–20:23）
-----------------------------------------------------
目的：便利さだけでなく最低限のリスク管理も伝える。
・個人情報を不用意に入れない
・未公開情報・機密情報をそのまま入れない
・AIの文章をそのまま使わず、最後は人間が確認する
・日付・会場・金額・登壇者名は必ず確認する
・事実と想いを分けて扱う
・AIは最終責任者ではなく、補佐役である
伝えるメッセージ：AIを使うほど、人間の確認力と判断力が大切になる。
