★ なぜSNSなのか — 目的から始める（19:18–19:24）
-----------------------------------------------------
ねらい：やり方（HOW）の前に目的（WHY）を握る。「目的なき配信は続かない」を最初に伝える。
フレーム：理念（なぜやる）→ 目的（何のため）→ ゴール（成功の状態）→ 誰のために（届ける相手）→ なぜ自社（独自の理由）
話す内容：
・なぜSNSなのか：人の心と行動はSNSで動く時代。事業も仲間集めも、まず「知ってもらう」から。
・やらないとどうなるか：知られない＝選ばれない。発信しない会社・活動は「無い」のと同じになっていく。
・議案と同じ：JC議案で一番大事なのは背景と目的。SNSも手段から入ると続かない。
・目的なき配信は消滅する：ネタ切れ→反応なし→やめる、の悪循環。目的があるから続く。
・理念・目的・ゴールを先に決める。
・誰のために価値を提供するのか：フォロワー数でなく「誰の・どんな悩みに・どんな価値を」。
・なぜ自社（自分）なのか：他でもない自分が発信する理由＝独自の想い・経験・強み。共感の源。
口頭イメージ：AIの話に入る前に、一番大事なこと。なぜSNSをやるのか。やり方だけ覚えても目的がないと続かない。これはJCの議案と同じで、一番大事なのは背景と目的。目的なき配信は消えていく。だから理念・目的・ゴールを決め、誰のために何の価値を届けるのか、そしてなぜ自分が発信するのかを言葉にする。AIはその想いを速く広く届ける道具。

【プロンプト：自社の「発信コンセプト」を言語化する】
私（自社）のSNS発信の軸を一緒に言語化してください。次の順で1つずつ質問し、私の答えをもとに整理してください。
1. 理念：なぜ発信するのか（根っこの想い）
2. 目的：何のために（事業・採用・仲間づくり 等）
3. ゴール：どうなったら成功か（数値や状態）
4. 誰のために：届けたい相手は誰で、どんな悩みを持っているか
5. 提供価値：その人にどんな価値を届けるか
6. なぜ自分か：他でもない自分・自社が発信する理由（独自の経験・強み）
最後に、以上を2〜3行の「発信コンセプト」にまとめてください。

⑧ 実演3：AI秘書・ショートカット・スキル活用（19:59–20:07）
-----------------------------------------------------
目的：SNSだけでなく、日々の業務やJC活動全体にAIを使えることを見せる。

伝えるメッセージ：一回使って終わりでなく、よく使うものは型にする。型にすると個人のスキルが組織の資産になる。

【プロンプト：議事録からToDoと連絡事項を抽出】
次の議事録から、ToDoと連絡事項を抜き出してください。
【議事録】（貼る）
出力：
1. ToDo（担当・期限つき）
2. 決定事項
3. 保留・要確認事項
4. 誰に何を連絡するか（連絡文の案つき）

【プロンプト：投稿作成エージェントを作る（Claude Code /agents → Generate with Claude に貼る）】
SNS投稿を作る専門エージェントを作って。
役割：渡されたネタメモから、Instagram・X・Facebookの3媒体ぶんの投稿文を作る。
ルール：
- 家族目線のやさしい言葉。宣伝くさくしない
- 媒体ごとの作法に合わせる（インスタ＝共感＋ハッシュタグ／X＝短く／FB＝丁寧）
- 個人情報・機密は書かない
使うツール：ファイルの読み書きのみ（最小限）

【プロンプト：AIチームに今週のSNSを回させる（一括指示）】
今週のSNSを回して。次の順で進めて、最後にまとめて。
1. ネタ収集エージェント：今週の話題・写真メモから投稿ネタを3つ出す
2. 投稿作成エージェント：3媒体×各2本の投稿文を作る
3. 校正・炎上チェックエージェント：誤字と炎上しそうな表現を点検して直す
最後に、月〜日の投稿カレンダー（曜日／媒体／本文）にまとめて。
