AIに働かせ、想いを届ける時代へ

JC活動・社業・SNSを進化させる実践型AIセミナー。各スライドのねらい・話す内容・演出と、デモでそのまま使えるコピペ用プロンプトをまとめた登壇台本です。

想定時間：約90分（デモ各5〜7分）／ 名古屋JC SNS戦略部会
◎

この台本の使い方・全体設計

感情の波で設計しています。笑い → 信頼 → 自分ごと化 → 実演の衝撃 → 想いで締め。各スライドは「ねらい／話す内容／演出」の3点セット、デモ枠にはコピペ用プロンプトを入れています。

→

→
自分ごと8枚
→

→
想いで締め23枚
通底メッセージ

AIは「使う」ではなく「働かせる」。作業を圧縮し、空いた時間で“人にしかできない想いを届ける”。知識ではなく「明日、自分のPCで1個やってみる」を持ち帰らせるのがゴール。

NotebookLMプロンプト

プロンプト
ねらい

1つの資料から複数の成果物を量産できると示す。

話す内容
同じ資料から“要約／議事録／SNS投稿文／想定問答”を一気に。会議後30分の作業が、30秒になります。
演出・小ネタ
🎬プロンプト4種をその場で実行して見せる。
📋コピーして使えるプロンプト（4種）
要約・整理資料を多面的に1発で整理する
この資料を読み込み、以下の形式で整理してください。
1. 3行要約
2. 重要ポイントを5つ（各1行）
3. 会議で確認すべき論点を3つ
4. SNS投稿に使える切り口を3つ
5. 30秒で話せるスピーチ原稿
6. 想定される質問と回答を3組
議事録化録音・メモから議事録を作る
この資料（または文字起こし）から、配布用の議事録を作成してください。
- 形式：日時／参加者／議題ごとの「決定事項」「保留事項」「ToDo（担当・期限）」
- 文体：です・ます調、簡潔に
- 最後に「次回までの宿題」を箇条書きでまとめる
SNS化資料を3媒体の投稿文に変える
この資料の内容を、以下3媒体向けの投稿文に書き分けてください。
- Instagram：共感から入る本文＋ハッシュタグ10個
- X（旧Twitter）：140字以内のフック1本＋スレッド3連投の構成
- Facebook：少し丁寧に、背景と想いが伝わる長文
それぞれ、読み手が「自分ごと」に感じる一文から始めてください。
質問生成理解を深める想定問答をつくる
この資料について、理解度を確認するための質問を作ってください。
- 初級5問（用語・事実確認）
- 中級5問（背景や狙いを問う）
- 応用3問（自分の事業にどう活かすか）
各質問に、資料を根拠にした模範解答も付けてください。

Flowプロンプト

プロンプト
ねらい

“設計図さえ書けば映像になる”を持ち帰らせる。

話す内容
“誰に・何を感じてほしいか”を書くだけで、30秒シナリオと絵コンテが出ます。撮影前の設計が一瞬で終わります。
演出・小ネタ
🎬シナリオ生成 → そのまま映像プロンプトに変換する流れを見せる。
🎞️コピーして使えるプロンプト（2種）
シナリオ30秒動画のシナリオ＋絵コンテ
あなたはプロの動画ディレクターです。次の条件で30秒動画の構成を作ってください。
- 目的：（例）福祉事業の温かさを伝え、見学申込につなげる
- 視聴者：（例）入居を検討する家族
- 感じてほしい感情：安心・信頼
出力：
1. 30秒の構成（0-5秒/5-15秒/15-25秒/25-30秒の4ブロック、各ナレーション付き）
2. 各ブロックの絵コンテ（映像の説明を1〜2行）
3. 画面に出すテロップ案
4. 最後のCTA（行動喚起）の一言
画像→動画Flow用の映像プロンプト（英語化込み）
次のシーンを、Google Flowで生成するための映像プロンプトに変換してください。
- 日本語で意図を整理したあと、英語の生成プロンプトも併記
- カメラワーク・光・雰囲気・被写体・色味を具体的に指定
シーン：（例）夕方、縁側で笑い合う高齢者とスタッフ。柔らかい逆光。

実演④ Claude Code / Codex / Cursor

実演＋プロンプト
ねらい

資料生成の先＝“作業そのもの”を任せる世界を見せる。

話す内容
ここが核心です。資料を作る先、“作業そのもの”をAIに任せる世界。さらにClaude Codeなら、自分専用の“AIチーム”（サブエージェント）を作って仕事を分業・自動化できます。これは私が普段やっている仕事の中身そのものです。
演出・小ネタ
🎬/agents でエージェントを作る様子→「今週のSNS回して」で3役が順に動くのをライブで。
初心者の入口：Claude Codeで /agents →「Generate with Claude」を選び、やりたいことを日本語で言うだけ。中身はAIが自動で組みます。1エージェント＝1専門に絞るのがコツ。
⌨️① はじめの一歩プロンプト
入門Claude Code / Cursor への最初の指示
あなたは私専属のエンジニアです。専門用語は避けて進めてください。
作りたいもの：（例）問い合わせフォーム付きの1ページの紹介サイト
条件：スマホで見やすい／画像は仮でOK／公開まで手順を教えて
まずは完成イメージを言葉で確認し、合意できたら作り始めてください。
途中で私に選ばせたい点があれば、3択までで質問してください。
🤖② 自分専用のAIチームを作る（参考動画の手法）
AIチーム投稿作成エージェントを作る（/agents → Generate with Claude）
SNS投稿を作る専門エージェントを作って。
役割：渡されたネタメモから、Instagram・X・Facebookの3媒体ぶんの投稿文を作る。
ルール：
- 家族目線のやさしい言葉。宣伝くさくしない
- 媒体ごとの作法に合わせる（インスタ＝共感＋ハッシュタグ／X＝短く／FB＝丁寧）
- 個人情報・機密は書かない
使うツール：ファイルの読み書きのみ（最小限）
AIチームAIチームに今週のSNSを回させる（一括指示）
今週のSNSを回して。次の順で進めて、最後にまとめて。
1. ネタ収集エージェント：今週の話題・写真メモから投稿ネタを3つ出す
2. 投稿作成エージェント：3媒体×各2本の投稿文を作る
3. 校正・炎上チェックエージェント：誤字と炎上しそうな表現を点検して直す
最後に、月〜日の投稿カレンダー（曜日／媒体／本文）にまとめて。
