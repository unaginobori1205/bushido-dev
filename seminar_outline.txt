=====================================================
セミナー発表者台本・構成案
タイトル：AIに働かせ、想いを届ける時代へ
サブタイトル：JC活動・社業・SNSを進化させる実践型AIセミナー
全24スライド ／ 想定時間 約90分（デモ各5〜7分）
主催：名古屋JC SNS戦略部会
=====================================================

■ 全体設計の考え方
・感情の波：笑い（1-4枚）→ 信頼（5-7枚）→ 自分ごと化（8枚）→ 実演の衝撃（12-21枚）→ 想いで締め（23枚）
・通底メッセージ：AIは「使う」ではなく「働かせる」。作業を圧縮し、空いた時間で“人にしかできない想いを届ける”。
・ゴール：知識ではなく「明日、自分のPCで1個やってみる」を持ち帰らせる。

-----------------------------------------------------
【第1部：つかみ／想いとキャラを刺す（スライド1-8・約20分）】
-----------------------------------------------------

スライド1：表紙「AIに働かせ、想いを届ける時代へ」
・ねらい：世界観を一言で提示し、空気を作る。
・話す内容：今日のテーマはAIの操作方法ではなく、「AIに働かせて、空いた時間で人の心を動かす」その実演をします。
・演出：タイトルだけ映して約10秒沈黙→第一声。

スライド2：今日のゴール
・ねらい：到達点を最初に約束する。
・話す内容：ゴールは1つ。AIを便利ツール扱いから卒業し、“優秀な部下”として使えるようになること。指示の出し方さえ覚えれば、資料も動画もLPも部下が作る。
・演出：「便利ツール→部下」の矢印アニメ。

スライド3：まず笑ってください（草彅剛似ネタ）
・ねらい：警戒を解き、心の距離を縮める。
・話す内容：よく「草彅剛に似てる」と言われます。似てます?（間）これで皆さん今日1日忘れません。
・演出：「似てる／似てない」を挙手で2分、会場を巻き込む。

スライド4：名古屋が燃えた話（雪山インスタライブ事件）
・ねらい：SNSのリアルな威力と失敗談で共感を作る。
・話す内容：雪山でインスタライブをやったら想定外に名古屋界隈がザワついた。狙ってバズったのではなく、素の想いが伝わると人は動く。SNSは台本より熱量。
・演出：当時の画面・反応・数字をチラ見せ。

スライド5：自己紹介（JC歴・事業・SNS15アカウント）
・ねらい：「この人の話は聞く価値がある」と思わせる。
・話す内容：JC歴、本業の福祉事業（障害者グループホーム等）、SNS15アカウントを実運用。評論家ではなく毎日現場で回している側。
・演出：15アカウントのアイコンを一覧で見せる。

スライド6：2023〜2026の歩み
・ねらい：進化の文脈で説得力を上げる。
・話す内容：JCでブランディング→広報→国際→今AI/SNS。やってきた全部が“想いを届ける技術”として今つながっている。
・演出：年表を1本の線で。点が線になる演出。

スライド7：SNSで事業は動く
・ねらい：理想論でなく結果で語る。
・話す内容：SNSは遊びではない。実際にグループホームが満床になり、インバウンドのサミットまで動いた。発信は集客と信用の資産。
・演出：Before/Afterを実数で。

スライド8：今日の問い「今いちばんやりたいことは?」
・ねらい：受け身を自分ごとに切り替える。
・話す内容：皆さんが今いちばんやりたいこと・解決したいことは何ですか。それを今日のデモの題材にします。
・演出：数名に口頭ヒアリング→後半のLP/パワポ実演の題材にする。

【第2部：橋渡し／レベル確認と全体像（スライド9-11・約10分）】
-----------------------------------------------------

スライド9：使う時代から働かせる時代へ
・ねらい：意識の階段を見せ、現在地を自覚させる。
・話す内容：AI活用には段階がある。①検索代わり→②文章作成→③資料・動画生成→④作業そのものを任せる。今日は③〜④まで一気に体験。
・演出：4段ピラミッド、自分の現在地を指で確認。

スライド10：会場アンケート

・話す内容：音声入力／NotebookLM／Notion／Claude Codeを使ったことがある人?ほぼ全員が知らない=今日が分かれ目。
・演出：QRでリアルタイム投票でも可。

スライド11：ゲシュタルト説明（全部つながって1つ）
・ねらい：今日の世界観の核を渡す。
・話す内容：SNS・AI・事業・想いはバラバラに見えて1つ。AIで作業を圧縮し、SNSで届け、事業が回り、原動力は想い。全部つながって初めて機能する。
・演出：4つの円が重なって1つになる図。

【第3部：実演／ここが本番（スライド12-21・約45分）】
デモ共通の型：①課題提示→②AIに指示（プロンプトを見せる）→③その場で生成→④「これ手作業なら何時間?」と問う。
-----------------------------------------------------

スライド12：実演① NotebookLM（資料を読み込ませる）
・ねらい：自分の資料だけを根拠に答えるAIを体感させる。
・話す内容：分厚いJC資料・会社資料を放り込むと、その資料だけを根拠に答える専属アシスタントになる。でたらめ（ハルシネーション）が起きにくいのが強み。
・演出：実ファイルを読み込ませ質問を1つ投げて回答を見せる。

スライド13：NotebookLMプロンプト（コピペ用4種）
・ねらい：1つの資料から複数の成果物を量産できると示す。
・話す内容：同じ資料から要約／議事録／SNS投稿文／想定問答を一気に。会議後30分の作業が30秒に。

【プロンプト：要約・整理】
この資料を読み込み、以下の形式で整理してください。
1. 3行要約
2. 重要ポイントを5つ（各1行）
3. 会議で確認すべき論点を3つ
4. SNS投稿に使える切り口を3つ
5. 30秒で話せるスピーチ原稿
6. 想定される質問と回答を3組

【プロンプト：議事録化】
この資料（または文字起こし）から、配布用の議事録を作成してください。
- 形式：日時／参加者／議題ごとの「決定事項」「保留事項」「ToDo（担当・期限）」
- 文体：です・ます調、簡潔に
- 最後に「次回までの宿題」を箇条書きでまとめる

【プロンプト：SNS化】
この資料の内容を、以下3媒体向けの投稿文に書き分けてください。
- Instagram：共感から入る本文＋ハッシュタグ10個
- X（旧Twitter）：140字以内のフック1本＋スレッド3連投の構成
- Facebook：少し丁寧に、背景と想いが伝わる長文
それぞれ、読み手が「自分ごと」に感じる一文から始めてください。

【プロンプト：質問生成】
この資料について、理解度を確認するための質問を作ってください。
- 初級5問（用語・事実確認）
- 中級5問（背景や狙いを問う）
- 応用3問（自分の事業にどう活かすか）
各質問に、資料を根拠にした模範解答も付けてください。

スライド14：実演② Google Flow（想いを動画にする）
・ねらい：文字で書いた想いが映像になる驚きを体感。
・話す内容：文字で書いた想いをそのまま動画に。広告でもJC事業紹介でも、熱量を映像化できる。
・演出：短尺生成をその場で実行。待ち時間にトーク。

スライド15：Flowプロンプト（コピペ用2種）
・ねらい：設計図さえ書けば映像になると持ち帰らせる。
・話す内容：誰に・何を感じてほしいかを書くだけで30秒シナリオと絵コンテが出る。撮影前の設計が一瞬。

【プロンプト：30秒動画のシナリオ＋絵コンテ】
あなたはプロの動画ディレクターです。次の条件で30秒動画の構成を作ってください。
- 目的：（例）グループホームの温かさを伝え、見学申込につなげる
- 視聴者：（例）入居を検討する家族
- 感じてほしい感情：安心・信頼
出力：
1. 30秒の構成（0-5秒/5-15秒/15-25秒/25-30秒の4ブロック、各ナレーション付き）
2. 各ブロックの絵コンテ（映像の説明を1〜2行）
3. 画面に出すテロップ案
4. 最後のCTA（行動喚起）の一言

【プロンプト：Flow用の映像プロンプト（英語化込み）】
次のシーンを、Google Flowで生成するための映像プロンプトに変換してください。
- 日本語で意図を整理したあと、英語の生成プロンプトも併記
- カメラワーク・光・雰囲気・被写体・色味を具体的に指定
シーン：（例）夕方、縁側で笑い合う高齢者とスタッフ。柔らかい逆光。

スライド16：実演③ パワポ生成（その場で資料を作る）
・ねらい：今見ているこの資料もこう作れると接続する。
・話す内容：理事会資料も営業資料も箇条書きを渡せば構成済みスライドに。今見ているこの資料もこう作れる。
・演出：スライド8でヒアリングした会場の題材で実演。

スライド17：パワポプロンプト（用途別テンプレ3種）
・ねらい：用途別に型があると伝え、再現性を渡す。
・話す内容：目的・対象・枚数・トーンの4点を書くだけ。あとはAIが構成する。

【プロンプト：理事会資料】
次の条件でプレゼン資料の構成（各スライドのタイトル＋箇条書き本文）を作ってください。
①目的：理事会で〇〇事業の承認を得る
②対象：理事メンバー（多忙・結論を急ぐ）
③枚数：8枚
④トーン：簡潔・論理的・数字重視
構成には「現状→課題→提案→効果→費用→スケジュール→お願い」を含めてください。

【プロンプト：営業資料】
次の条件で営業提案資料の構成を作ってください。
①目的：〇〇サービスの導入を決めてもらう
②対象：意思決定者（経営者）
③枚数：10枚
④トーン：共感→課題→解決→証拠→行動
顧客の「困りごと」から始め、最後に明確なCTAと料金プランを入れてください。

【プロンプト：セミナー資料】
次の条件でセミナー資料の構成を作ってください。
①目的：参加者が〇〇を「明日やってみよう」と思う
②対象：〇〇に詳しくない人
③枚数：15枚
④トーン：体験型・笑い・実演多め
途中に「会場への問いかけ」を3回、最後にアンケート導線を入れてください。

スライド18：実演④ Claude Code / Codex / Cursor
・ねらい：資料生成の先＝作業そのものを任せる世界を見せる。
・話す内容：資料を作る先、作業そのものをAIに任せる世界。LP・ツール・自動化を指示だけで。これが普段の仕事の中身そのもの。
・演出：簡単な生成を実行し、AIが勝手に作っていく様子をライブで。

【プロンプト：最初の指示テンプレ】
あなたは私専属のエンジニアです。専門用語は避けて進めてください。
作りたいもの：（例）問い合わせフォーム付きの1ページの紹介サイト
条件：スマホで見やすい／画像は仮でOK／公開まで手順を教えて
まずは完成イメージを言葉で確認し、合意できたら作り始めてください。
途中で私に選ばせたい点があれば、3択までで質問してください。

スライド19：LP実演（参加者の事業でLP骨子を作る）
・ねらい：自分の事業が画面に立ち上がる体験で最高潮に。
・話す内容：スライド8でヒアリングした参加者の事業を題材に、その場でLPの骨子を作る。

スライド20：LPプロンプト（FV〜CTA）
・ねらい：刺さるLPには型があると再現可能な形で渡す。
・話す内容：①FVで一言→②共感→③解決→④証拠→⑤CTA。これをAIに指示するだけ。

【プロンプト：LP構成】
あなたはコンバージョンに強いLP（集客ページ）の構成プロです。
次の事業のLP構成を、5ブロックで作ってください。
- 事業：（例）障害者グループホームの入居者募集
- ターゲット：（例）親亡き後を心配する家族
- ゴール：見学予約
出力：
1. ファーストビュー：心をつかむキャッチコピー3案＋サブコピー
2. 共感パート：読み手の不安・悩みを言語化
3. 解決パート：私たちが提供する価値（3つ）
4. 証拠：実績・声・数字で信頼を作る要素
5. CTA：申し込みたくなる一言＋ボタン文言3案
全体を通して、専門用語を避け、家族目線のやさしい言葉で。

スライド21：実演⑤ Notion / Obsidian（情報を資産化する）

・演出：今日のプロンプト集がこの形で蓄積されていることを見せる。
