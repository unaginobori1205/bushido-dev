## 結論（最重要）

ユーワード活動は「紹介・勧誘・登録・報酬」が関係するため、**特定商取引法の連鎖販売取引に関するルール**を正しく守る必要がある。研修資料の内容は、消費者庁「特定商取引法ガイド」の連鎖販売取引の説明とも大筋で一致している。

特に重要な5原則：

1. 最初に身分・目的・商品役務を明示する
2. 「儲かる」「絶対得する」などの断定表現をしない
3. 概要書面を契約前に渡す
4. クーリング・オフや中途解約を正しく説明する
5. ユーワード以外の勧誘（投資・宗教・政治・他社ビジネス等）に組織を使わない

行動指針を一言でまとめると：

> **隠さない。盛らない。急がせない。強要しない。書面を渡す。記録を残す。**

## 重要論点の分析

### A. コンプライアンスの定義

一般的なコンプライアンス＝法令遵守、企業倫理、ルールを守ること。
ユーワードにおいては、**ユーワード倫理綱領・特定商取引法・概要書面記載ルール**を守って健全に活動することが中心。

ポイントは、単なる「法律を守る」ではなく、**社会から存続と成長を認められる活動**をすること。
ギリギリ違法でなければよい、ではなく、相手に誤解・不安・不信を与えない活動が求められる。

### B. 連鎖販売取引とは何か

消費者庁の定義：個人を販売員として勧誘し、さらにその個人に次の販売員を勧誘させる形で販売組織を拡大する商品・権利・役務の取引。

重要語：

| 用語 | 意味 |
| --- | --- |
| 特定負担 | 販売員・パートナーになるために必要な経済的負担 |
| 特定利益 | 組織から得られる利益・報酬 |

この2つが絡むと説明責任が一気に重くなる。
→ 紹介時に「無料っぽく見せる」「報酬だけ強調する」「費用や条件を後出しする」のは危険。

### C. 勧誘前に必ず伝える3点（資料9ページ・実務上最重要）

1. 統括者・勧誘者の氏名または名称
2. 特定負担を伴う契約の勧誘目的であること
3. 商品または役務の種類

消費者庁の公式説明でも同じ。

**実務での安全な言い方：**

> 「今日は、ユーワードのサービスとパートナー制度についてご説明します。登録費用や月会費などの負担、紹介に関する報酬制度も関係する内容です。無理に参加を勧めるものではありませんので、まず概要書面を確認しながら判断してください。」

この一言を最初に入れるだけで、かなりリスクが下がる。

### D. 禁止行為（資料11〜12ページ・最も事故が起きやすい）

| 禁止行為 | 危険な例 |
| --- | --- |
| 不実告知 | 「絶対儲かる」「必ず元が取れる」 |
| 事実不告知 | 費用、月会費、解約条件を説明しない |
| 威迫・困惑 | 「今決めないと損」「断る理由ある？」 |
| 勧誘目的を隠す | 「面白い話がある」とだけ言って個室に誘う |
| 断定的判断の提供 | 「この仕組みは確実に伸びる」 |
| 書面不交付 | 概要書面を渡さず登録に進める |

消費者庁も、重要事項について事実を告げない・事実と違うことを告げる・威迫して困惑させる・勧誘目的を告げずに公衆の出入りしない場所で勧誘することを禁止行為としている。

### E. 広告・SNS・メールでの注意（資料13〜15ページ）

**SNS投稿で危ない表現：**

| NG表現 | 理由 |
| --- | --- |
| 「誰でも月収100万円」 | 誇大広告・断定的判断になりやすい |
| 「登録するだけで稼げる」 | 報酬条件の誤認につながる |
| 「ノーリスク」 | 特定負担がある場合は危険 |
| 「絶対損しない」 | 実際より有利と誤認させる可能性 |
| 「詳しくはDMで」だけ | 目的を隠した誘引に見える可能性 |

**安全な表現：**

> 「ユーワードの仕組み、サービス内容、費用、報酬条件、解約ルールを概要書面に基づいて説明します。収益は活動内容や条件により異なり、保証されるものではありません。」

未承諾の電子メール広告は、消費者があらかじめ承諾しない限り原則禁止。承諾や請求の記録は最後に送信した日から**3年間**保存が必要。

### F. 書面交付の重要性（資料16〜17ページ）

| 書面 | タイミング | 誰が出すか |
| --- | --- | --- |
| 概要書面 | 契約前 | 紹介者が提示 |
| 契約書面 | 契約後 | 会社から送付 |

「説明した」だけでは弱い。記録として以下を残すと安全：

- 概要書面を渡した日
- 相手が受け取ったこと
- 特定負担を説明したこと
- 特定利益を説明したこと
- クーリング・オフを説明したこと
- 中途解約・返品ルールを説明したこと
- 相手からの質問と回答内容

### G. クーリング・オフ（資料19〜20ページ）

連鎖販売取引では、法律で定められた書面を受け取った日、または商品の引渡しが後であればその日から数えて**20日以内**であれば、書面または電磁的記録によりクーリング・オフができる。

事実と違う説明や威迫によって相手が誤認・困惑し、クーリング・オフしなかった場合は、20日を過ぎてもクーリング・オフできる可能性がある。
→ **クーリング・オフ妨害はかなり危険。**

**絶対に言ってはいけない例：**

- 「もう使ったから解約できない」
- 「登録したら取り消せない」
- 「会社に迷惑がかかるからやめて」
- 「紹介者の顔を潰すことになる」
- 「今さら無理」

### H. 中途解約・返品ルール（資料21〜22ページ）

連鎖販売契約を結んだ無店舗個人は、クーリング・オフ期間経過後も将来に向かって契約を解除できる。さらに以下の条件をすべて満たす場合は商品販売契約も解除できる：

1. 入会後1年を経過していない
2. 商品引渡しから90日を経過していない
3. 商品を再販売していない
4. 商品を使用または消費していない
5. 自分の責任で商品を滅失・き損していない

## ユーワード独自ルールの重要ポイント

### A. クロスリクルート禁止（資料24ページ）

クロスリクルート＝ユーワードの組織をユーワード以外の目的で利用する行為。

対象は他社ビジネスだけではない：

- 投資
- 政治
- 宗教
- 自己啓発
- 金銭トラブルにつながる勧誘
- その他、ユーワード活動に悪影響を与えるもの

ユーワードの人脈で別案件を広げると、本人は軽い紹介のつもりでも、相手や上位者からは「組織を利用された」と見られる可能性がある。

### B. 処分対象になりうる行為（資料25ページ）

- ユーワード社や会員への誹謗中傷
- 会員登録や追加ポジション、SA資格申請の強要
- ノルマを課す行為
- ビジネス活動の強要
- 本人に無断でメニュー購入や月会費を代行する行為
- 系列操作
- 登録資金・活動資金の借入を勧める行為

特に危険なのは**善意の代行**。「今月だけ払っておくね」「登録だけしておいたよ」は、本人の同意や理解が曖昧だと大きな問題になる。

### C. 処分の種類（資料26ページ）

1. 注意・警告処分
2. 報酬の一部または全部の停止、既払い報酬の返還
3. ビジネス活動の一部または全部の停止
4. パートナーまたはパートナー加盟店資格の解約処分

違反は「怒られる」だけでは終わらない。報酬停止、返還、資格解約まであり得る。

## 実務用チェックリスト

### 勧誘前チェック

- [ ] 相手に自分の氏名・立場を伝えた
- [ ] ユーワードの説明であることを伝えた
- [ ] パートナー制度・費用・報酬が関係することを伝えた
- [ ] 商品・サービスの種類を伝えた
- [ ] 「参加しなくても大丈夫」と明示した

### 説明時チェック

- [ ] 特定負担を説明した
- [ ] 月会費・登録費・初期費用を説明した
- [ ] 特定利益・報酬条件を説明した
- [ ] 報酬は保証ではないと説明した
- [ ] クーリング・オフ20日を説明した
- [ ] 中途解約・返品ルールを説明した
- [ ] 概要書面を渡した
- [ ] 相手の質問に答えた
- [ ] 強引な勧誘をしていない

### SNS・広告チェック

- [ ] 「絶対」「必ず」「誰でも稼げる」を使っていない
- [ ] 収益保証に見える表現をしていない
- [ ] 費用を隠していない
- [ ] 説明会やDM誘導の目的を隠していない
- [ ] 会社名・サービス内容・必要な費用が分かる
- [ ] 誤認を招くビフォーアフターや過大表現がない

### 登録後チェック

- [ ] 契約書面が会社から送られることを説明した
- [ ] クーリング・オフの連絡方法を妨げていない
- [ ] 月会費や購入を強要していない
- [ ] 本人の同意なく支払・購入を代行していない
- [ ] 他社案件や投資等を紹介していない

## そのまま使える安全トーク

### 冒頭説明

> 本日は、ユーワードのサービス内容と、パートナー制度についてご説明します。
> 登録費用や月会費などの負担、紹介に関する報酬制度も関係する内容です。
> 無理に参加をお願いするものではありませんので、概要書面を確認しながら、ご自身で判断してください。

### 報酬説明

> 報酬制度はありますが、収益を保証するものではありません。
> 活動内容、条件、継続状況によって結果は異なります。
> 詳細は概要書面に基づいて説明します。

### 断られた時

> もちろん大丈夫です。
> 必要ないと感じた場合は、参加しない判断も尊重します。
> 分からない点があれば、いつでも確認してください。

### クーリング・オフ説明

> 契約後も、法律で定められた条件に基づき、クーリング・オフ制度があります。
> 連鎖販売取引では、書面を受け取った日または商品引渡し日の遅い方から20日以内が基本です。

## この研修からの実務上の結論

ユーワード活動では、**「何を勧めているのか」「いくら必要なのか」「どんな利益があり得るのか」「解約できるのか」**を、最初から正直に伝えることが最重要。

守るべき基準：

> **隠さない。盛らない。急がせない。強要しない。書面を渡す。記録を残す。**

ここを徹底すれば、信頼を積み上げながら活動できる。逆に曖昧にすると、たった一件のクレームで信用も組織も崩れる。
この資料は、単なる研修資料ではなく、**紹介活動・SNS発信・説明会運営のリスク管理マニュアル**として扱う。
