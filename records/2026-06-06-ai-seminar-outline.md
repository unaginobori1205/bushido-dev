## 1. つかみ・自己紹介（5分）

皆さんこんにちは。
名古屋青年会議所の上岡賢輔です。

2016年に入会し、広報、国際系事業、3Gプロジェクト、国際アカデミーなどに関わってきました。
今は会社経営をしながら、SNSアカウントを15個ほど運用しています。

あと、よく草彅剛に似てると言われます。
今日はそこだけ覚えて帰ってもらっても大丈夫です。笑

ただ、今日一番伝えたいのは、
AIを“使う時代”はもう終わり始めているということです。
これからは、AIを“働かせる時代”です。

## 4. 上級編：AIツールの役割分担（15分）

AIツールは「役割」で捉えると整理しやすい。

- **ChatGPT／Gemini** → 相談相手
- **NotebookLM** → 資料を読ませる秘書
- **Claude Code／Codex／Cursor／Antigravity** → 実際に手を動かす開発スタッフ

| ツール | 役割・特徴 |
| --- | --- |
| Claude Code | コードベース理解、ファイル編集、コマンド実行を行うエージェント型開発ツール |
| Codex | OpenAIのコーディングエージェント。コード作成・レビュー・出荷支援に使える |
| Google Antigravity | Googleのエージェントファースト開発プラットフォーム |
| Cursor | AIコーディングエージェント型の開発環境 |
