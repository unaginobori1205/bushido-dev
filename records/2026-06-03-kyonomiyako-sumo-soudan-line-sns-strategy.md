## 1. LINE公式「京の都 相撲相談室」の目的

LINE公式アカウントを、単なる告知チャネルではなく **「相談の入口」** として位置づける。

- 障がい・福祉・グループホームに関する **気軽な相談窓口** をつくる
- 「相撲相談室」という親しみやすい名前で、**敷居を下げる**
- 受給者証・権利・制度の **正しい情報を届ける啓発拠点** にする
- 将来の入居検討者・家族・支援者と **継続的につながる名簿** を育てる
- SNS（Instagram / TikTok）で集めた関心を、LINEで **個別の関係** に変える

### ゴール指標（KPI候補）

- LINE友だち登録数（月次）
- 初回メッセージ後の返信率
- 相談 → 見学 → 体験入居 → 入居 の転換数
- 地域別の相談件数（どの地域にニーズがあるか）

---

## 2. Instagram / TikTok から LINE への導線

「発信して終わり」にせず、**SNS → LINE → 相談** の一本道をつくる。

```
Instagram / TikTok（認知・共感）
        ↓ プロフィールリンク / 投稿CTA
   LINE公式「京の都 相撲相談室」（個別relationship）
        ↓ 初回メッセージ・ステップ配信
   相談 → 見学 → 体験入居 → 入居
```

### 導線設計のポイント

- 各SNSの **プロフィール欄にLINEリンク** を常設
- 投稿の最後に必ず **「相談はLINEで（プロフィールから）」のCTA**
- TikTokは「保存・コメント」、Instagramは「ストーリーズのリンク」で誘導
- 「DMより、LINEのほうがゆっくり相談できます」と伝える
- 友だち追加直後に **自動の初回メッセージ** が届くよう設定

## 3. 発信の3本柱（コンテンツ方針）

| 柱 | 目的 | 内容例 |
| --- | --- | --- |
| ① 受給者証・制度の啓発 | 正しい知識を届け、信頼を得る | 受給者証の取り方、使える制度、申請の流れ |
| ② 権利啓発 | 当事者・家族の不安を減らす | 障がい者の権利、合理的配慮、相談先の紹介 |
| ③ グループホーム情報発信 | 京の都の暮らしを伝える | 日常の様子、入居までの流れ、Q&A、スタッフの想い |

- 3本柱を **曜日・テーマで回す** と継続しやすい
- 「売り込み」より「役に立つ情報」を先に出し、信頼を積む
- 専門用語は避け、**当事者・家族の言葉** で語る

## 4. LINE初回メッセージ案

> 友だち追加ありがとうございます。
> 「京の都 相撲相談室」です。
>
> ここは、障がいやグループホームのことを
> 気軽に相談できる場所です。
>
> ・受給者証ってどう取るの？
> ・どんな制度が使えるの？
> ・グループホームってどんなところ？
>
> どんな小さなことでも大丈夫です。
> このトークにメッセージを送ってください。
> スタッフがゆっくりお返事します。
>
> 見学・体験のご相談もこちらからどうぞ。

### 補足

- 1通目は **長すぎない** こと。最初の心理的ハードルを下げる
- 「答えを売る」のではなく「聞いていいんだ」と思ってもらう
- 名前・地域・関係性（本人/家族/支援者）を **無理なく聞ける流れ** にする

## 5. ステップ配信案（友だち追加後）

| タイミング | 内容 | ねらい |
| --- | --- | --- |
| 即時（0日目） | 初回あいさつ＋相談歓迎メッセージ | 心理的ハードルを下げる |
| 1〜2日目 | 「受給者証って何？」やさしい解説 | 役立つ情報で信頼を得る |
| 3〜4日目 | グループホーム「京の都」の暮らし紹介 | イメージを持ってもらう |
| 5〜7日目 | 入居までの流れ（見学→体験→入居） | 次の一歩を見せる |
| 10日目前後 | 「気になることありませんか？」一言 | 個別相談のきっかけ |
| 2週間〜 | 見学・体験のご案内 | 行動への自然な誘導 |

- 売り込みすぎず、**情報→共感→誘導** の順を守る
- 返信があったら **自動配信を止めて個別対応** に切り替える

## 6. 地域ごとの開所判断基準

新しいグループホームの開所候補地域を、**感覚ではなくデータで** 判断する。

### 判断材料（チェック項目）

- LINE相談・SNS反応の **地域別の数**（需要の実感）
- 対象となる障がい者・家族の **人口規模**
- 近隣の **競合グループホームの数と空き状況**
- **物件**（バリアフリー、家賃、広さ、立地）の確保しやすさ
- **支援機関・医療・行政** との連携のしやすさ
- **スタッフ採用** の見込み
- 自治体の **福祉施策・補助** の状況

### 判断の進め方

1. LINE/SNSの地域別データで **需要のある地域を絞る**
2. 上位地域について現地・行政・物件を **実地調査**
3. チェック項目を点数化し、**開所候補地域DB** に記録
4. 優先順位をつけて意思決定

## 8. 最初の30日アクション

### 1週目：土台づくり

- LINE公式アカウント開設・初回メッセージ設定
- Instagram / TikTok プロフィールにLINEリンク設置
- Notionに4つの台帳を作成

### 2週目：発信開始

- 3本柱に沿って投稿を開始（まず各柱1〜2本ずつ）
- ステップ配信を設定（0日目〜2週間）
- 投稿ネタ台帳に10本ストック

### 3週目：相談を受ける

- LINE相談に個別対応を開始
- 相談内容・地域をLINE相談者台帳に記録
- 反応の良い投稿を分析

### 4週目：振り返りと地域分析

- 地域別の相談・反応を地域ニーズ台帳に集計
- 開所候補地域DBの初期入力
- 30日の数字（友だち数・相談数・転換数）を振り返り、翌月の方針決定

1. 受給者証ってどうやって取るの？（申請の流れをやさしく）

9. 入居者の1日（プライバシーに配慮した日常）
