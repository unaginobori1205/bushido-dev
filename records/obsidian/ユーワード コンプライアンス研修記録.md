# ユーワード コンプライアンス研修記録

## 概要

2026年6月23日、ユーワード発信に関する「コンプライアンス研修.pdf」（全27ページ）を受講・記録。
研修内容は消費者庁「特定商取引法ガイド」の連鎖販売取引の説明とも大筋で一致している。

ユーワード活動は「紹介・勧誘・登録・報酬」が関係するため、**特定商取引法の連鎖販売取引に関するルール**を正しく守る必要がある。

この記録は、単なる研修メモではなく、**紹介活動・SNS発信・説明会運営のリスク管理マニュアル**として扱う。

---

## 結論：守るべき5原則

1. 最初に身分・目的・商品役務を明示する
2. 「儲かる」「絶対得する」などの断定表現をしない
3. 概要書面を契約前に渡す
4. クーリング・オフや中途解約を正しく説明する
5. ユーワード以外の勧誘（投資・宗教・政治・他社ビジネス等）に組織を使わない

> **隠さない。盛らない。急がせない。強要しない。書面を渡す。記録を残す。**

---

## 重要テーマ

### 1. コンプライアンスとは

法令遵守・企業倫理・ルールを守ること。
ユーワードでは、**ユーワード倫理綱領・特定商取引法・概要書面記載ルール**を守って健全に活動すること。

ギリギリ違法でなければよい、ではなく、**社会から存続と成長を認められる活動**＝相手に誤解・不安・不信を与えない活動が求められる。

### 2. 連鎖販売取引・特定負担・特定利益

連鎖販売取引＝個人を販売員として勧誘し、その個人にさらに次の販売員を勧誘させて組織を拡大する取引。

- **特定負担**：パートナーになるために必要な経済的負担（登録費・月会費・初期費用など）
- **特定利益**：組織から得られる利益・報酬

この2つが絡むと説明責任が重くなる。「無料っぽく見せる」「報酬だけ強調」「費用を後出し」は危険。

### 3. 勧誘前に必ず伝える3点（実務上最重要）

1. 統括者・勧誘者の氏名または名称
2. 特定負担を伴う契約の勧誘目的であること
3. 商品または役務の種類

冒頭の一言でリスクが大きく下がる。

### 4. 禁止行為（最も事故が起きやすい）

- 不実告知：「絶対儲かる」「必ず元が取れる」
- 事実不告知：費用・月会費・解約条件を説明しない
- 威迫・困惑：「今決めないと損」「断る理由ある？」
- 勧誘目的を隠す：「面白い話がある」とだけ言って個室に誘う
- 断定的判断の提供：「この仕組みは確実に伸びる」
- 書面不交付：概要書面を渡さず登録に進める

### 5. 広告・SNS・メール

NG表現：「誰でも月収100万円」「登録するだけで稼げる」「ノーリスク」「絶対損しない」「詳しくはDMで」だけ。

未承諾の電子メール広告は原則禁止。承諾・請求の記録は最後の送信日から**3年間**保存。

### 6. 書面交付

- 概要書面：契約**前**に紹介者が提示
- 契約書面：契約**後**に会社が送付

「説明した」だけでは弱い。渡した日・受領・各説明事項・質問と回答を記録に残す。

### 7. クーリング・オフ

書面受領日または商品引渡日の遅い方から**20日以内**は書面・電磁的記録でクーリング・オフ可能。
妨害（不実告知・威迫で誤認困惑させる）があれば20日経過後も可能になり得る。

**NG発言**：「もう使ったから解約できない」「登録したら取り消せない」「会社に迷惑がかかる」「紹介者の顔を潰す」「今さら無理」。

### 8. 中途解約・返品

クーリング・オフ期間後も将来に向かって契約解除可。
以下を全て満たせば商品販売契約も解除可：①入会1年未満 ②引渡し90日未満 ③未再販売 ④未使用・未消費 ⑤自己責任で滅失き損していない。

## ユーワード独自ルール

### クロスリクルート禁止

ユーワードの組織をユーワード以外の目的で利用する行為。
対象は他社ビジネスに限らず、投資・政治・宗教・自己啓発・金銭トラブル勧誘なども含む。

人脈で別案件を広げると、軽い紹介のつもりでも「組織を利用された」と見られる。

### 処分対象になりうる行為

誹謗中傷／登録・追加ポジション・SA資格申請の強要／ノルマ／ビジネス活動の強要／無断のメニュー購入・月会費代行／系列操作／登録資金・活動資金の借入勧誘。

特に危険なのは**善意の代行**（「今月だけ払っておくね」「登録だけしておいたよ」）。

### 処分の種類

1. 注意・警告処分
2. 報酬の一部・全部停止、既払い報酬の返還
3. ビジネス活動の一部・全部停止
4. パートナー／パートナー加盟店資格の解約処分

## 安全トーク集

### 冒頭説明
> 本日は、ユーワードのサービス内容と、パートナー制度についてご説明します。登録費用や月会費などの負担、紹介に関する報酬制度も関係する内容です。無理に参加をお願いするものではありませんので、概要書面を確認しながら、ご自身で判断してください。

### 報酬説明
> 報酬制度はありますが、収益を保証するものではありません。活動内容、条件、継続状況によって結果は異なります。詳細は概要書面に基づいて説明します。

### 断られた時
> もちろん大丈夫です。必要ないと感じた場合は、参加しない判断も尊重します。分からない点があれば、いつでも確認してください。

### クーリング・オフ説明
> 契約後も、法律で定められた条件に基づき、クーリング・オフ制度があります。連鎖販売取引では、書面を受け取った日または商品引渡し日の遅い方から20日以内が基本です。

## 実務チェックリスト

### 勧誘前
- [ ] 氏名・立場を伝えた
- [ ] ユーワードの説明であることを伝えた
- [ ] パートナー制度・費用・報酬が関係すると伝えた
- [ ] 商品・サービスの種類を伝えた
- [ ] 「参加しなくても大丈夫」と明示した

### 説明時
- [ ] 特定負担（月会費・登録費・初期費用）を説明
- [ ] 特定利益・報酬条件を説明
- [ ] 報酬は保証ではないと説明
- [ ] クーリング・オフ20日を説明
- [ ] 中途解約・返品ルールを説明
- [ ] 概要書面を渡した
- [ ] 質問に答えた／強引な勧誘をしていない

### SNS・広告
- [ ] 「絶対」「必ず」「誰でも稼げる」を使っていない
- [ ] 収益保証に見える表現をしていない
- [ ] 費用を隠していない／目的を隠していない
- [ ] 会社名・サービス内容・必要な費用が分かる
- [ ] 誤認を招く過大表現がない

### 登録後
- [ ] 契約書面が会社から送られると説明
- [ ] クーリング・オフ連絡を妨げていない
- [ ] 月会費・購入を強要していない
- [ ] 無断で支払・購入を代行していない
- [ ] 他社案件・投資等を紹介していない

## 今後のアクション

- 紹介・説明会ごとに「記録用テンプレート」で記録を残す
- SNS発信前に「SNS・広告チェック」を必ず通す
- 概要書面の提示を契約前ルーティンに固定する
- クロスリクルート（投資・宗教・政治・他社案件）を絶対に持ち込まない
- 善意の代行支払・代行登録をしない
