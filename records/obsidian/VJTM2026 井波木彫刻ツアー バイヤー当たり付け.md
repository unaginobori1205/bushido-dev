# VJTM2026 井波木彫刻ツアー バイヤー当たり付け

## 概要

富山県南砺市・井波の木彫刻ツアー「Michi Tour 雅」（2026年9月13-14日）について、
VJTM & VJMM 2026（2026年9月24-26日／東京ビッグサイト）の海外バイヤーに当たりを付けられるかを検討した。

結論として、**方向性は正しいが、VJTM2026本体に間に合わせる前提は成立しない可能性が高い**。
また、対象となるバイヤーは約280社のうち多く見積もって20社程度に絞られる。
その絞り込みを決めるのは、宿の収容力という物理的な制約である。

| 職人 | 彫刻師・野村清宝（伝統工芸士） |

### 強み

- 職人に弟子入りできる宿という構造そのものが世界的に希少
- 通常非公開の夜間拝観＝バイヤーが最も欲しがる「金で買えない特別感」
- 日本遺産の公式ストーリーによる裏付け
- 金沢から約1時間。既存のゴールデンルート周遊に1泊で差し込める
- ホテルではなく「250年の町に住む」体験。リピーター需要と一致

### 制約

- **収容力が小さい**：Bed and Craftは6棟。1棟1〜3名〜1〜6名規模で、全館貸切でも20名前後が上限
- **固定日程**：設定日型のため海外の旅程に合わない
- **単価の位置づけ**：国内基準では高額だが、欧米ラグジュアリー基準では中の上。むしろ割安に映る
- **言語対応が不明**：英語ガイド・通訳の有無が最大の未確認事項

> 収容力20名という一点が、バイヤー選別のすべてを決める。
> 40名バスを埋める商品を扱う会社は、どれだけ大手でも対象外になる。

## 3. タイミング上の2つの問題

### 問題1：ツアー催行日が商談会より前

9/13-14のツアーは、9/24-26の商談会より前に終わっている。
つまり商談で出すべきは設定日商品そのものではなく、**中身をモジュール化した私的手配版**である。

これは弱点ではなく、正しい売り方への矯正でもある。
海外バイヤーは6〜12ヶ月前に旅程を組むため、設定日型の国内パッケージはそもそも買えない。

提示すべき形：

- 「1泊2日／2〜8名／通年設定可」の私的手配プログラム
- ネット料金（NET rate）とコミッション条件の明示
- 9/13-14のツアーは **催行実績・信頼材料として見せる**

### 問題2：セラー申込が既に締め切られている

8月16日時点で新規申込は不可能。枠を未確保の場合、2026年の打ち手は以下。

| 打ち手 | 実現性 |
| --- | --- |
| 富山県・南砺市の地域優先枠に相乗り | 中 |
| 富山県観光連盟／南砺市観光協会経由での紹介 | 中 |
| JNTO海外事務所経由の個別提案 | 高（費用ゼロ） |
| **バイヤー招請FAMツアーへの組み込み** | **最有力** |
| 2027年に正式エントリー | 高 |

> 最有力はFAMツアー。VJTMのバイヤーは会期前後に地方視察をする。
> 井波は「金沢から1時間圏」という好条件を持つ。ここに1泊差し込めれば、20分の商談100回に勝る。

## 4. バイヤー選別の6条件

約280社をこの6条件で機械的に絞る。

| # | 条件 | 判定基準 | 重み |
| --- | --- | --- | --- |
| 1 | 少人数FIT／オーダーメイド型か | 団体シリーズ・OTA・格安系は除外 | ★★★ 必須 |
| 2 | 北陸・中部を既に扱っているか | 金沢／白川郷／高山が商品にあるか | ★★★ |
| 3 | リピーター客層を持つか | 訪日2回目以降が主か | ★★★ |
| 4 | 工芸・アート・建築のテーマ性があるか | 職人体験・美術・寺社を売っているか | ★★ |
| 5 | 1人1日あたりの単価が高いか | 目安 US$400／日以上 | ★★ |
| 6 | 市場のアクセス適性 | 北陸新幹線／小松・富山空港が使えるか | ★ |

**1〜3すべてに○が付く会社だけを商談対象にする。**

## 8. 20分商談の型

| 時間 | 内容 |
| --- | --- |
| 0:00-0:02 | 挨拶。1問で客層確認「訪日は初回客が中心ですか、リピーターですか？」 |
| 0:02-0:07 | 商品説明。**写真3枚のみ**（夜の瑞泉寺／彫る手元／泊まる町家） |
| 0:07-0:12 | 「金沢から1時間」の地図。既存行程への差し込みを具体的に示す |
| 0:12-0:17 | 条件確認 |
| 0:17-0:20 | 次のアクション合意（FAM招請の打診、サンプル行程の送付日を約束） |

**言葉より地図。** 井波の位置を知らないバイヤーが大半なので、金沢との距離を示した瞬間に反応が変わる。

### 必ず聞かれる質問と、用意すべき答え

| 質問 | 準備すべき回答 |
| --- | --- |
| ネット料金は？ | 公表価格ではなくNET rate表。コミッション率も明示 |
| 最少催行人数は？ | 2名から。上限は宿の棟数で決まる旨を正直に伝える |
| 通年設定できるか？ | 可否と、不可な時期（積雪期の扱い）を明確に |
| 英語ガイドは付くか？ | **最重要。** 付かないなら商談価値が半減する |
| 予約リードタイムは？ | 6棟しかないため、何ヶ月前までに押さえる必要があるか |
| キャンセルポリシーは？ | 一棟貸しの規定をそのまま |
| 食事対応は？ | ベジタリアン／ハラール／アレルギー対応の可否 |

> 英語ガイドの有無と、NET料金表。この2つが無いと商談は成立しない。
> VJTMに向かう前に、この2点を主催者側に確認することが最優先タスク。

## 9. BUSHIDO JAPANとしての位置づけ

この商品は自社商品ではない。関わり方は3通り。

| 立場 | 内容 | 必要なもの |
| --- | --- | --- |
| A. 送客パートナー | Michi Tour側の商品を海外バイヤーに紹介し手数料を得る | 販売委託合意、NET料金 |
| B. 共同造成 | 井波の素材を使いBUSHIDO JAPAN版として再構成 | 宿・職人・寺との直接の関係構築 |
| C. 自社商品への応用 | 「弟子入りできる宿」の構造を武士道・弓道の文脈で展開 | 永野一翠工房訪問の学びと接続 |

**Cが本命。**
[[永野一翠工房 訪問記録]]で確認した「伝統は商売に合わせて曲げてはいけない」という姿勢と、
井波の「職人の生活の中に客を入れる」構造は同じ思想上にある。
井波は、その構造がすでに商品として成立している先行事例として学ぶ価値が高い。

## 判断のまとめ

- VJTMのバイヤーに当たりを付ける方向は正しい。ただし対象は約280社のうち多くて**20社程度**
- 絞り込みの決定要因は「宿6棟・最大20名」という収容力。ここで団体系は全部落ちる
- 2026年のVJTM本体には間に合わない可能性が高い。代わりにFAMツアーとJNTO海外事務所経由で動く
- 商談会に出る前に潰すべき前提が2つ：**英語ガイドの有無**と**NET料金の有無**
