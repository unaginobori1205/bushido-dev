## [0:00–0:18] HOOK（ゆっくり・力強く）

> Every year, / more than **42 million** people travel to Japan / — a new **record**. //
> They spend over **nine trillion yen**. //
> Yet / almost **none** of them / truly **experience** Japan. /
> They photograph the temples, / but never meet the **masters** / who give them meaning. //

- trillion（トゥ**リ**リオン）/ truly（トゥ**ルー**リ）/ masters（**マ**スターズ）

## [0:18–0:40] FOUNDER + INSIGHT（落ち着いて、自分の言葉で）

> My name is **Kensuke Ueoka**. /
> I've practiced **kyudo** / — the way of the bow — / and calligraphy / since I was a child. //
> I know this world / from the **inside**. //
> And I know its **problem**: /
> Japan's deepest culture / — kyudo, tea ceremony, Zen, / the wisdom of local masters — /
> stays **locked** / behind language, / booking, / and **trust** barriers. //

- calligraphy（カ**リ**グラフィ）/ wisdom（**ウィ**ズダム）/ barriers（**バ**リアーズ）

## [0:40–1:05] SOLUTION（テンポよく）

> That's why I'm building **BUSHIDO AI** / — the cultural **intelligence** platform / for authentic Japan. //
> We use **AI** / to understand a traveler's purpose, / interests, / and budget, /
> and design a **personalized** journey / — matching them with **verified** local masters, /
> interpreters, / transport, / and itinerary, / in **one trusted layer**. //
> We're **not** a tour agency. / We're a **cultural experience operating system**. //

- authentic（オー**セ**ンティック）/ itinerary（アイ**ティ**ネラリー）/ verified（**ヴェ**リファイド）

## [1:05–1:30] MOAT（自信を持って）

> Our advantage is simple: / **AI plus trust**. //
> The AI personalizes / and orchestrates the journey. //
> But the **trust** / — a verified network of **real masters** — /
> is something a generic platform / **can't copy**. //
> I've spent **years** building that network / through the **Nagoya Inbound Summit**, / which I founded, /
> and through communities like **JC** and **BNI**. //

- orchestrates（**オー**ケストレイツ）/ generic（ジェ**ネ**リック）

## [1:30–1:55] TRACTION（事実を淡々と・誇りを持って）

> And this is **already happening**. //
> We've delivered **live experiences** / — kyudo, / tea ceremony, / calligraphy. //
> We host the Nagoya Inbound Summit, / connecting tourism, / hotels, / government, / and media. //
> And we're **in talks** with **Nihon Ryoko**, / one of Japan's largest travel agencies. //

## [1:55–2:18] MARKET + EXPANSION（大きく・前向きに）

> Japan aims for **60 million visitors** / and **15 trillion yen** / by **2030** /
> — shifting from mass tourism / to **high-value, authentic** experiences. //
> That is **exactly** our market. //
> We'll start from **Singapore and ASEAN** / — their affluent travelers, / schools, / and corporates — /
> with a **Singapore entity** / as our gateway to Asia. //

- affluent（**ア**フルエント）/ corporates（**コー**ポレッツ）

## [2:18–2:35] VISION + CTA（ゆっくり・目線はレンズ・締める）

> We're **not** selling sightseeing. //
> We're building the **infrastructure** / that delivers the **spirit of Japanese culture** / to the world. //
> I'm Kensuke Ueoka. / This is **BUSHIDO AI**. / **Join us**. //

- infrastructure（**イン**フラストラクチャー）/ spirit（ス**ピ**リット）

## 日本人が外しやすい音（意識する3つ）

1. **th**：think / trust の "th" は舌を軽く噛む（ス/ズではない）
2. **r / l**：trillion・culture の r、locked・layer の l を区別
3. **語尾を消さない**：masters / barriers / experiences の "-s" まで言い切る
