# 16チャンネル SNS運用管理システム

> 基本思想：**人が魂を入れ、AIとスタッフが運用を支える。**
> 完全放置の自動化ではなく、企画はケンの思想・事業方針から作り、量産はAI、編集・予約はスタッフ、最終チェックは重要アカウントだけケンが行う。
> ゴールは「ケンが毎日SNSに張り付かなくても、思想・事業・集客が止まらない状態」。

最終更新：2026-06-07

---

## このシステムの使い方（全体像）

運用は次の4ステップのサイクルで回します。整える順番もこの通りです。

```
① 16チャンネル基本台帳   … 目的・ターゲット・方針を固定（最初に1回作る土台）
        ↓
② 月間投稿カレンダー     … 月1回ケンが方針決定 → 月間の投稿予定を埋める
        ↓
③ 週次予約投稿          … 週2回、スタッフが台本・投稿文を仕上げて予約投稿
        ↓
④ 週次レポート          … 週1回、数字をまとめてケンが事業判断
        ↓（翌週・翌月へ）
   ①②へ反映して改善
```

| [`templates/channel-post-templates.md`](./templates/channel-post-templates.md) | チャンネル別 投稿テンプレ集 | スタッフ＋AI |

## 自動化していい部分・ダメな部分

| ✅ 自動化していい | ⛔ 自動化しない方がいい |
| --- | --- |
| 投稿テーマ出し（AI） | 自動フォロー（スパム判定リスク） |
| 台本作成（AI） | 自動いいね（アカウント制限リスク） |
| キャプション作成（AI） | 自動コメント（信用低下） |
| ハッシュタグ作成（AI） | 自動DM営業（炎上・通報リスク） |
| 投稿カレンダー作成（スプレッドシート） | 個人情報を含む福祉投稿（人の確認必須） |
| 予約投稿（公式機能・外部ツール） | 重要な思想投稿（ケンの魂を入れる必要あり） |
| 数値集計・レポート作成（ツール／AI） | |

## 月次サイクル（ケンがやること＝ここだけ）

毎月1回、次を決めて月間カレンダーに反映します。

1. 今月の重点事業
2. 売りたい商品・集めたい人
3. イベント予定の共有
4. 各チャンネルの重点テーマ

例：

| 月間テーマ | 対象チャンネル |
| --- | --- |
| 名古屋インバウンドサミット集客 | BUSHIDO TRAINING / LinkedIn / realjapan.vibes |
| 鰻ギフト販売 | unaginobori_kensuke |
| 京の都の入居相談 | kyounomiyako_toyoake / 福祉サービス解説 |
| コインランドリー梅雨需要 | bsl各店舗 |

→ 詳しい運用手順は各ファイルを参照してください。
