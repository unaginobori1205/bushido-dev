# ③ 週次予約投稿フロー

> **目的**：カレンダーで決めた投稿を、毎週決まった手順で予約投稿まで持っていく。
> **やる人**：スタッフ（一次）／ケン（重要アカウントの最終確認のみ）。
> **頻度**：週2回（例：水・金）まとめて予約。

最終更新：2026-06-07

---

## 週次の流れ（チェックリスト）

```
[1] カレンダー確認   … 今週の「予約済にすべき投稿」を抽出
[2] 素材そろえる     … 素材管理表で動画・写真・サムネを確認（不足は依頼）
[3] AIで仕上げ       … 台本・投稿文・ハッシュタグを最終化（トーンは基本台帳に従う）
[4] 編集            … 動画編集・サムネ作成 → 状態「編集中」
[5] ケン確認        … ◎/○ チャンネルのみ。OKが出たら次へ（→下の確認ルール）
[6] 予約投稿        … 各プラットフォームで予約セット → 状態「予約済」
[7] 記録            … カレンダーの状態を更新、予約日時を記入
```

毎朝、ケンは当日分の方針だけ確認 → 修正指示 or 許可。許可済みの下書きはスタッフが投稿（or 既に予約済み）。

## 予約投稿の手段（使い分け）

### おすすめの段階導入

| 段階 | 方法 |
| --- | --- |
| **最初** | Googleスプレッドシート（カレンダー）＋ 各SNSの**公式予約機能** |
| **慣れてきたら** | Buffer または Metricool で**一元管理** |

### プラットフォーム別

| プラットフォーム | 予約方法 | 予約可能期間 | 備考 |
| --- | --- | --- | --- |
| **Instagram**（投稿・リール） | 公式予約機能 | 最大30日前まで / 1日25件まで（と案内） | プロアカウント前提。フィード・リール対応 |
| **TikTok** | 公式Video Scheduler / TikTok Studio | 15分後〜10日後 | 10日より先はカレンダー上で「予約待ち」管理し、期間に入ったらセット |
| **LinkedIn** | 公式予約 or Buffer | - | 英語投稿。ビジネス文体 |
| **YouTube（Shorts含む）** | 公式の公開予約 / Buffer | - | サムネ・タイトル・概要欄を忘れず設定 |
| **Googleビジネス（店舗）** | 投稿は基本その都度 | - | 店舗系の口コミ導線。最新情報・特典投稿 |

> ⚠️ **TikTokの10日制限に注意**：カレンダーで11日以上先に決めた投稿は、予約可能期間に入ってから改めてセットする。「予約待ち」を毎週のチェックで拾う。

## ケン確認ルール（基本台帳の「ケン確認」列に従う）

| レベル | 対象 | 予約前にやること |
| --- | --- | --- |
| ◎必須 | Ueoka Kensuke / LinkedIn / kyounomiyako_toyoake / 福祉サービス解説 / BUSHIDO TRAINING / realjapan.vibes | 投稿文・素材をケンに共有 → 許可を得てから予約 |
| ○任意 | P.Kensuke / テスラ / bushido_international_program / unaginobori / ユーワード | 迷ったら確認。基本はスタッフ判断で予約可 |
| △任せる | コインランドリー5店舗 | スタッフ判断で予約。週次レポートでまとめて報告 |

### 必ず人が確認するもの（自動化しない）
- **個人情報を含む福祉投稿**（kyounomiyako_toyoake）：顔出し・障がい特性が分かる情報がないか必ず確認
- **重要な思想投稿**（Ueoka Kensuke / LinkedIn等）：ケンの言葉・魂が入っているか
- **制度説明**（福祉サービス解説）：内容の正確性

## 予約前 最終チェックリスト（各投稿）

- [ ] チャンネルのトーンに合っているか（→ 基本台帳）
- [ ] 投稿文の誤字脱字・事実確認
- [ ] ハッシュタグは3〜7個か
- [ ] 素材（動画・写真・サムネ）は正しいか・画質OKか
- [ ] 個人情報・顔出し配慮（福祉系は特に）
- [ ] 投稿日時は予約可能期間内か
- [ ] ◎/○ チャンネルはケン確認済みか
- [ ] カレンダーの状態を「予約済」に更新したか

---

## やってはいけない自動化（再掲・重要）

| ⛔ NG | 理由 |
| --- | --- |
| 自動フォロー | スパム判定リスク |
| 自動いいね | アカウント制限リスク |
| 自動コメント | 不自然で信用を落とす |
| 自動DM営業 | 炎上・通報リスク |

コメント対応は**スタッフが一次確認**し、人の言葉で返す。
