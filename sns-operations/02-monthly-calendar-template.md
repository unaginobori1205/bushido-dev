# ② 月間投稿カレンダー

> **目的**：いつ・どのチャンネルに・何を投稿するかを1ヶ月分まとめて管理する。
> **作る人**：月初の方針はケン、日々の記入はスタッフ or AI。**週1回更新**。

最終更新：2026-06-07 ／ スプレッドシート取り込み用：[`csv/02-monthly-calendar.csv`](./csv/02-monthly-calendar.csv)

## カレンダー記入項目（各投稿で埋める）

| 項目 | 説明 |
| --- | --- |
| 投稿日 | 何月何日 |
| 時間 | 何時に投稿するか |
| チャンネル | どのアカウントか |
| グループ | A〜E |
| テーマ | 何についてか |

| 投稿文 | Instagram / TikTok 用キャプション |
| ハッシュタグ | 3〜7個 |

**状態の流れ**：`企画中` → `編集中` → `予約済` → `投稿済`

## 週ごとの配分の目安（週40〜50投稿）

グループ別の頻度（→ [基本台帳](./01-channel-master.md)）をそのまま週に落とすと、1週間でおおよそ次の配分になります。

| グループ | チャンネル数 | 各チャンネル/週 | 週合計（目安） |
| --- | --- | --- | --- |
| A 思想系 | 4 | 3〜5 | 12〜20 |
| B インバウンド・教育系 | （Aと一部重複）+1 | 3 | 3〜6 |
| C 物販系 | 3 | 3〜5 | 9〜15 |
| D 店舗系 | 5 | 2〜3 | 10〜15 |
| E 福祉系 | 3 | 3 | 9 |
| **合計** | | | **約40〜50** |

> 全チャンネル毎日は不要。**「信用／売上／来店／相談／思想」のどれを今週伸ばすか**を意識して配分します。

## 推奨タイムライン（毎週のリズム）

| タイミング | やること |
| --- | --- |
| 月曜 | 今週分のカレンダー確定 → AIで台本・投稿文・ハッシュタグ量産 |
| 火〜水 | スタッフが編集 → 状態を「編集中」に |
| 水・金（週2回） | 予約投稿（→ [週次予約投稿フロー](./03-weekly-scheduling-workflow.md)）→ 状態を「予約済」に |
| 毎朝 | ケンが当日の方針確認 → 修正指示 or 許可。ケン録画が必要な投稿だけ収録 |

---

## 予約可能期間メモ（公式仕様）

- **Instagram**：投稿・リールの予約に対応。最大30日前まで・1日25件まで予約可能と案内されています。
- **TikTok**：公式Video Schedulerで15分後〜10日後まで予約可能。
- **一元管理ツール**：Buffer は Instagram・TikTok・LinkedIn・YouTube Shorts などの予約に対応と案内。Metricool は計画・分析・管理をまとめるツールと案内。
- → カレンダー作成時は**予約可能期間内**に収まるよう逆算して埋める。
