# BUSHIDO JAPAN スタイルガイド

人気の日本紹介・教養系チャンネル（旅行系 Vlog、歴史解説、Shorts で伸びている解説動画）に共通する「型」を取り入れ、BUSHIDO JAPAN らしい品格を加えたデザインルールです。パイプラインはこのルールどおりに自動で作ります。

| 名前 | 色 | 使いどころ | 意味 |

| 墨（Ink） | `#111114` | 図の背景、サムネイルの影 | 静けさ・品格 |
| 朱（Vermilion） | `#C8102E` | ショートのフック帯、アクセント線 | 鳥居・日の丸・情熱 |

| 山吹（Highlight） | `#FFD34D` | 字幕のキーワード強調 | 目を引く・読みやすい |

## 2. 字体（すべて商用利用可能なオープンフォント）

| 用途 | 字体 | 理由 |
| --- | --- | --- |
| 本編の英語字幕・図の本文 | **Montserrat ExtraBold** | 太く丸みのある形で、スマホでも読みやすい。欧米の人気チャンネルで定番 |
| ショートの大テロップ・タイトル | **Anton** | 縦長で詰まった字形。1〜3語を大きく出す Shorts の定番書体 |

## 3. 本編（横 16:9）のレイアウト

```
┌────────────────────────────────────────────┐
│                          ┌──────────────┐  │
│                          │  写真ワイプ    │  │  ← 話題の写真を右上に（白フチ＋影＋キャプション）
│        （話し手）          │ Nagoya Castle │  │
│                          └──────────────┘  │
│           日本語字幕（淡い金色）             │
│   English subtitle with **Keyword** 強調    │  ← 1行42文字以内・キーワードは山吹色
└────────────────────────────────────────────┘
```
- **全画面カード**（図解・名言・地図）は、説明の要点で5〜25秒。下部は字幕のために空けています。
- **ワイプ**は話し手の顔を隠さないよう右上に。人気の解説動画で最も多い配置です。
- 字幕は常時表示（英語話者でない視聴者、音を出さずに見る視聴者が多いため）。

## 4. ショート（縦 9:16）のレイアウト

```
┌──────────────┐
│ ▐ HOOK TEXT ▌│ ← 朱色の帯に白文字（最初の1秒で「続きが気になる」一言）
│ ┌──────────┐ │
│ │ 写真/図解 │ │ ← 該当する画像があれば上半分に
│ └──────────┘ │
│   （話し手）   │
│ BIG CAPTION  │ ← 1〜3語ずつ大きく表示、ポンと弾む動き
│  日本語字幕   │
│ BUSHIDO JAPAN│
└──────────────┘
```
- **1〜3語ずつ大きく出すテロップ**は、現在の Shorts で最も視聴維持率が高いとされる型です。
- 冒頭の**フック**は疑問形か意外性（例：「Golden fish on a castle?」）。
- 長さは **20〜45秒**が目安（台本の 🎬 SHORT 区間がこの長さになるよう設計しています）。

## 5. タイトルとサムネイル

**タイトルの型**（英語圏で伸びやすい形）
- 意外性：`Why Nagoya Is the Real Hometown of the Samurai`
- 数字：`The 7 Virtues of Bushido in 40 Seconds`
- 強調語を大文字：`This Japanese Bow Is ALIVE`
- 本編は末尾に `| BUSHIDO JAPAN EP01` を付けてシリーズ感を出す

**サムネイル**：ご自身の表情が映る1コマ ＋ 左側を墨色で暗くして **3〜4語の大きな白文字** ＋ **朱色の帯に1語**（例：NAGOYA）。文字は3行まで。

## 6. 話し方・原稿のルール

- 1文は15語以内、中学〜高校レベルの語彙（CEFR B1）。専門用語は必ず直後に言い換える（例：*Kyudo, the Japanese way of the bow*）。
- 各回に**旅行のプロ向けの実用パート**（モデルコース、所要時間、体験の提案）を必ず入れる。代理店が「お客様にそのまま話せる」一言を意識。
- 伝統への敬意を最優先に。流派名・工房名・人物名を出すときは事前に許可をいただく（小笠原流の「名を商いに使わない」教えに倣う）。
