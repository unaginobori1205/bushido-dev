### 読み方のコツ（収録前にご一読ください）

- **「/」は一呼吸（0.5秒）、「//」はしっかり間（1〜2秒）**。間があると字幕も切れ目がきれいになり、ショートの切り出し精度も上がります。
- **太字の語は少し強く、ゆっくり**。キーワードとして字幕でも色付きで強調されます。
- 日本語の固有名詞（Nobunaga, Atsuta など）は日本語の発音のままで大丈夫です。それが「本物」の説得力になります。
- `🎬 SHORT` の開始文と終了文は**台本どおりに読んでください**（言い換えると自動切り出しが外れます）。それ以外は自由にアドリブして大丈夫です。

## 1. Why Nagoya? The Three Great Unifiers / なぜ名古屋？三英傑（約3分）

`[VISUAL] Diagram: "The Three Unifiers" — Nobunaga / Hideyoshi / Ieyasu with map of Aichi`

> 🎬 **SHORT 2 START**

About 450 years ago, / Japan was at war. / This time is called the **Sengoku period**, / the Warring States period. // Many samurai lords fought each other / for more than one hundred years. //

Then, / three great leaders appeared. / They ended the wars / and brought Japan together. / In Japanese, / we call them the **San-eiketsu**, / the Three Great Heroes. //

And here is the amazing part. / All three of them / came from this area, / around Nagoya. //

> 🎬 **SHORT 2 END**

約450年前、日本は戦の時代でした。戦国時代と呼ばれます。多くの武将が100年以上も争い続けました。
そこに3人の偉大なリーダーが現れ、戦を終わらせ、日本をひとつにしました。日本語で「三英傑」と呼びます。
そして驚くべきことに、3人とも名古屋周辺の出身なのです。

---

The first one is **Oda Nobunaga**. / He was bold, / fast, / and not afraid of new ideas. / He used guns in battle / when other lords did not. //

The second one is **Toyotomi Hideyoshi**. / He was born in a poor family / in Nakamura, / which is now part of Nagoya city. / He started as a servant, / and he became the ruler of all Japan. / It is a true "rags to riches" story. //

The third one is **Tokugawa Ieyasu**. / He was patient. / Very, very patient. / He waited for the right time, / and he started a peace / that lasted about **260 years**. //

一人目は織田信長。大胆で素早く、新しいものを恐れませんでした。他の武将が使わなかった鉄砲を戦に取り入れました。
二人目は豊臣秀吉。現在の名古屋市中村区の貧しい家に生まれ、仕える身から天下人になりました。まさに立身出世の物語です。
三人目は徳川家康。忍耐の人でした。本当に、本当に辛抱強い人でした。時を待ち、約260年続く平和を築きました。

---

`[VISUAL] Text card: "Nobunaga — kill it / Hideyoshi — make it sing / Ieyasu — wait for it"`

There is a famous old saying / about these three men. / Imagine a little bird / that will not sing. //

Nobunaga says, / "If the bird does not sing, / kill it." //
Hideyoshi says, / "If the bird does not sing, / make it want to sing." //
Ieyasu says, / "If the bird does not sing, / wait until it sings." //

Three different leaders. / Three different styles. / I think your clients will love this story. / It is a great way / to explain Japanese history / in just thirty seconds. //

この3人について有名な言い伝えがあります。鳴かない小鳥を想像してください。
信長は「鳴かぬなら殺してしまえホトトギス」。
秀吉は「鳴かぬなら鳴かせてみせようホトトギス」。
家康は「鳴かぬなら鳴くまで待とうホトトギス」。
3人のリーダー、3つのスタイル。お客様はきっとこの話を気に入ります。日本史をたった30秒で伝えられる、とても良い方法です。

## 2. Nagoya Castle and the Golden Shachi / 名古屋城と金鯱（約2.5分）

`[VISUAL] Photo: Nagoya Castle main keep with golden shachihoko`

> 🎬 **SHORT 3 START**

Look at the roof of **Nagoya Castle**. / Do you see the two golden fish? //

They are called **Kinshachi**, / the golden shachi. / A shachi has the head of a tiger / and the body of a fish. / People believed / it could call water / and protect the castle from fire. //

Today, / the golden shachi is the symbol of Nagoya. / You will see it everywhere in the city, / even on souvenirs and manhole covers. //

> 🎬 **SHORT 3 END**

名古屋城の屋根を見てください。2匹の金色の魚が見えますか？
「金鯱（きんしゃち）」と呼ばれます。鯱は虎の頭と魚の体を持ち、水を呼んで城を火事から守ると信じられていました。
今では金鯱は名古屋のシンボルです。お土産やマンホールのふたまで、街のあちこちで見かけます。

---

Nagoya Castle was built / by Tokugawa Ieyasu, / starting in **1610**. / It was one of the most important castles / in all of Japan. //

Sadly, / the main tower was burned / in the Second World War, / in 1945. / It was rebuilt later. / Right now, / the main tower is closed / for a new wooden reconstruction project, / so please check the latest information / before you plan a visit. //

But here is my recommendation for your clients: / the **Hommaru Palace**. / It was carefully rebuilt / with traditional Japanese methods, / and it opened fully in 2018. / The painted gold walls / and the beautiful wooden rooms / show you / how the samurai lords really lived. //

名古屋城は1610年から徳川家康によって築かれました。日本でも最も重要な城のひとつでした。
残念ながら天守は1945年、第二次世界大戦で焼失し、のちに再建されました。現在は木造復元計画のため天守は閉館中ですので、訪問を計画する前に最新情報をご確認ください。
でも、お客様へのおすすめは「本丸御殿」です。伝統工法で丁寧に復元され、2018年に全面公開されました。金色に彩られた障壁画や美しい木造の部屋は、武将たちが実際にどう暮らしていたかを見せてくれます。

## 3. What is Bushido? / 武士道とは（約3分）

`[VISUAL] Book cover: "Bushido: The Soul of Japan" by Nitobe Inazo (1900)`

So, / what is **Bushido**? //

"Bushi" means samurai, / or warrior. / "Do" means **the way**. / So Bushido is / "the way of the warrior." //

In 1900, / a Japanese man named **Nitobe Inazo** / wrote a book in English / called *Bushido: The Soul of Japan*. / He wanted to explain Japanese values / to people in the West. / The book became famous around the world. / Even the American president Theodore Roosevelt / read it. //

では、武士道とは何でしょう？
「武士」はサムライ、戦士のこと。「道」はみち、あり方のことです。つまり武士道は「武士の道」です。
1900年、新渡戸稲造という日本人が英語で『武士道』という本を書きました。日本の価値観を西洋の人々に伝えたかったのです。この本は世界的に有名になり、アメリカのセオドア・ルーズベルト大統領も読みました。

---

`[VISUAL] Diagram: "The 7 Virtues of Bushido" (Gi, Yu, Jin, Rei, Makoto, Meiyo, Chugi)`

> 🎬 **SHORT 4 START**

Bushido is often explained / with **seven virtues**. / Let me share them with you, / one by one. //

**Gi** — / doing what is right. //
**Yu** — / courage. //
**Jin** — / kindness and compassion. //
**Rei** — / respect for others. //
**Makoto** — / honesty and sincerity. //
**Meiyo** — / honor. //
**Chugi** — / loyalty. //

Seven simple words. / But to live them every day / is not simple at all. //

> 🎬 **SHORT 4 END**

武士道はよく「7つの徳」で説明されます。ひとつずつご紹介します。
義 ― 正しいことを行うこと。
勇 ― 勇気。
仁 ― 思いやりと慈しみ。
礼 ― 他者への敬意。
誠 ― 誠実さ。
名誉 ― 名誉。
忠義 ― 忠誠。
7つのシンプルな言葉。でも、毎日それを生きるのは、まったく簡単ではありません。

---

Here is what I want you to understand. / Bushido is **not only about fighting**. / In fact, / during the long peace of the Edo period, / most samurai did not fight at all. / They worked as officials, / teachers, / and artists. //

So Bushido became / a way to live well / in peaceful times. / It is about how you bow, / how you speak, / how you keep your promises, / and how you treat people / who are weaker than you. //

And this spirit / is still alive in Japan today. / When your clients see / a train that arrives exactly on time, / or a shop owner who bows / as they leave, / they are seeing a little bit of Bushido. //

ぜひ知っていただきたいのは、武士道は戦いだけのものではない、ということです。実際、江戸時代の長い平和の間、ほとんどの武士は戦いませんでした。役人として、教師として、芸術家として働いていたのです。
だから武士道は、平和な時代をよく生きるための道になりました。お辞儀の仕方、話し方、約束の守り方、そして自分より弱い立場の人への接し方――それが武士道です。
そしてこの精神は、今も日本に生きています。お客様が時間ぴったりに到着する電車や、帰り際にお辞儀をする店主を見たとき、それは武士道のかけらを見ているのです。

## 4. Atsuta Shrine — The Sacred Sword / 熱田神宮（約1.5分）

`[VISUAL] Photo: Atsuta Shrine torii gate and forest`

Now, / let me take you to a very special place in Nagoya: / **Atsuta Shrine**. //

Atsuta Shrine is about **1,900 years old**. / It is said to keep one of Japan's three sacred treasures, / the holy sword called **Kusanagi**. / Nobody is allowed to see it. / Not even the Emperor. //

> 🎬 **SHORT 5 START**

In 1560, / Oda Nobunaga had a very small army. / His enemy had a huge army. / Everyone thought / Nobunaga would lose. //

Before the battle, / he stopped at **Atsuta Shrine** / and prayed. // Then he attacked / in the rain / and won. / This was the famous **Battle of Okehazama**. //

To say thank you, / Nobunaga gave the shrine a wall. / And that wall / is still standing today. //

> 🎬 **SHORT 5 END**

For Japanese people, / shrines like Atsuta / are not only for religion. / They are places / where we feel connected / to nature, / to our ancestors, / and to something bigger than ourselves. / This feeling is at the center / of Japanese spirituality. //

次に、名古屋のとても特別な場所へご案内します。熱田神宮です。
熱田神宮は約1900年の歴史があり、三種の神器のひとつ「草薙剣（くさなぎのつるぎ）」を祀るとされています。誰も見ることは許されていません。天皇陛下でさえも。
1560年、織田信長の軍はとても小さく、敵は大軍でした。誰もが信長は負けると思っていました。
戦いの前、信長は熱田神宮に立ち寄り、祈りました。そして雨の中を攻め込み、勝利しました。これが有名な「桶狭間の戦い」です。
感謝のしるしとして、信長は神宮に塀を奉納しました。その塀は今も残っています（信長塀）。
日本人にとって熱田神宮のような神社は、宗教のためだけの場所ではありません。自然、祖先、そして自分より大きな何かとのつながりを感じる場所です。この感覚こそ、日本の精神性の中心にあります。

## 5. Kyudo — A Bow That Is Alive / 弓道 ― 生きている弓（約2.5分）

`[VISUAL] Photo: Kyudo archer at full draw (kai) / bamboo bow close-up`

Now I want to tell you about / something very close to my heart: / **Kyudo**. //

Kyudo is Japanese archery. / But in Kyudo, / hitting the target / is not the most important thing. / We have a saying: / **"Seisha hitchu."** / It means, / "A correct shot / will naturally hit the target." //

So we do not chase the target. / We make our posture right, / our breathing right, / and our heart right. / Then the arrow flies true. //

今日は私の心にとても近いもの、弓道についてお話しします。
弓道は日本の弓術です。でも弓道では、的に当てることが一番大切なのではありません。「正射必中（せいしゃひっちゅう）」という言葉があります。「正しい射は、自然に的に当たる」という意味です。
だから私たちは的を追いかけません。姿勢を正し、呼吸を正し、心を正す。そうすれば矢はまっすぐ飛んでいきます。

---

> 🎬 **SHORT 6 START**

This year, / I visited a workshop / where a family makes **bamboo bows** / by hand. //

They taught me something beautiful. / A bamboo bow is **alive**. / It changes with the temperature, / the humidity, / even the time of day. / The same bow feels different / in the morning / and in the evening. //

A carbon bow is always the same. / It is easier. / But a bamboo bow / asks you to listen to nature, / and to listen to yourself. //

That is why / Kyudo is not a sport. / It is a way / to polish your heart. //

> 🎬 **SHORT 6 END**

今年、手作りで竹弓を作っているご家族の工房を訪ねました。
そこで美しいことを教わりました。竹弓は「生きている」のです。気温や湿度、時間帯によってさえ変化します。同じ弓でも、朝と夕方では感覚が違うのです。
カーボンの弓はいつも同じで、扱いやすい。でも竹弓は、自然の声を聴き、自分自身の声を聴くことを求めてきます。
だからこそ弓道はスポーツではありません。心を磨くための道なのです。
